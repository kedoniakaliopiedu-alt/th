# Тайские направительные частицы (Directional Verbs)

Глаголы, грамматикализовавшиеся в постглагольные частицы.  
Стоят **после основного глагола** и уточняют направление, аспект или отношение действия к говорящему.

---

## Итоговая схема

| Частица | Исходный глагол | Аспектуальный смысл |
|---------|-----------------|---------------------|
| มา      | приходить       | к говорящему / нарастание до сейчас |
| ไป      | идти            | от говорящего / продолжение вперёд |
| ไว้     | хранить         | результат сохранён / сделано впрок |
| ออก     | выходить        | высвобождение / результат явлен |
| ขึ้น    | подниматься     | нарастание / увеличение / начало |
| ลง      | спускаться      | уменьшение / снижение |
| เข้า    | входить         | вхождение / углубление / начало контакта |
| คืน     | возвращаться    | возврат к исходному |

---

## Подробно с примерами

### มา — направление К говорящему / возникновение
เขาเอากระเป๋ามา — Он принёс сумку *(сюда, ко мне)*  
ฉันรู้จักเขามานานแล้ว — Я знаю его уже давно *(нарастание до сейчас)*  
เขาโทรมา — Он позвонил *(звонок направлен ко мне)*

### ไป — направление ОТ говорящего / продолжение
เขาเอากระเป๋าไป — Он унёс сумку *(туда, от меня)*  
ทำไปก่อน — Делай пока / продолжай делать  
คิดไปเอง — Додумываешь лишнее *(мысль ушла сама по себе)*  
ต่อไป — Продолжать, далее

### ไว้ — результат зафиксирован / сделано впрок
เปิดไว้ — Открыто *(и оставлено так)*  
จำไว้ — Запомни *(и держи в памяти)*  
บอกไว้แล้ว — Уже сказано / предупреждено заранее  
เก็บไว้ — Убери / сохрани *(и оставь так)*

### ออก — высвобождение / результат явлен наружу
ร้องออกมา — Закричать *(звук вышел наружу)*  
คิดออก — Додуматься, придумать *(мысль вышла)*  
พูดออกมา — Произнести вслух *(слова вышли)*

### ขึ้น — нарастание / увеличение / начало
ราคาแพงขึ้น — Цена выросла  
ดีขึ้น — Стало лучше  
เริ่มขึ้น — Началось  
นึกขึ้นมา — Вспомнилось *(поднялось и пришло)*

### ลง — уменьшение / снижение
ราคาถูกลง — Цена снизилась  
เบาลง — Стало легче / тише  
นั่งลง — Сесть *(спуститься на место)*

### เข้า — вхождение / углубление / начало контакта
เข้าใจ — Понять *(войти в смысл)* — полностью лексикализовалось  
วิ่งเข้าไป — Вбежать внутрь  
ซึมเข้าไป — Просочиться / впитаться внутрь

### คืน — возврат к исходному состоянию
ได้คืน — Получить обратно / вернуть себе  
หายดีคืนมา — Поправиться, вернуться к здоровью

---

## Комбинации

Несколько частиц могут стоять подряд:

| Фраза | Разбор | Перевод |
|-------|--------|---------|
| นึกขึ้นมา | поднялось + пришло ко мне | Вспомнилось |
| เอาออกไป | возьми + выйди + уйди | Унеси |
| วิ่งออกมา | бежать + выйти + прийти сюда | Выбежал сюда |

---

## Межъязыковые параллели

Одна и та же идея — направление меняет смысл глагола — реализована в трёх языках по-разному:

- **Русский**: приставка сливается с глаголом → *принести, унести, выбежать*
- **Английский**: частица стоит после глагола отдельно → *bring in, take away, run out*
- **Тайский**: частица стоит после глагола отдельно → *เอามา, เอาไป, วิ่งออก*

Тайский и английский структурно похожи (постпозиция), русский — морфологически вплавляет направление в глагол.

| Тайская частица | Смысл | Рус. приставка | Англ. частица | Нюансы соответствия |
|---|---|---|---|---|
| มา | к говорящему / нарастание до сейчас | при- | *back, →* (come) | англ. не имеет одной частицы — направление передаёт сам глагол *come* |
| ไป | от говорящего / продолжение | у- / от- | *away, off* | *off* — скорее отделение; *away* — удаление; оба частично покрывают ไป |
| ออก | наружу / высвобождение результата | вы- | *out* | наиболее точное соответствие из всех; *out* = ออก почти 1:1 |
| เข้า | внутрь / углубление | в- | *in, into* | *in* = физически внутрь; *into* = углубление в процесс — оба нужны |
| ขึ้น | вверх / нарастание / начало | вз- / воз- / по- | *up* | *up* в англ. также означает завершённость (*eat up, finish up*) — это уже ближе к ไว้ |
| ลง | вниз / убывание | с- / у- | *down* | соответствие точное; *calm down = เบาลง, sit down = นั่งลง* |
| คืน | возврат к исходному | воз- / вернуть | *back* | *back* = คืน почти 1:1; *get back = ได้คืน* |
| ไว้ | фиксация результата / впрок | за- *(запомни, закрой)* | *(keep), up* | англ. аналога нет; *keep* передаёт идею, но это глагол, не частица |

### Примеры троек

| Тайский | Русский | Английский |
|---|---|---|
| เอามา | при**нести** | bring **→** / carry **over** |
| เอาไป | у**нести** | take **away** |
| วิ่งออก | вы**бежать** | run **out** |
| วิ่งเข้า | в**бежать** | run **in** |
| ราคาขึ้น | цена по**высилась** | prices went **up** |
| ราคาลง | цена с**низилась** | prices went **down** |
| คิดออก | при**думать** / до**думаться** | figure **out** |
| ได้คืน | воз**вратить** / вернуть **себе** | get **back** |
| จำไว้ | за**помни** | keep (in mind) |
| เปิดไว้ | оставь от**крытым** | keep **open** / leave **open** |
| ดีขึ้น | стало **лучше** | get **better** / look **up** |
| นั่งลง | **сесть** | sit **down** |

---

## Ключевой принцип

**Пространственная метафора становится аспектуальной.**  
Физические направления описывают абстрактные движения — мысли, звука, состояния, времени.
