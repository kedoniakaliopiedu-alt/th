Зачем этот блок

Когда задания одной темы идут подряд, правильный ответ подсказывает сам блок — и кажется, что тема выучена. Здесь темы перемешаны нарочно: каждый пункт требует сначала понять, какое правило нужно, и только потом его применить. Это единственный блок, который показывает реальное состояние дел.

График повторов. Один проход ничего не закрепит — работает возвращение через увеличивающиеся промежутки. Отмечай даты прямо здесь:

  1. Сегодня — весь лист, кроме блока N. ____
  2. Через день — блоки, где было больше двух промахов, + блок N. ____
  3. Через три дня — только блок N; что провалилось, гони его блок целиком. ____
  4. Через неделю — блок N ещё раз. ____
  5. Через две недели — блок N последний раз; чисто — тема отпущена. ____

Ключ открывается после ответа, не до. Если открыла раньше — этот пункт не считается пройденным, вернись к нему на следующем круге.

Присылай результаты блоками — текстом либо фото из тетради (тогда через scripts/intake). Разберу и обновлю трекер.
