## Подтема 1.2.1 — Краткие и долгие монофтонги

### Словарный запас (9 пар)

В тайском **каждая гласная имеет краткую и долгую форму**. Это не просто длительность — это **разные фонемы**, и они меняют смысл слова и тон.

| Звук | Краткая | Долгая | Пример (короткая) | Пример (долгая) |
|---|---|---|---|---|
| а | –ะ / –ั | –า | กะ (ка — и, с) | กา (каа — ворона) |
| и | –ิ | –ี | ติ (ти — критиковать) | ตี (тии — бить) |
| ы | –ึ | –ื | หึ (хы̌ — ха!) | หืน (хы̌ын — затхлый) |
| у | –ุ | –ู | จุ (джу — вмещать) | จู๋ (джу̌у — крошечный) |
| ӭ | เ–ะ / เ–็ | เ– | เกะ (кӭ — мешать) | เก (кӭӭ — старый) |
| э | แ–ะ / แ–็ | แ– | แกะ (кэ — баран) | แก (кээ — ты, груб.) |
| о | โ–ะ | โ– | โต๊ะ (то́ — стол) | โต (тоо — большой) |
| о | เ–าะ | –อ | เกาะ (ка̀ — остров) | กอ (коо — куст) |
| ӧ | เ–อะ | เ–อ | เงอะ (нгӧ — неуклюжий) | เธอ (тхӧӧ — ты, мягко) |

⚠️ Знаки в таблице (–ะ, –า и т. д.) — это **знаки гласных**, которые присоединяются к согласной. Чёрточка показывает, где будет стоять согласная.

### Теория

**Где пишется гласный знак?**

Тайский — **абугида**: знак гласной не стоит в линию с согласной, а размещается вокруг неё. Возможны 4 позиции:

| Позиция | Пример | Гласная |
|---|---|---|
| **После** согласной | กา | –า |
| **Над** согласной | กิ | –ิ |
| **Под** согласной | กุ | –ุ |
| **Перед** согласной (читается **после**!) | เก | เ– |
| **Вокруг** согласной (с двух сторон) | เกะ | เ–ะ |

Самая важная особенность: знаки **เ–, แ–, โ–, ใ–, ไ–** пишутся **перед** согласной, но **произносятся после** неё. То есть เก читается «кӭ», а не «ӭк». Это легко перепутать на начальном этапе.

**Принцип написания:** одна гласная = один знак (даже если знак состоит из нескольких частей, как เ–าะ).

**Долгота гласной — фонема, а не оттенок.**

| Пара | Перевод |
|---|---|
| ขาว (кха̌ау) — белый | vs. ขำ (кха̌м) — забавный |
| มา (маа) — приходить | vs. มะ (ма́) — манго (сокр.) |
| ดี (дии) — хороший | vs. ดิน (дин) — земля |

Не просто «протянуть звук» — долгий гласный физически в 2 раза длиннее краткого. Это влияет:
- на смысл (разные слова)
- на тон (краткий слог считается мёртвым, долгий — живым; см. Тема 1.3)
- на финаль (краткий гласный обычно требует фиксированной финали)

**Особые знаки длительности:**
- **–ั** (ма́й хан аакаат) — превращает краткое «а» в **закрытом** слоге: กัน (кан), а не กะน
- **–็** (ма́й тай кху́у) — делает гласный **кратким** в закрытом слоге: เก็บ (кеп), без неё было бы เกบ (кееп)

## Подтема 1.2.2 — Дифтонги и трифтонги

### Словарный запас

Дифтонги — гласные из двух звуков, слитых в один слог. В тайском их **3 основных** (плюс комбинации с -ย, -ว).

| Тайский | Транскрипция | Длина | Пример |
|---|---|---|---|
| เ–ีย | иа / ииа | долгий | เสีย (си̌иа — потерять) |
| เ–ียะ | иа | краткий | เผียะ (пхиа — щёлкать) |
| เ–ือ | ыа / ыыа | долгий | เรือ (рыыа — лодка) |
| เ–ือะ | ыа | краткий (редко) | редко используется |
| –ัว / –ว– | уа / ууа | долгий | กลัว (клуа — бояться) |
| –ัวะ | уа | краткий | ผัวะ (пхуа — шлёп!) |

**Сочетания с -ย (й):**

| Тайский | Транскрипция | Пример |
|---|---|---|
| ไ– | ай | ใจ (дьжай — сердце), ไป (пай — идти) |
| ใ– | ай | ใหญ่ (йа̀й — большой) |
| –ัย | ай | ภัย (пхай — опасность) |
| –าย | аай | ขาย (кха̌ай — продавать) |
| –อย | ооай | ลอย (лоой — плыть) |
| –ุย | уй | คุย (кхуй — болтать) |

**Сочетания с -ว (у):**

| Тайский | Транскрипция | Пример |
|---|---|---|
| เ–า | ау | เขา (кха̌у — он/она, гора) |
| –าว | аау | กาว (каау — клей) |
| –ิว | иу | หิว (хи̌у — голодный) |
| –ีว | ииу | ตีว (тииу — не используется как слог) |
| เ–ียว | ииау | เดี๋ยว (дьжи̌ау — момент) |
| เ–ือย | ыыай | เหนื่อย (ныыай — уставший) |

### Теория

**Формула чтения дифтонга เ–ีย:**

```
เ + согласная + ี + ย
↓        ↓        ↓
"иа" формируется из трёх частей знака
```

Все три части (เ, ี, ย) **обязательны** — это один знак. Без любой из них получится другой слог. Например:
- เสีย → си̌иа (потерять)
- สี → си̌и (цвет)
- สา → са̌а (вид бумаги)

**Формула เ–ือ аналогична**, но с ื и อ:

```
เ + согласная + ื + อ → "ыа"
```

**Сочетания с -ย и -ว** — это, формально, гласная + полугласная-финаль. Но их обычно учат как дифтонги, потому что слышатся слитно.

**Что такое трифтонги?**

Три гласных звука в одном слоге. Их немного:
- เ–ียว (ииау): เดี๋ยว — момент, เลี้ยว — поворачивать
- เ–ือย (ыыай): เหนื่อย — уставший, เลื้อย — ползать

В транскрипции мы записываем все три звука: ии-а-у, ы-ы-а-й.

**Опасный момент — ใ vs ไ.**

Обе буквы читаются как **ай** и звучат одинаково. Различие только в написании. Букв ใ всего **20** в тайском языке (это заученный список), все остальные случаи — ไ.

Самые частые слова с ใ:
> ใจ (дьзай — сердце), ใหญ่ (йа̀й — большой), ใช่ (щай — да), ใน (най — в), ให้ (ха̂й — давать), ใช้ (ща́й — использовать), ใคร (кхрай — кто).

## Подтема 1.2.3 — Особые гласные

### Словарный запас

Эти знаки и буквы — не «гласные» в полном смысле, но ведут себя как самостоятельные слоги или меняют слог особым образом.

| Знак / буква | Чтение | Происхождение | Пример |
|---|---|---|---|
| **อำ** | ам | заимствование из санскрита | คำ (кхам — слово), ทำ (тхам — делать) |
| **ใ–** | ай | один из двух способов записи [ай] | ใจ (дьжай) |
| **ไ–** | ай | второй (основной) способ | ไป (пай) |
| **เ–า** | ау | дифтонг | เขา (кха̌у), เกา (као — чесать) |
| **ฤ** | ры / ри / рӧ | санскритская гласная | ฤดี (рыдии — радость), ฤษี (рыыси̌и — отшельник) |
| **ฤๅ** | рыы | долгая версия ฤ | ฤๅษี = ฤษี (вариант записи) |
| **ฦ** | лы (устаревшая) | санскритская гласная | в современном языке не встречается |
| **ฦๅ** | лыы (устаревшая) | долгая версия | не встречается |

### Теория

**Почему อำ — это «гласная»?**

อำ — короткое сокращение для записи звука [ам]. Это **один знак**, и в тайской лингвистике он считается **гласной**, а не комбинацией «а + м». Хотя по звучанию это ровно «а + м» в финали.

Сравни:
- คำ (кхам) — пишется одним знаком อำ
- คาม (кхаам) — пишется как อา + ม (две части: долгая а + м-финаль)

То есть อำ всегда даёт **короткое [ам]** в конце слога.

**ฤ — санскритское наследство.**

Буква ฤ — реликт из санскрита, где она обозначала «слоговое р». В тайском её произношение зависит от слова. Запомни 3 чтения:

| Чтение | Когда | Пример |
|---|---|---|
| **ры** | перед большинством согласных | ฤดี (рыдии — радость) |
| **ри** | перед некоторыми санскритскими корнями | ฤทธิ์ (ри́т — сверхъестественная сила) |
| **рӧ** | в очень редких случаях | ฤกษ์ (рӧ̂ӧк — благоприятный момент) |

Это правило с исключениями — не пытайся вывести логику. Просто запоминай слова с ฤ по отдельности (их немного).

**ใ и ไ — почему два знака для одного звука?**

Исторически они **звучали по-разному** в древнем тайском (ใ был более закрытым). Сейчас слились в один звук [ай], но различаются в письме. ใ используется только в **20 «святых словах»** — учить их нужно списком.

**Двадцать слов с ใ** (стих для запоминания):

```
ใฝ่ ใจ ใช้ ใช่ ใหญ่ ใหม่ ให้ ใส
ใส่ ใต้ ใน ใคร ใคร่ ใบ ใย ใด
สะใภ้ หลงใหล ใกล้ ใบ้
```

Это нужно знать наизусть. Все остальные [ай]-слова пишутся через ไ.

## Подтема 1.2.4 — Изменение формы в закрытом слоге

### Словарный запас

Когда после гласной появляется согласная-финаль, **некоторые гласные меняют форму**. Это не новые звуки — это **орфографические трансформации**.

| Открытый слог | Закрытый слог | Что произошло |
|---|---|---|
| **กะ** (ка) | **กัน** (кан) | –ะ → –ั (ма́й хан аакаат) |
| **เกะ** (кӭ) | **เก็น** (кӭн) | เ–ะ → เ–็ (ма́й тай кху́у) |
| **แกะ** (кэ) | **แก็น** (кэн) | แ–ะ → แ–็ |
| **โกะ** (ко) | **กน** (кон) | โ–ะ → нет знака! гласная «скрывается» |
| **เกาะ** (ка̀) | **ก็น** (кон) | особый случай |
| **เกอะ** (кӧ) | **เกิน** (кӧн) | เ–อะ → เ–ิ |
| **เกอ** (кӧӧ) | **เกิน** (кӧн) | เ–อ → เ–ิ (в закрытом — то же) |
| **กือ** (кыы) | **กืน** (кыын) | –ือ → –ื– (อ исчезает) |
| **กัว** (куа) | **กวน** (куан) | –ัว → –ว– (ั исчезает, ว уходит вглубь) |

### Теория

**Главный принцип:** при добавлении финали тайская орфография стремится к **компактности**. Если знак гласной можно «свернуть» — он сворачивается.

**Самое частое преобразование:**

`–ะ → –ั` (ма́й хан аакаат)

```
открытый: กะ + (хотим добавить ก в финали) 
закрытый: กัก (а не กะก!)
```

Знак –ะ просто несовместим с финалью — нужна замена.

**Самое коварное преобразование:**

`โ–ะ → исчезает`

```
открытый: โกะ (ко) — короткое о
закрытый: กน — читается «кон»!
```

В закрытом слоге короткое [о] **не имеет знака** — оно «по умолчанию» вписывается между двумя согласными. Это значит:

| Запись | Чтение | Объяснение |
|---|---|---|
| คน | кхȯн | согласная + согласная без знака гласной = «о» |
| กบ | гȯ̀п | то же правило |
| สด | сȯ̀т | то же |
| รส | рȯ́т | то же |

Если бы был долгий [о], писалось бы โกน (коон), โบน (боон).

**Запомни как правило-якорь:**
> Две согласные подряд без гласного знака между ними = краткое [о].

**Дифтонги тоже меняются:**

`–ัว → –ว–`

```
открытый: ตัว (туа — тело)
закрытый: ตวน (туан) — ั исчезает, ว уходит на место «между»
```

`–ือ → –ื–`

```
открытый: คือ (кхыы — это есть)
закрытый: คืน (кхыын — ночь, возвращать) — อ исчезает
```

**Зачем это знать?**

Когда читаешь незнакомое слово, нужно различать:
- กน → **кон** (краткое [о] без знака)
- กัน → **кан** (а с финалью)
- กิน → **кин** (и с финалью)
- กืน → **кыын** (ы долгое с финалью, อ исчезла)

Без знания этих трансформаций ты не сможешь правильно прочитать ни одно закрытое слово.
