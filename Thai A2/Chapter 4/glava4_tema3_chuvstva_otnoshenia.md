### Теория

**Три большие категории.**

Эмоции в тайском условно делятся на:

**1. Через ใจ (сердце):**
Большинство психологических состояний — через корень **ใจ** (джай — сердце, ум, психика). Об этом отдельная подтема.

**2. Самостоятельные глаголы:**
```
รัก          любить
ชอบ        нравиться
เกลียด      ненавидеть
โกรธ        злиться
กลัว         бояться
```

**3. Через มี + существительное:**
```
มีความสุข        быть счастливым («иметь счастье»)
มีความรัก        быть влюблённым («иметь любовь»)
มีความเศร้า     грустить («иметь печаль»)
```

**ความ + прилагательное** = существительное эмоции. Это абстрактное «-ость»:
- สุข (счастливый) → ความสุข (счастье)
- เศร้า (грустный) → ความเศร้า (грусть)
- รัก (любить) → ความรัก (любовь)

**รัก vs ชอบ — критическое различие.**

- **รัก** — глубокая привязанность, любовь (к человеку, к стране, к семье).
- **ชอบ** — предпочтение, нравится («любить» в смысле «нравится»).

```
ฉันรักคุณ          я люблю тебя (любовно)
ฉันชอบกาแฟ      мне нравится кофе («я люблю кофе»)
ฉันชอบคุณ         ты мне нравишься (романтически — но мягче, чем รัก)
```

**В лакорнах:**
- Герой говорит «ฉันชอบเธอ» — первое признание, ещё не любовь, но симпатия.
- «ฉันรักเธอ» — серьёзное признание, обычно ближе к середине-концу.

Путать категорически нельзя. Сказать матери «ฉันชอบคุณแม่» — это «ты мне нравишься» (странно от ребёнка). Правильно — «ฉันรักคุณแม่».

**คิดถึง — «скучать по кому-то».**

Буквально «думать-достигать» — мысль доходит до кого-то. Это не «грустить от отсутствия», а **«постоянно думать о ком-то отсутствующем»**:

```
คิดถึงเธอ              скучаю по тебе
คิดถึงบ้าน              скучаю по дому
คิดถึงเมืองไทย       скучаю по Таиланду
```

В лакорнах одна из самых частых романтических фраз:
- **«คิดถึงนะ»** — «скучаю, ладно?»
- **«คิดถึงมาก»** — «очень скучаю»

В песнях — почти в каждой второй.

**Гнев — несколько слов.**

- **โกรธ** (кро̀от) — злиться (общее, нейтральное).
- **โมโห** (моо-хо̌о) — сердиться (сильнее, чаще от женщин).
- **หงุดหงิด** (нгу̀т-нгѝт) — раздражаться, быть на нервах (от мелочей).

```
ฉันโกรธคุณ              я зла на тебя
อย่าโมโหสิ               не злись же
หงุดหงิดทั้งวัน          весь день раздражённая
```

**Стесняться — две формы.**

- **อาย** (аа̄й) — общее «стесняться» (в любой социальной ситуации).
- **เขิน** (кхо̌эн) — «смущаться» в **романтическом** контексте, когда краснеешь от комплимента или влюблённости.

```
อายคน              стесняться людей
เขินอ่ะ              смущаюсь («ой, смущаюсь»)
```

В лакорнах героиня от комплимента: «**เขินจัง**» (так смущаюсь!).

### Якоря

- **รัก** = любить, **ชอบ** = нравиться — не путать.
- **คิดถึง** = «скучать по кому-то» (думать о ком-то).
- **โกรธ / โมโห / หงุดหงิด** — три оттенка гнева.
- **อาย** общее, **เขิน** романтическое.
- **ความ + прилагательное** = существительное эмоции.

| **ดีใจ** | дии-джай | хорошо-сердцу | радоваться |

| **เข้าใจ** | кхâу-джай | войти-сердце | понимать |

### Теория

**Главный принцип:** в тайском **ใจ (сердце) — центр психологии**. Большинство эмоций, состояний, черт характера и мотивов описываются **составными словами с ใจ**.

Это не образная речь — это **базовая лексика**. Тайцы не задумываются, что говорят «сердце-хорошее» — они просто говорят «добрый».

**Две структуры.**

**1. ใจ + прилагательное** = черта характера / постоянное состояние:
```
ใจดี              добрый
ใจร้าย            злой
ใจเย็น           спокойный
ใจร้อน           вспыльчивый
```

**2. Глагол/прилагательное + ใจ** = эмоциональное состояние / действие:
```
ดีใจ              радоваться
เสียใจ           расстроиться
เข้าใจ           понимать
สนใจ            интересоваться
```

⚠️ Заметь: **ใจดี** и **ดีใจ** — **разные слова**!
- **ใจดี** (сердце-хорошее) = добрый (черта характера)
- **ดีใจ** (хорошо-сердцу) = радоваться (эмоция)

Порядок имеет значение.

**Главные пары.**

| Прилагательное | + ใจ (состояние) | ใจ + прилагательное (характер) |
|---|---|---|
| **ดี** (хороший) | **ดีใจ** = рад | **ใจดี** = добрый |
| **เสีย** (потерять/сломать) | **เสียใจ** = расстроен | **ใจเสีย** = в смятении |
| **เย็น** (прохладный) | — | **ใจเย็น** = спокойный |
| **ร้อน** (горячий) | — | **ใจร้อน** = вспыльчивый |

**Психологическое пространство ใจ.**

ใจ — это **сердце как вместилище**:
- **กว้าง** (широкое) — щедрое.
- **แคบ** (узкое) — мелочное.
- **อ่อน** (мягкое) — поддающееся.
- **แข็ง** (твёрдое) — стойкое.
- **กล้า** (смелое) — храброе.
- **เสีย** (сломанное) — потерянное.
- **หาย** (исчезло) — в шоке.

Это **универсальная метафора**: сердце как пространство, которое может быть разной формы и состояния.

**Глагол + ใจ — действия с сердцем.**

```
เข้าใจ            войти-в-сердце = понять
สนใจ             сосредоточить-сердце = интересоваться
ตั้งใจ             поставить-сердце = намереваться, стараться
ใส่ใจ             положить-сердце = обращать внимание
น้อยใจ          мало-в-сердце = обижаться (чувствовать, что тебе не дали достаточно)
กินใจ            съесть-сердце = трогать (за душу)
เปลี่ยนใจ       сменить-сердце = передумать
```

**В лакорнах ใจ — главный концепт.**

Драмы строятся вокруг «состояния сердца» героев:
- **«หัวใจสลาย»** (хǎу-джай са̀-лǎай) — «сердце разбито».
- **«ใจหายไป»** — «сердце ушло».
- **«กินใจ»** — «трогает (за душу)».
- **«ดวงใจ»** (дуанг-джай) — «моё сердечко» (нежное обращение к любимому).

Романтические песни почти полностью построены на ใจ-метафорах:
- **«ใจฉันมีเธอคนเดียว»** — «в моём сердце только ты».
- **«ใจของเธออยู่กับใคร»** — «с кем твоё сердце».

**เกรงใจ — ещё раз.**

Это слово ты уже встречала. В контексте ใจ-составных: «бояться сердца (другого)» — то есть не хотеть нарушить покой / комфорт другого человека. Это эмоция, **направленная вовне**, на чувства собеседника. Универсальное тайское переживание.

### Якоря

- **ใจ + прилагательное** = черта характера (постоянное).
- **Прилагательное + ใจ** = эмоция (преходящее).
- **ใจดี ≠ ดีใจ** — порядок важен.
- В лакорнах **ใจ-метафоры** — главный язык чувств.

## Подтема 4.3.3 — Романтическая лексика

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **รัก** | рак | любить |

| **คิดถึง** | кхит́-тхы̌нг | скучать |
| **คนรัก** | кхон-рак | возлюбленный/-ая |

| **คู่รัก** | кху̂у-рак | пара (влюблённых) |
| **อกหัก** | о̀к-ха̀к | разбитое сердце («грудь сломана») |
| **เลิกกัน** | лы̂ык-кан | расстаться |
| **คบกัน** | кхо́п-кан | встречаться |
| **จีบ** | джип̀ | флиртовать, ухаживать |
| **ขอแต่งงาน** | кхо̌о-тэ̀энг-нгаан | сделать предложение |
| **แต่งงาน** | тэ̀энг-нгаан | пожениться |
| **หย่า** | йа̀а | развестись |
| **หมั้น** | ман̂ | помолвиться |
| **หวง** | хуа̌нг | ревновать |
| **หึง** | хы̌нг | ревновать (сильно, к измене) |
| **คิดมาก** | кхит́-маа̂к | переживать, много думать |
| **ทำเป็น** | тхам-пэн | прикидываться |
| **หลอก** | ло̀ок | обманывать |
| **โกหก** | коо-хо̀к | лгать |
| **เชื่อใจ** | чхы̂а-джай | доверять |
| **เป็นห่วง** | пэн-ху̀анг | беспокоиться о ком-то |
| **ดูแล** | дуу-лэ̄э | заботиться |
| **ห่างเหิน** | ха̀анг-хэ̌эн | отдаляться |
| **กลับมา** | кла̀п-маа | вернуться |
| **อกหัก** | о̀к-ха̀к | страдать от разбитого сердца |

### Теория

**Лексическая лестница любви.**

Тайская романтическая лексика идёт по **градации интенсивности**:

```
ชอบ          нравится (симпатия)
↓
หลงรัก        влюбиться, увлечься
↓
ตกหลุมรัก    влюбиться по уши («упасть в ямку любви»)
↓
รัก           любить
↓
รักมาก        очень любить
↓
รักที่สุด        любить больше всех
```

В лакорнах это **движение по лестнице** — двигатель сюжета. От первого «ชอบ» до «รักที่สุด» — обычно вся серия отношений.

**ที่รัก — главное обращение.**

**ที่รัก** (тхии-рак) — «дорогой/дорогая, любимый/любимая». Универсальное романтическое обращение, не различает пол:

```
ที่รักของฉัน          моя любимая / мой любимый
ที่รัก ฉันคิดถึงเธอ    дорогой/-ая, я скучаю по тебе
```

В лакорнах **ที่รัก** — постоянное в романтических диалогах. В русских субтитрах часто передают как «милый/милая».

**Другие нежные обращения:**
- **ดวงใจ** (дуанг-джай) — «сердечко моё».
- **ที่หนึ่งในใจ** (тхии ныɣ най джай) — «единственный в сердце».
- **คนเดียวในใจ** (кхон дии-уу най джай) — «единственный в сердце».

**Признание в любви.**

```
ฉันรักเธอ                я люблю тебя (стандарт)
ผมรักคุณ                я люблю вас (мужчина, формально-нежно)
รักนะ                     люблю (без подлежащего, интимно)
รักที่สุดในโลก            люблю больше всего на свете
```

**Расставание.**

- **เลิกกัน** (лы̂ык-кан) — расстаться (буквально «закончить друг с другом»).
- **อกหัก** (о̀к-ха̀к) — «грудь сломана» = разбитое сердце.

```
เราเลิกกันแล้ว                  мы расстались
ฉันอกหัก                          у меня разбито сердце
ฉันร้องไห้ทุกคืน                 я плачу каждую ночь
```

В лакорнах сцена расставания — кульминация серии. **«เลิกกัน»** часто звучит как окончательный приговор: «**พอแล้ว เลิกกัน**» — «хватит, расстаёмся».

**Ревность — два слова.**

- **หวง** (хуа̌нг) — ревновать, оберегать («моё, не трогай»). Может быть к вещи, к человеку.
- **หึง** (хы̌нг) — ревновать в значении подозрения в измене.

```
ฉันหวงเธอ            я тебя ревную (оберегаю)
ฉันหึงเธอ              я тебя ревную (подозреваю)
```

**Обман и доверие.**

```
เชื่อใจ              доверять
ไม่เชื่อใจ           не доверять
หลอก               обмануть
โกหก                лгать
ปลอม               фальшивый
จริงใจ              искренний
```

В лакорнах главный конфликт часто — **โกหก / ปลอม / หลอก** vs **จริงใจ / รักจริง**. Героиня раскрывает обман — кульминация.

**Уход и возвращение.**

```
จาก                  уйти
จากไป                уйти прочь
ทิ้ง                    бросить (бросить кого-то)
หาย                  пропасть
กลับมา               вернуться
รอ                    ждать
ไม่กลับมา           не вернуться
```

В песнях и лакорнах:
- **«อย่าทิ้งฉัน»** — «не бросай меня».
- **«ฉันจะรอ»** — «я буду ждать».
- **«ฉันจะกลับมา»** — «я вернусь».

### Якоря

- Лестница: **ชอบ → หลงรัก → ตกหลุมรัก → รัก**.
- **ที่รัก** — универсальное «любимый/-ая».
- **เลิกกัน** — расстаться.
- **หวง vs หึง** — два типа ревности.
- **โกหก / หลอก** — обман — главный сюжетный двигатель.

### Практические упражнения

**Упражнение 1.** Переведи:
1. Я люблю тебя.
2. Я скучаю.
3. Дорогой/-ая, я тебя жду.
4. Мы расстались.
5. У меня разбито сердце.

**Упражнение 2.** Расставь по силе чувства (от слабого к сильному):
> ตกหลุมรัก, ชอบ, รักที่สุด, หลงรัก, รัก

**Упражнение 3.** Прочитай и переведи:

2. อย่าทิ้งฉันไปนะ
3. ฉันจะรอเธอเสมอ

5. ที่รัก คิดถึงมาก

## Подтема 4.3.4 — Усилители и оттенки

### Словарный запас

| **มากๆ** | маа̂к-маа̂к | очень-очень |
| **มากที่สุด** | маа̂к тхии су̀т | больше всего |
| **เลย** | лӧ̄эй | вообще, совсем (усилитель) |
| **เกินไป** | кӧ̄эн-пай | слишком |
| **ที่สุด** | тхии-су̀т | самый, в наивысшей степени |
| **จริงๆ** | джинг-джинг | по-настоящему, правда-правда |
| **แบบ** | бэ̀эп | как, вроде, типа |
| **เหมือน** | мы̌ан | как, похоже на |
| **เพียง** | пхиианг | только, лишь |
| **แค่** | кхэ̂э | только, лишь |
| **น้อย** | но́й | мало |
| **นิดหน่อย** | нѝт-нòй | чуть-чуть |
| **เกือบ** | кы̀ап | почти |
| **ค่อนข้าง** | кхо̂н-кха̂анг | довольно, скорее |
| **สุดๆ** | су̀т-су̀т | вообще, до предела |
| **อย่างยิ่ง** | йâанг-йин̂g | в высшей степени (формальное) |
| **ขนาดนี้** | кха̀-нàат нии́ | до такой степени |

### Теория

**Базовые усилители — มาก, เลย, ที่สุด.**

**มาก** (маа̂к) — «очень, много». Самый частый усилитель:
```
รักมาก               очень люблю
สวยมาก              очень красиво
หิวมาก                очень голодная
```

Ставится **после** прилагательного или глагола.

**เลย** (лӧ̄эй) — «вообще, совсем». Используется для подчёркивания:
```
ไม่รู้เลย               вообще не знаю
ดีเลย                  отлично (= вообще хорошо)
ชอบเลย               сразу понравилось
ไปเลย                  пошёл!
```

В лакорнах **เลย** часто работает как разговорное «ну прям»: «สวยเลย» — «прям красиво».

**ที่สุด** (тхии-су̀т) — «самый, в наивысшей степени»:
```
สวยที่สุด                самая красивая
รักที่สุด                 больше всего люблю
ชอบที่สุด               больше всего нравится
```

Это **суперлатив**, аналог русского «-айший».

**Удвоение — มากๆ.**

Через **майямок (ๆ)** прилагательное удваивается для усиления:
```
สวยๆ            красиво-красиво (очень)
ดีๆ              хорошо-хорошо
มากๆ            очень-очень
```

В лакорнах:
- «ฉันรักเธอมากๆ» — «я очень-очень тебя люблю».

**Слишком — เกินไป.**

Ставится **после** прилагательного:
```
แพงเกินไป           слишком дорого
ดีเกินไป              слишком хорошо (= подозрительно)
รักมากเกินไป       любить слишком сильно
```

В лакорнах «**รักมากเกินไป**» — драматический самоупрёк героя: «я слишком сильно полюбил».

**Только — แค่ vs เพียง.**

- **แค่** (кхэ̂э) — разговорное «только, лишь».
- **เพียง** (пхиианг) — более литературное.

```
แค่หนึ่งคน            только один человек
แค่ฉันกับเธอ          только ты и я
เพียงเท่านี้             только это (формально)
```

**Чуть-чуть — นิดหน่อย.**

```
หิวนิดหน่อย                чуть голодная
รักนิดหน่อย                чуть-чуть люблю (= не сильно)
รอนิดหน่อย                подожди немного
```

**Почти — เกือบ.**

```
เกือบทุกวัน                почти каждый день
เกือบลืม                   почти забыла
เกือบร้องไห้              почти расплакалась
```

**Довольно — ค่อนข้าง.**

Это «срединное» состояние — не сильно, но и не слабо:
```
ค่อนข้างดี              довольно хорошо
ค่อนข้างเก่ง           довольно умелый
ค่อนข้างเหนื่อย       довольно усталая
```

**Усиления через сравнение — เหมือน, แบบ.**

```
เหมือนฝัน               как сон
สวยเหมือนดารา        красивая как актриса
ใจดีแบบแม่               добрая как мама
แบบนี้                       как это
```

В лакорнах **«เหมือน»** — частое в романтических фразах: «**เธอสวยเหมือนนางฟ้า**» — «ты красива как ангел».

### Якоря

- **มาก** = очень; **เลย** = вообще/совсем; **ที่สุด** = самый.
- **มากๆ** — удвоение для усиления.
- **เกินไป** = слишком; **แค่ / เพียง** = только.
- **เกือบ** = почти; **ค่อนข้าง** = довольно.
- **เหมือน / แบบ** — сравнения.

### Практические упражнения

**Упражнение 1.** Усиль фразу разными способами:
1. ฉันรักเธอ → очень → ?
2. ฉันรักเธอ → больше всего → ?
3. ฉันรักเธอ → очень-очень → ?
4. ฉันรักเธอ → слишком → ?

**Упражнение 2.** Переведи:
1. Я очень рада.
2. Я больше всего люблю свою маму.
3. Мне это слишком дорого.
4. Только ты и я.
5. Почти каждый день.

**Упражнение 3.** Прочитай и переведи:
1. ฉันรักเธอมากที่สุดในโลก
2. ดีเลย
3. ค่อนข้างเหนื่อย
4. เกือบลืมเลย
5. สวยเหมือนนางฟ้า

**Упражнение 4.** Найди отличие в оттенках:
1. รัก vs รักมาก vs รักที่สุด
2. ดี vs ดีๆ vs ดีเลย
