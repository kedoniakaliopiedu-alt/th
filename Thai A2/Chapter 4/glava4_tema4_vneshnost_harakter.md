### Теория

**Главное различие — สวย vs หล่อ.**

В отличие от русского, тайский имеет **разные слова** для красоты по полу:

- **สวย** (су̌ай) — красивая (о женщине, девушке).
- **หล่อ** (ло̀) — красивый (о мужчине, парне).

Перепутать нельзя:
```
✓ ผู้หญิงสวย          красивая девушка
✗ ผู้หญิงหล่อ          (неестественно)
✓ ผู้ชายหล่อ           красивый парень
✗ ผู้ชายสวย            (звучит странно)
```

Однако **น่ารัก** (милый) применяется к обоим полам — это нейтральное «симпатичный».

**Литературное — งาม.**

**งาม** (нгааам) — «прекрасный». Используется в поэзии, песнях, исторических лакорнах. В современной разговорной речи редко.

```
นางงาม              «прекрасная леди» (титул победительницы конкурса красоты)
สวยงาม              красивый-прекрасный (усиление)
```

**Размер и фигура.**

```
สูง                 высокий
เตี้ย               низкий
อ้วน                толстый
ผอม                худой
หุ่นดี              хорошая фигура
สวยหุ่น              красивая фигура
```

**Замечание:** в тайской культуре **«толстый» (อ้วน) — деликатное слово**. Прямо сказать «อ้วน» о человеке — невежливо. Чаще говорят:
- **«ท้วม»** (тхуа́м) — пухленький, в теле (мягче).
- **«หุ่นไม่ดี»** (хун̀ ма̂й дии) — «фигура не очень» (эвфемизм).

В лакорнах злые свекрови иногда прямо говорят: «อ้วนแล้วนะ» — «уже толстая стала» — намеренная грубость.

**Возраст.**

- **เด็ก** — молодой, ребёнок.
- **หนุ่ม / สาว** — молодой/молодая (16-35).
- **กลางคน** — средний возраст (35-55).
- **แก่** — пожилой, старый.

```
ผู้หญิงสาว              молодая женщина
หนุ่มหล่อ                красивый молодой парень
คนแก่                    старый человек, пожилой
```

**ดู + прилагательное = «выглядеть как».**

```
ดูดี                    хорошо выглядишь
ดูแก่                   выглядишь старше
ดูเด็ก                   выглядишь моложе
ดูเหนื่อย               выглядишь усталой
ดูสวย                   выглядишь красивой
```

В лакорнах **«ดูดีนะวันนี้»** — комплимент при встрече.

### Якоря

- **สวย** = женская красота, **หล่อ** = мужская.
- **น่ารัก** = для обоих, нейтрально.
- **อ้วน** — деликатное слово, лучше **ท้วม** или эвфемизм.
- **ดู + прилагательное** = «выглядеть».

### Теория

**Структура составных частей тела.**

Многие части тела — **составные** через «主 + узел/часть»:
```
ข้อ + ศอก       сустав + локоть = ข้อศอก (локоть как сустав)
ข้อ + มือ        сустав + рука = ข้อมือ (запястье)
ข้อ + เท้า       сустав + стопа = ข้อเท้า (щиколотка)
นิ้ว + เท้า       палец + стопы = นิ้วเท้า (палец ноги)
ส้น + เท้า       пятка + стопы = ส้นเท้า (пятка)
```

Это даёт систематичность: зная корни (ข้อ — сустав, นิ้ว — палец), можешь конструировать.

**Тайский избегает прямых упоминаний.**

В тайской культуре есть **табу на упоминание частей тела ниже пояса** в прямой речи. Вместо прямых названий:
- В медицинском контексте — формальные термины.
- В обычной речи — эвфемизмы.

В лакорнах это не проблема, потому что эти части почти не упоминаются. Внешность фокусируется на лице, фигуре в общем, руках, ногах.

**Голова — особая часть.**

В буддистской культуре **голова священна**. Категорически нельзя:
- Похлопать ребёнка или взрослого по голове (только очень близких).
- Передавать вещи **через голову** другого.
- Перешагивать через лежащего человека.

Соответственно, **ноги — наименее «чистая» часть**:
- Нельзя показывать ступнями на людей, изображения Будды, важные предметы.
- Сидеть лицом к Будде нужно с ногами, повёрнутыми в сторону, не на образ.

В лакорнах эти культурные коды проявляются: герои не похлопывают друг друга по голове (только мать с ребёнком, очень нежно), не задирают ноги при сидении.

**ใจ ≠ หัวใจ.**

- **ใจ** (джай) — психологическое «сердце» (центр эмоций, ума).
- **หัวใจ** (хуа̌-джай) — анатомическое **«сердце»** (орган).

```
ฉันเจ็บใจ              мне больно на душе (психологически)
ฉันเจ็บหัวใจ           у меня боль в сердце (физически или сильная эмоциональная боль)
```

В лакорнах **«หัวใจสลาย»** (сердце разбито) — это сильнее, чем «ใจสลาย» — задействует и физическое сердце.

**Болеть — конструкция.**

```
ปวด + часть тела
ปวดหัว              головная боль
ปวดท้อง            болит живот
ปวดฟัน              зубная боль
ปวดหลัง            болит спина
ปวดหู                боль в ухе

เจ็บ + часть тела
เจ็บคอ              болит горло
เจ็บเข่า              больно колено (от ушиба)
```

Разница:
- **ปวด** — ноющая, тупая боль (мигрень, тяжесть).
- **เจ็บ** — острая, резкая боль (ушиб, ранение).

### Якоря

- Голова — **священна**, ноги — **«низкие»** (культурные коды).
- **ใจ** (психологическое) vs **หัวใจ** (анатомическое).
- **ปวด** — ноющая боль; **เจ็บ** — острая боль.
- **ข้อ + часть** = сустав (запястье, локоть, щиколотка).

| **ขี้แย** | кхии̂-йэ́э | склонный к плачу | плакса |

### Теория

**Что такое ขี้-приставка.**

**ขี้** (кхии̂) — это **продуктивная приставка**, превращающая глагол или состояние в **черту характера**: «склонный к (что-то)».

```
ขี้ + เกียจ (лениться) = ขี้เกียจ (ленивый)
ขี้ + อาย (стесняться) = ขี้อาย (стеснительный)
ขี้ + โกหก (врать) = ขี้โกหก (лжец)
```

**⚠️ Этимологическая особенность.** Само слово **ขี้** буквально значит «экскременты», «помёт». В качестве приставки оно работает метафорически: «то, что у человека постоянно выделяется» = «характерное поведение». Это не воспринимается как грубость в составных словах — это **обычная грамматическая частица**.

Однако в **прямом** значении **ขี้** — действительно грубое слово, и его использование как существительного — детский лексикон или просторечие.

**Структура: ขี้ + глагол / состояние.**

Приставка добавляется к **глаголу или прилагательному** действия:

```
ขี้ลืม              забывчивый (часто забывает)
ขี้บ่น              ворчливый (часто бурчит)
ขี้กลัว             пугливый (часто боится)
ขี้สงสาร           жалостливый (часто жалеет)
```

Это **продуктивная** структура — можешь придумать новые слова по образцу:
- ขี้คิด — мечтательный (много думает)
- ขี้นอน — соня (любит спать)
- ขี้ถาม — любознательный (много спрашивает)

Не все такие «новые» слова устоявшиеся, но тайцы поймут.

**Эмоциональный окрас.**

Большинство ขี้-слов имеют **лёгкий негативный** или **дружески-критический** оттенок. Это **ярлык-наклейка**, который можно использовать:
- С симпатией к близкому: «อย่ามาขี้บ่นสิ» (не ворчи!) — мягкий упрёк.
- С критикой к третьему лицу: «เขาขี้เหนียวมาก» (он очень скупой) — характеристика.

В лакорнах ขี้-слова часто звучат в дружеских поддразниваниях между подругами или в характеристике персонажа:
- **«เธอขี้อาย»** — «ты застенчивая» (мило).
- **«เขาขี้หึง»** — «он ревнивый» (предупреждение).
- **«ผัวขี้เมา»** — «муж-пьянчуга» (грубовато).

**Список самых частых:**

| Слово | Смысл | Контекст лакорна |
|---|---|---|
| **ขี้เกียจ** | ленивый | критика подростка, нерадивого мужа |
| **ขี้อาย** | стеснительный | характеристика молодой героини |
| **ขี้บ่น** | ворчун | старшая родственница, жена |
| **ขี้ลืม** | забывчивый | пожилые, рассеянные персонажи |
| **ขี้หึง** | ревнивый | антагонист, ревнивый муж |
| **ขี้น้อยใจ** | обидчивый | героиня, склонная к слезам |
| **ขี้เหนียว** | скупой | антагонист-богач |

**Контраст с прямыми прилагательными.**

```
อาย               стесняется (сейчас, в данный момент)
ขี้อาย              стеснительный (характер, постоянно)

กลัว              боится (сейчас)
ขี้กลัว              пугливый (характер)

ลืม                забыла (сейчас)
ขี้ลืม              забывчивая (характер)
```

ขี้ переводит **временное состояние в постоянную черту**.

### Якоря

- **ขี้ + глагол/состояние** = «склонный к этому» (черта характера).
- Лёгкий **негативный** или **дружески-критический** окрас.
- В лакорнах — частые **ярлыки** для персонажей.
- Превращает **временное** в **постоянное**.

## Подтема 4.4.4 — Сравнения

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **กว่า** | кваа̀ | чем (для сравнения) |
| **มากกว่า** | маа̂к-кваа̀ | больше чем |
| **น้อยกว่า** | но́й-кваа̀ | меньше чем |
| **เหมือนกัน** | мы̌ан-кан | одинаково |
| **เหมือน** | мы̌ан | как, похоже на |
| **คล้าย** | кхла́ай | похожий |
| **ต่างกัน** | та̀анг-кан | отличаться |
| **ที่สุด** | тхии-су̀т | самый |
| **เท่ากัน** | тхау-кан | равно |
| **เท่ากับ** | тхау-кàп | равно (формальное) |
| **ราวกับ** | рау-кàп | как будто, словно |
| **ดุจ** | ду̀т | как (поэтическое) |
| **เปรียบเหมือน** | приан-мы̌ан | сравнить с |

### Теория

**Базовое сравнение — กว่า.**

Структура:
```
[A] + прилагательное + กว่า + [B]
«A более прилагательнее, чем B»
```

Примеры:
```
ฉันสูงกว่าเธอ                    я выше тебя
เขารวยกว่าฉัน                   он богаче меня
ผมฉันยาวกว่าผมเธอ              мои волосы длиннее твоих
ที่นี่ร้อนกว่ารัสเซีย                здесь жарче, чем в России
```

**Самый — ที่สุด.**

```
สวยที่สุด                       самая красивая
รักมากที่สุด                   больше всего люблю
ลูกคนเล็กที่สุด                 самый младший ребёнок
```

В лакорнах **ที่สุด** — частая клятва: «**รักเธอที่สุดในโลก**» — «люблю тебя больше всех на свете».

**Одинаковость — เหมือนกัน.**

```
เราเหมือนกัน                  мы одинаковые
สูงเหมือนกัน                  одинакового роста
ฉันก็คิดเหมือนกัน              я думаю так же
```

**Похожесть — เหมือน, คล้าย.**

- **เหมือน** (мы̌ан) — как, похоже (более полное сходство).
- **คล้าย** (кхла́ай) — похоже (внешне).

```
เธอเหมือนแม่                  ты как мама / похожа на маму
เด็กคนนี้คล้ายพ่อ                этот ребёнок похож на отца
สวยเหมือนนางฟ้า               красива как ангел
```

**Различия — ต่างกัน.**

```
เราต่างกัน                       мы разные
ความคิดต่างกัน                  взгляды разные
แตกต่างกันมาก                  очень отличаются (усиление через แตก)
```

**Равенство — เท่ากัน, เท่ากับ.**

```
อายุเท่ากัน                     одного возраста (равны)
สูงเท่ากัน                       одного роста
2 + 2 = 4 → สองบวกสองเท่ากับสี่
```

**Поэтические сравнения — ราวกับ, ดุจ.**

Литературные, в песнях и лакорнах:
```
ราวกับฝัน                  как будто сон
ราวกับความจริง            как будто наяву
สวยดุจดอกฟ้า              прекрасна как небесный цветок
ใจอ่อนดุจน้ำ                 сердце мягкое как вода
```

В лакорнах поэтические сравнения — высокий стиль, особенно в исторических и романтических жанрах.

### Якоря

- **กว่า** — основа сравнения «больше чем».
- **ที่สุด** — суперлатив «самый».
- **เหมือนกัน** — одинаковость; **เหมือน / คล้าย** — похожесть.
- **ต่างกัน** — различие; **เท่ากัน** — равенство.
- **ราวกับ / ดุจ** — поэтические сравнения.

### Практические упражнения

**Упражнение 1.** Переведи:
1. Я выше тебя.
