# Глава 5 · Тема 5.2 — Время и аспект

> Цель темы: понимать тайскую систему маркеров времени (язык без флексий), различать **แล้ว / กำลัง / จะ / เคย / ได้**, говорить о прошлом, настоящем и будущем.

---

## Подтема 5.2.1 — Тайский без времён глагола

### Словарный запас

(грамматические термины и базовые маркеры)

| Тайский | Транскрипция | Назначение |
|---|---|---|
| **แล้ว** | лэ́эу | завершённость («уже», «потом») |
| **กำลัง** | кам-ланг | продолжительность («сейчас», «прямо сейчас») |
| **อยู่** | йу̀у | продолжительность («находится в состоянии») |
| **จะ** | джа̀ | будущее, намерение («собираться») |
| **เคย** | кхӧ̄эй | прошлый опыт («бывало») |
| **ได้** | да̂й | завершённость + результат |
| **ยัง** | ян́g | «ещё», в отрицании |

### Теория

**Главный принцип:** в тайском **глагол не изменяется по времени**. «กิน» (есть) — это и «ем», и «ел», и «буду есть». Время указывается:
1. **Контекстом** (когда речь идёт о прошлом, понятно).
2. **Маркерами времени** (เมื่อวาน — вчера, พรุ่งนี้ — завтра).
3. **Специальными частицами аспекта** (แล้ว, กำลัง, จะ).

```
ฉันกินข้าว                    я ем рис / я ел рис / я буду есть рис
ฉันกินข้าวเมื่อเช้า          я ел утром
ฉันกำลังกินข้าว             я (прямо сейчас) ем
ฉันจะกินข้าว                 я буду есть
ฉันกินข้าวแล้ว              я уже поел
```

Тайский **не имеет «времён» как в русском или английском** — но имеет **аспектную систему**: указание на завершённость, длительность, опыт, намерение.

**Это похоже на китайский и японский.** В этих языках тоже нет «времён», а аспект выражается частицами.

**Преимущество для изучающего.**

Тебе **не нужно учить таблицы спряжения**. Один и тот же глагол работает везде. Главное — **владеть маркерами**.

**Структура с маркерами.**

| Маркер | Позиция | Смысл |
|---|---|---|
| **แล้ว** | после глагола | завершено (уже) |
| **กำลัง** | перед глаголом | продолжается (сейчас) |
| **อยู่** | после глагола | состояние пребывания |
| **จะ** | перед глаголом | будущее, намерение |
| **เคย** | перед глаголом | прошлый опыт |
| **ได้** | после глагола | результат, мог |

### Якоря

- Тайский **глагол не меняется по времени**.
- Время указывается **контекстом** и **маркерами аспекта**.
- Маркеры ставятся либо **перед**, либо **после** глагола.

### Практические упражнения

**Упражнение 1.** Один глагол ทำ (делать) — переведи в разных временах:
1. Я делаю.
2. Я делал.
3. Я буду делать.

(Один тайский ทำ, но русский требует разных форм.)

**Упражнение 2.** Какие маркеры нужны?
1. «уже»: ?
2. «прямо сейчас»: ?
3. «бывало»: ?
4. «буду»: ?

**Упражнение 3.** Прочитай и переведи:
1. ฉันทำงาน (без маркеров)
2. ฉันทำงานแล้ว
3. ฉันกำลังทำงาน
4. ฉันจะทำงาน
5. ฉันเคยทำงานที่นี่

**Упражнение 4.** Какой маркер изменит смысл «ฉันรักเธอ»?
1. + แล้ว → ?
2. + กำลัง → ?
3. + จะ → ?
4. + เคย → ?

**Упражнение 5.** Объясни своими словами, в чём принципиальное отличие тайского от русского в выражении времени.

## Подтема 5.2.2 — แล้ว — завершённость

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **แล้ว** | лэ́эу | уже / завершено |
| **เสร็จแล้ว** | сѐт лэ́эу | закончено |
| **กินแล้ว** | кин лэ́эу | поел уже |
| **มาแล้ว** | маа лэ́эу | пришёл уже |
| **ทำแล้ว** | тхам лэ́эу | сделал уже |
| **... ยัง?** | ... ян́g | «...уже или ещё нет?» |
| **ยัง** | ян́g | ещё (не) |
| **ยังไม่ได้** | ян́g ма̂й да̂й | ещё не успел |

### Теория

**Главное значение แล้ว — завершение действия.**

**แล้ว** ставится **после глагола** и означает: «действие совершилось / закончилось».

```
ฉันกินข้าวแล้ว                я уже поела
เขามาแล้ว                     он уже пришёл
ฉันทำการบ้านแล้ว             я уже сделала задание
ฉันรู้แล้ว                       я уже знаю
```

В этом значении **แล้ว близко к русскому «уже»**.

**Двойное значение แล้ว.**

1. **«Уже»** (завершение) — как выше.
2. **«Потом, затем»** (последовательность) — с **ก็** (แล้วก็).

```
ฉันตื่น แล้วก็อาบน้ำ
я просыпаюсь, потом купаюсь
```

Контекст обычно ясно различает.

**Усиление «уже давно» — ... มานานแล้ว.**

Чтобы подчеркнуть, что действие/состояние длится уже долго, добавляют **มานาน** («уже долго») перед แล้ว:
```
ฉันรู้มานานแล้ว        я знаю уже давно
เขาไปมานานแล้ว      он ушёл уже давно
```

Само по себе удвоение แล้ว в тайском не используется.

**Вопрос «уже или ещё нет?» — ... แล้ว ... ยัง.**

```
ทาน(ข้าว)แล้วยัง?              поел уже?
ทำเสร็จแล้วยัง?                закончил уже?
มาถึงแล้วยัง?                    приехал уже?
```

Это **стандартный** вопрос. В лакорнах часто:
- **«กินข้าวแล้วยัง?»** — главная фраза заботы (как ты помнишь).

**Ответ на ... แล้วยัง.**

Положительный:
```
แล้ว           уже
ทานแล้ว       поел уже
เสร็จแล้ว      закончил уже
```

Отрицательный:
```
ยัง             ещё (не)
ยังไม่ได้กิน    ещё не поел
ยังไม่เสร็จ     ещё не закончил
```

**ยัง — «ещё».**

**ยัง** (ян́g) работает как «ещё»:

1. **«Ещё не»** (отрицание завершения):
   ```
   ฉันยังไม่กิน              я ещё не ел
   ยังไม่รู้                    ещё не знаю
   ```

2. **«Ещё (продолжает)»** (состояние длится):
   ```
   ฉันยังรักเธอ              я ещё (всё ещё) тебя люблю
   ยังอยู่ไหม?                всё ещё здесь?
   ```

**В лакорнах:**

«**ฉันยังรักเธอ**» — «я всё ещё тебя люблю» — драматическая декларация (особенно после расставания).
«**ยังไม่หายเศร้า**» — «ещё не пережила грусть».

**Прошедшее с явной завершённостью — แล้ว.**

```
เมื่อวานฉันไปเชียงใหม่      вчера я ездила в Чиангмай
                              (прошлое, но без явного маркера)

เมื่อวานฉันไปเชียงใหม่แล้ว   вчера я уже съездила в Чиангмай
                              (с явной завершённостью)
```

Чаще тайцы **не добавляют แล้ว** к прошедшему, если контекст ясен. Маркеры **เมื่อวาน, เมื่อกี้, ตอนเช้านี้** уже указывают на прошлое.

### Якоря

- **แล้ว** — после глагола, означает «уже» (завершено).
- Двойное значение: «уже» и «потом» (с ก็).
- **... แล้วยัง?** — стандартный вопрос «уже или ещё нет?».
- **ยัง** — «ещё», в отрицании = «ещё не».
- В прошлом **แล้ว часто не нужно**, если есть временной маркер.

### Практические упражнения

**Упражнение 1.** Преобразуй в «уже»:
1. ฉันกินข้าว → ?
2. ฉันทำการบ้าน → ?
3. เขามา → ?
4. ฉันรู้ → ?

**Упражнение 2.** Задай вопрос «уже или ещё нет?»:
1. (поел) → ?
2. (закончил) → ?
3. (пришёл) → ?
4. (понял) → ?

**Упражнение 3.** Ответь отрицательно («ещё не»):
1. กินแล้วยัง? → ?
2. มาถึงแล้วยัง? → ?
3. รู้แล้วยัง? → ?

**Упражнение 4.** Прочитай и переведи:
1. ฉันทำงานเสร็จแล้ว
2. เขาแต่งงานแล้ว
3. ยังไม่ได้กินข้าวเลย
4. ฉันยังรักเธออยู่
5. ทำเสร็จแล้วยัง?

**Упражнение 5.** В лакорной сцене героиня говорит: «**ฉันยังรักเขา**». В каком эмоциональном контексте это могло прозвучать?

## Подтема 5.2.3 — กำลัง...อยู่ — продолжающееся действие

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **กำลัง** | кам-ланг | сейчас (в процессе) |
| **อยู่** | йу̀у | находится (в состоянии) |
| **กำลัง...อยู่** | кам-ланг ... йу̀у | прямо сейчас делает |
| **ตอนนี้** | тон-нии́ | сейчас |
| **เดี๋ยวนี้** | дии̌ау нии́ | прямо сейчас (момент) |

### Теория

**Главный принцип:** для **продолжающегося действия** (русское «делаю», «делает», continuous в английском) используются **กำลัง** и/или **อยู่**.

**Три варианта структуры.**

1. **กำลัง + глагол:**
   ```
   ฉันกำลังกินข้าว           я сейчас ем
   เขากำลังทำงาน             он сейчас работает
   ```

2. **Глагол + อยู่:**
   ```
   ฉันกินข้าวอยู่               я (в процессе) ем
   เขาทำงานอยู่                 он работает (сейчас)
   ```

3. **กำลัง + глагол + อยู่** (часто используется):
   ```
   ฉันกำลังกินข้าวอยู่         я прямо сейчас ем
   เขากำลังทำงานอยู่           он сейчас работает
   ```

Все три варианта **правильные**. Разница тонкая:
- **กำลัง** — акцент на **«сейчас, в этот момент»**.
- **อยู่** — акцент на **«находится в состоянии»**.
- **กำลัง...อยู่** — оба усиления.

В разговорной речи частая комбинация **กำลัง...อยู่** даёт самое чёткое настоящее время.

**Сравни.**

```
ฉันกินข้าว                       я ем (в общем)
ฉันกำลังกินข้าว                  я сейчас ем
ฉันกินข้าวอยู่                    я (в процессе) ем
ฉันกำลังกินข้าวอยู่              я прямо сейчас ем
```

**В лакорнах:**

«**คุณกำลังทำอะไรอยู่?**» — «Ты что (сейчас) делаешь?» — стандартное в телефонных разговорах.

**Отрицание продолжающегося.**

```
ฉันไม่ได้กำลังทำงาน            я не работаю (сейчас)
ฉันไม่ได้ทำงานอยู่              я не нахожусь в процессе работы
```

Часто проще:
```
ฉันไม่ได้ทำงาน                  я не работаю (общее отрицание)
```

**ตอนนี้ vs เดี๋ยวนี้.**

Оба — «сейчас», с оттенками:
- **ตอนนี้** — «в это время» (общее «сейчас», может включать недавнее прошлое и ближайшее будущее).
- **เดี๋ยวนี้** — «прямо в эту минуту» (узкое «сейчас»).

```
ตอนนี้ฉันอยู่ที่บ้าน                сейчас я дома (в этот период)
เดี๋ยวนี้ฉันยังกินอยู่               прямо сейчас я ещё ем
```

**С глаголами состояния.**

С некоторыми глаголами **กำลัง** не нужен, потому что они **сами по себе** обозначают состояние:
- **อยู่** — находиться
- **มี** — иметь
- **เป็น** — являться

```
ฉันอยู่ที่บ้าน              я дома (нахождение, не процесс)
ฉันเป็นครู                  я учитель (статус)
ฉันมีปัญหา                у меня проблема
```

Не нужно говорить «ฉันกำลังอยู่ที่บ้าน» — это излишне.

### Якоря

- **กำลัง + глагол** — сейчас (акцент на момент).
- **Глагол + อยู่** — в процессе (акцент на состояние).
- **กำลัง...อยู่** — комбинация, самое чёткое настоящее.
- С **อยู่, มี, เป็น** маркер **กำลัง** не нужен.

### Практические упражнения

**Упражнение 1.** Образуй продолжающееся действие:
1. ฉันกินข้าว → (сейчас) ?
2. เขาทำงาน → ?
3. ฉันเรียนภาษาไทย → ?
4. แม่ทำกับข้าว → ?

**Упражнение 2.** Переведи:
1. Я сейчас работаю.
2. Я смотрю лакорн.
3. Мама готовит ужин.
4. Что ты сейчас делаешь?
5. Я думаю о тебе (сейчас).

**Упражнение 3.** Прочитай и переведи:
1. ฉันกำลังเรียนภาษาไทยอยู่
2. คุณกำลังทำอะไรอยู่
3. ฝนกำลังตก
4. ฉันคิดถึงเธออยู่
5. เธอกำลังร้องไห้

**Упражнение 4.** Найди ошибку:
1. ฉันกำลังเป็นครู
2. ฉันกำลังมีหมา
3. ฉันกำลังกินข้าว
4. ฉันกำลังอยู่บ้าน

**Упражнение 5.** Опиши, что ты делаешь прямо сейчас — 3-5 предложений с использованием **กำลัง / อยู่**.

## Подтема 5.2.4 — จะ — будущее и намерение

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **จะ** | джа̀ | буду, собираюсь |
| **กำลังจะ** | кам-ланг джа̀ | собираюсь прямо сейчас, вот-вот |
| **ใกล้จะ** | кла̂й джа̀ | скоро (вот-вот) |
| **เดี๋ยว** | дии̌ау | подожди / сейчас (= скоро) |
| **อีกสักครู่** | ѝик са̀к кхру̂у | через минутку |
| **พรุ่งนี้** | пхрунг-нии́ | завтра |
| **อาทิตย์หน้า** | аа-тхи́т на̂а | на следующей неделе |
| **ปีหน้า** | пии на̂а | в следующем году |
| **ในอนาคต** | най а̀-наа-кхо́т | в будущем |
| **คงจะ** | кхонг джа̀ | вероятно, наверное |

### Теория

**Главный принцип:** для **будущего и намерения** используется маркер **จะ** перед глаголом.

```
ฉันจะไป               я пойду / я собираюсь идти
ฉันจะกินข้าว           я буду есть
ฉันจะรัก                я буду любить
```

**จะ — универсальный маркер будущего и намерения.**

В отличие от русского, где есть отдельные формы (буду + инфинитив, или совершенный вид), тайский использует **одну частицу** для всех типов будущего.

**Типы будущего, передаваемые через จะ.**

1. **Простое будущее:**
   ```
   พรุ่งนี้ฉันจะไปทำงาน          завтра я пойду на работу
   ปีหน้าฉันจะเรียนต่อ          в следующем году буду учиться дальше
   ```

2. **Намерение / план:**
   ```
   ฉันจะแต่งงานกับเขา           я выйду за него замуж
   เราจะไปเที่ยวด้วยกัน         мы поедем в путешествие вместе
   ```

3. **Обещание:**
   ```
   ฉันจะไม่ลืม                     я не забуду
   ฉันจะรอเธอ                     я буду тебя ждать
   ฉันจะอยู่กับเธอตลอดไป       я буду с тобой всегда
   ```

4. **Прогноз / предположение:**
   ```
   ฝนคงจะตกเย็นนี้                наверное, вечером пойдёт дождь
   เขาคงจะรู้แล้ว                  он, наверное, уже знает
   ```

**กำลังจะ — «вот-вот» / «прямо сейчас собираюсь».**

```
ฉันกำลังจะไป                    я как раз собираюсь идти
ฝนกำลังจะตก                    дождь вот-вот начнётся
เขากำลังจะมา                    он уже едет
```

В лакорнах **«กำลังจะ...»** часто создаёт **напряжение момента**:
- «**เขากำลังจะรู้ความจริง**» — «он вот-вот узнает правду».
- «**ฉันกำลังจะตาย**» — «я вот-вот умру» (часто в драматических сценах болезни).

**ใกล้จะ — «скоро».**

```
ใกล้จะถึงแล้ว              скоро уже приедем
ใกล้จะสว่าง                 скоро рассветёт
ใกล้จะปีใหม่                 скоро Новый год
```

Чуть менее интенсивно, чем กำลังจะ — больше про **близкое будущее**, а не «прямо сейчас».

**Близкое будущее без จะ.**

В разговорной речи иногда **จะ опускают**, если из контекста ясно:
```
ไปกินข้าวกันไหม          пойдём поедим? (нет จะ, но смысл будущий)
รอเดี๋ยวนะ                   подожди-ка (нет จะ, но действие будущее)
```

В формальной речи или для **подчёркивания будущего** — จะ обязательно.

**Отрицание будущего.**

```
ฉันจะไม่ไป               я не пойду
จะไม่ลืม                   не забуду
จะไม่ทิ้งเธอ               не брошу тебя
```

Структура: **จะ + ไม่ + глагол**.

В лакорнах **«ฉันจะไม่ทิ้งเธอ»** — типичная клятва.

**Вопросы о будущем.**

```
จะไปไหม?                   пойдёшь?
พรุ่งนี้จะทำอะไร?            что будешь делать завтра?
เมื่อไหร่จะกลับ?              когда вернёшься?
```

### Якоря

- **จะ + глагол** — будущее и намерение (универсально).
- **กำลังจะ** — «вот-вот», «как раз собираюсь».
- **ใกล้จะ** — скоро.
- **คงจะ** — вероятно (с прогнозом).
- В разговорной речи **จะ можно опустить**, если контекст ясен.

### Практические упражнения

**Упражнение 1.** Образуй будущее:
1. ฉันไป → ?
2. ฉันกินข้าว → ?
3. ฉันรักเธอ → ?
4. ฉันทำงาน → ?

**Упражнение 2.** Переведи:
1. Я пойду домой.
2. Я буду тебя ждать.
3. Я не забуду тебя.
4. Скоро я приеду.
5. Дождь вот-вот пойдёт.

**Упражнение 3.** Прочитай и переведи:
1. พรุ่งนี้ฉันจะไปกรุงเทพ
2. ฉันจะรักเธอเสมอ
3. เขาคงจะมาช้า
4. กำลังจะถึงแล้ว
5. ปีหน้าจะแต่งงาน

**Упражнение 4.** Найди разницу в оттенках:
1. ฝนตก
2. ฝนกำลังตก
3. ฝนกำลังจะตก
4. ฝนจะตก

## Резюме по теме

К концу темы ты должна уметь:

- ✅ Понимать, что тайский **глагол не меняется по времени**
- ✅ Использовать **แล้ว** для завершения действия
- ✅ Использовать **กำลัง / อยู่ / กำลัง...อยู่** для продолжающегося действия
- ✅ Использовать **จะ** для будущего и намерения
- ✅ Различать **กำลังจะ** (вот-вот) и **ใกล้จะ** (скоро)
- ✅ Применять **ยัง / ยังไม่** для «ещё / ещё не»
- ✅ Знать связку **... แล้วยัง?** для вопроса о завершении
- ✅ Использовать **เคย** для прошлого опыта (уже знала по главам 3 и 4)
