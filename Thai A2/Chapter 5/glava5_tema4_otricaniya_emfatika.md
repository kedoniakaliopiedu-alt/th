# Глава 5 · Тема 5.4 — Отрицания и эмфатика

> Цель темы: понимать тонкости отрицания (что куда ставится), узнавать конечные частицы (สิ, นะ, ละ, อะ, จัง) и слышать эмоциональные оттенки в речи героев лакорнов.

---

## Подтема 5.4.1 — Тонкости отрицания

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **ไม่** | ма̂й | базовое отрицание |
| **ไม่ใช่** | ма̂й чха̂й | не есть, не верно |
| **ไม่ค่อย** | ма̂й кхо̂й | не очень, редко |
| **ไม่ได้** | ма̂й да̂й | не получилось / не могу |
| **ไม่เคย** | ма̂й кхӧ̄эй | никогда не |
| **ไม่...เลย** | ма̂й ... лӧ̄эй | вообще не |
| **ไม่...นัก** | ма̂й ... на́к | не очень-то (книжное) |
| **มิ** | ми | литературное «не» |
| **เปล่า** | плàу | нет (отрицание-констатация) |
| **หาไม่ใช่** | ха̌а ма̂й чха̂й | вовсе не (формальное усиление) |

### Теория

**Систематика тайских отрицаний.**

Главное отрицание — **ไม่**. Дополнительные конструкции дают **оттенки**:

| Конструкция | Сила | Использование |
|---|---|---|
| **ไม่** | базовая | стандартное отрицание |
| **ไม่ค่อย** | слабая | смягчение, «не очень» |
| **ไม่...เลย** | сильная | «вообще не», усиление |
| **ไม่เคย** | абсолютная | «никогда» |
| **ไม่...นัก** | книжная | «не очень-то» (формально) |
| **มิ** | литературная | в стихах, в старых текстах |

### Позиция ไม่ — ключевая

**ไม่** ставится **прямо перед глаголом/прилагательным**:

```
ไม่ + กิน               не ем
ไม่ + ไป                не иду
ไม่ + รัก                не люблю
ไม่ + สวย                не красивая
```

Если в группе несколько глаголов (модальный + основной) — отрицание ставится **в нужное место** в зависимости от того, **что отрицается**:

```
อยาก + ไป → อยากไป (хочу пойти)
ไม่ + อยากไป → ไม่อยากไป (не хочу пойти) — отрицается само хотение
```

```
จะ + ไป → จะไป (пойду)
จะ + ไม่ + ไป → จะไม่ไป (не пойду) — отрицается действие в будущем
```

```
ต้อง + ไป → ต้องไป (нужно пойти)
ไม่ต้อง + ไป → ไม่ต้องไป (не нужно идти) — отрицание обязательства
ต้อง + ไม่ + ไป → ต้องไม่ไป (нужно не идти) — обязательство не идти
```

⚠️ **Меняя позицию ไม่, ты меняешь смысл**. Сравни ещё раз:
- **ไม่ต้องไป** — нет обязательства идти.
- **ต้องไม่ไป** — обязательство не идти.

В лакорнах разница может быть драматической:
- Подруга: «**ไม่ต้องไป**» — «не надо ходить» (твоё право решить).
- Свекровь: «**ต้องไม่ไป**» — «нельзя идти» (запрет).

### ไม่ค่อย — мягкое смягчение

```
ไม่ค่อยชอบ                      не очень-то нравится
ไม่ค่อยรู้                         не очень знаю
ไม่ค่อยสบาย                     не очень хорошо себя чувствую
```

В тайской культуре **ไม่ค่อย** — это **вежливый способ сказать «нет»**. Прямо говорить «нет» считается слишком резким, особенно к старшим или незнакомым. **ไม่ค่อย** даёт мягкость.

```
А: คุณชอบไหม?       (вам нравится?)
Б: ไม่ค่อย              (не очень) — мягче, чем «ไม่ชอบ»
```

### ไม่...เลย — усиление

```
ไม่หิวเลย                        совсем не голодная
ไม่เข้าใจเลย                     совершенно не понимаю
ไม่รู้เลย                          вообще не знаю
ไม่อยากเลย                      совсем не хочу
```

**เลย** ставится **после** глагола/прилагательного с отрицанием. В лакорнах драматичное:
- «**ฉันไม่รักเขาเลย**» — «я его совсем не люблю».
- «**ไม่เคยลืมเลย**» — «никогда не забуду» (даже секунды не было забвения).

### ไม่เคย — «никогда»

```
ฉันไม่เคยไปไทย                     я никогда не была в Таиланде
ไม่เคยรัก                            никогда не любила
ไม่เคยเห็น                           никогда не видела
```

**ไม่เคย + เลย** — двойное усиление:
- **«ไม่เคยลืมเลย»** — «совсем никогда не забывала».

### ไม่...นัก — «не очень-то» (книжно)

Формальная альтернатива **ไม่ค่อย**:
```
ไม่สวยนัก                          не очень-то красивая
ไม่ดีนัก                             не особенно хорошо
```

Слышишь в литературе, в новостях, в формальных монологах. В разговоре — редко.

### มิ — литературное «не»

В **песнях, стихах, исторических лакорнах**:
```
มิอาจ                          не могу (литературно)
มิเคย                          никогда (литературно)
มิรู้                            не знаю (литературно)
```

Заменяет **ไม่** в высоком стиле. В современной разговорной речи **มิ** **не используется**.

### เปล่า — «нет» (опять)

Как ты уже знаешь — самостоятельное «нет», часто в ответе на вопрос с **รึเปล่า**:
```
А: ไปไหม?
Б: เปล่า                       нет

ไม่ใช่ เปล่า                  «не, нет» (двойное отрицание для усиления)
```

### Двойное отрицание

В отличие от русского, где «никто не пришёл» — норма, в тайском **двойное отрицание встречается реже**:

```
ไม่มีใครรู้                          никто не знает (буквально «не имеется кто знает»)
ไม่มีอะไรเลย                       совсем ничего
ไม่เคยเห็นใครเลย                  никогда никого не видел
```

Здесь **ไม่** + неопределённое местоимение (ใคร — кто-то / кто, อะไร — что-то / что) даёт значение «никто / ничего».

### Якоря

- **ไม่** ставится **прямо перед** глаголом / прилагательным.
- **Позиция ไม่ меняет смысл** (ไม่ต้องไป vs ต้องไม่ไป).
- **ไม่ค่อย** — вежливое смягчение.
- **ไม่...เลย** — усиление.
- **ไม่เคย** — никогда.
- **มิ** — литературное «не», в песнях и исторических текстах.
- **ไม่ + неопределённое** = «ни...»

### Практические упражнения

**Упражнение 1.** Объясни разницу:
1. ไม่ต้องไป vs ต้องไม่ไป
2. ไม่อยากกิน vs อยากไม่กิน (если такое возможно?)
3. ไม่เคยลืม vs ลืมไม่เคย

**Упражнение 2.** Преврати в смягчённое отрицание:
1. ฉันไม่ชอบ → ?
2. ฉันไม่รู้ → ?
3. ฉันไม่สบาย → ?

**Упражнение 3.** Усиль отрицание через ...เลย:
1. ฉันไม่รัก → ?
2. ฉันไม่เข้าใจ → ?
3. ฉันไม่อยาก → ?

**Упражнение 4.** Переведи:
1. Никто не знает.
2. Совсем ничего.
3. Я никогда не любила его.
4. Не нужно идти.
5. Нельзя идти.

**Упражнение 5.** Прочитай и переведи:
1. ฉันไม่ค่อยหิว
2. ไม่มีใครเข้าใจฉัน
3. ฉันไม่เคยลืมเลย
4. คุณไม่ต้องห่วง
5. คุณต้องไม่บอกใคร

## Подтема 5.4.2 — Конечные частицы — สิ / นะ / ละ / อะ

### Словарный запас

| Тайский | Транскрипция | Эффект |
|---|---|---|
| **สิ** | сѝ | побуждение, утверждение |
| **นะ** | на́ | смягчение, мягкая просьба |
| **ละ / ล่ะ** | ла́ / ла̂ | переключение темы, «а ты?» |
| **อะ / อ่ะ / อ้ะ** | а̀ / а́ | заполнитель, разговорный «вот» |
| **เถอะ** | тхӧ̀ | побуждение «давай» |
| **ซิ** | сѝ | вариант สิ |
| **เนอะ** | нӧ́ | подтверждение «верно?» |
| **โว้ย / ว้อย** | уоойй | грубо-неформально «эй» (м.) |
| **เฮ้ย** | хээй | «эй» (нейтрально) |
| **ฮะ** | ха | редуцированная ค่ะ |
| **เถ้ย / โว้ย** | (см. выше) | мужские маркеры в речи |

### Теория

**Главный принцип:** в тайском **конечные частицы** — это **не «слова»**, а **тональные маркеры эмоций**. Они не переводятся прямо, но **окрашивают всё предложение**.

Опытный тайский слушатель из частицы понимает:
- настроение говорящего;
- его отношение к собеседнику;
- регистр (формальное / неформальное);
- иногда даже пол.

### สิ — «давай», утверждение

**สิ** усиливает побуждение или утверждение:

```
ไปสิ                              иди же
บอกฉันสิ                         расскажи мне же
ฉันบอกแล้วสิ                   я же сказал
อย่าซะอย่างนั้นสิ                ну не так же
```

В лакорнах **สิ** часто — друг подруге:
- «**ไปเที่ยวกันสิ!**» — «давай развлечёмся!»
- «**บอกความจริงสิ!**» — «скажи же правду!»

### นะ — смягчение

**นะ** — самая частая частица в лакорнах. Делает фразу **мягче, теплее, эмоциональнее**:

```
รักนะ                              люблю, ладно?
คิดถึงนะ                            скучаю, ладно?
อย่าลืมนะ                          не забудь, ладно?
ไปก่อนนะ                          пойду уже, ладно?
ขอบคุณนะ                          спасибо, ладно?
```

**นะ** не значит «ладно» в прямом смысле — но создаёт **эмоциональную связь**: «я говорю это **тебе**, и хочу, чтобы ты услышал/услышала».

В романтических сценах **นะ** — практически обязательно:
- **«ที่รัก ฉันจะรอนะ»** — «дорогой, я буду ждать».

### ละ / ล่ะ — переключение темы

**ละ** (ла́) или **ล่ะ** (ла̂) — частица, означающая «**а ...?**», «**а как же ...?**»:

```
ฉันสบายดี คุณล่ะ?                  у меня всё хорошо. А ты?
แล้วเขาล่ะ?                            а он?
แล้วฉันล่ะ?                             а как же я?
```

В лакорнах **«แล้วฉันล่ะ?»** — драматическая реплика обиженной героини: «А как же я?!»

### อะ / อ่ะ — заполнитель

**อะ** (а̀) — разговорная «пауза», ничего не значит лексически, но смягчает:
```
ก็อ่ะ                                   ну вот
นั่นอ่ะ                                 ну то
ฉันอ่ะ                                  ну я (= это я хотела сказать)
```

В чатах часто:
- «**คือว่าอ่ะ**» — «ну, это, как сказать»...
- «**ก็อ่ะ**» — «ну да»...

### เถอะ — побуждение «давай»

Уже знакомая частица:
```
ไปเถอะ                              пойдём же
ลืมเถอะ                              забудь уже
นอนเถอะ                              ложись уже
```

Отличие от **สิ**: **เถอะ** мягче, чаще про «уже пора», **สิ** — более активное побуждение.

### เนอะ — «верно?», подтверждение

**เนอะ** (нӧ́) — поиск согласия:
```
สวยเนอะ                              красиво, правда?
อร่อยเนอะ                              вкусно, правда?
หิวเนอะ                                голодные, да?
```

В лакорнах часто — между подругами в милых разговорах.

### ฮะ — редуцированное ค่ะ

```
ค่ะ → ฮะ                              в быстрой разговорной речи
```

Используется в чатах, неформальной речи. Это **не отдельная частица**, а **разговорный вариант** ค่ะ. Смысл тот же — вежливость в женской речи.

### Мужские частицы

**โว้ย / ว้อย** (уоойй) — мужское разговорное «эй» в конце:
```
ไปกันเถอะโว้ย                       пошли, чувак!
อะไรว้อย                                чё это, а?
```

Звучит **грубовато**, среди близких мужчин-приятелей. К незнакомому — оскорбительно. В лакорнах — речь грубых, простонародных персонажей.

**เฮ้ย** (хээй) — более нейтральное «эй»:
```
เฮ้ย หยุดก่อน                         эй, стой
เฮ้ย ใครอ่ะ                              эй, кто это?
```

### Эмоциональные удлинения

Часто частицы удлиняют для эмоции:
```
นะ → นะคะ → น้าาา           (растяжка для нежности)
ค่ะ → ค้ะะะ                       (растяжка для просьбы)
ครับ → คร้าบบบ                  (растяжка от мужского усилия)
```

В лакорнах слышишь эти удлинения **постоянно** — это эмоциональная сигнатура персонажа.

### Якоря

- **สิ** — побуждение, «давай!».
- **นะ** — смягчение, эмоциональная связь.
- **ละ / ล่ะ** — «а ты? а как же?».
- **อะ / อ่ะ** — заполнитель, ничего не значит.
- **เถอะ** — мягкое «давай уже».
- **เนอะ** — «верно?», ищет согласия.
- **ฮะ** — разговорная ค่ะ.
- **โว้ย / เฮ้ย** — мужские «эй».

### Практические упражнения

**Упражнение 1.** Какую частицу добавить?
1. Иди же (друг другу) → ไป + ?
2. Спасибо, ладно? → ขอบคุณ + ?
3. А как же я? → แล้วฉัน + ?
4. Вкусно, правда? → อร่อย + ?
5. Ложись уже → นอน + ?

**Упражнение 2.** Переведи, добавляя нужную частицу:
1. Не забудь, ладно?
2. Скажи же правду!
3. Идём же.
4. Красиво, правда?
5. А ты? (как ты?)

**Упражнение 3.** Прочитай и опиши эмоцию:
1. รักนะ
2. รักสิ
3. รักเถอะ
4. รักล่ะ
5. รักเนอะ

**Упражнение 4.** В каком регистре говорит каждый?
1. ไปกันเถอะโว้ย → ?
2. ไปด้วยกันนะคะ → ?
3. ไปไหนอ่ะ → ?
4. กรุณาไป → ?

**Упражнение 5.** В лакорнах слышишь героиню: «**คิดถึงน้าาาา**» (с растяжкой). Что это говорит о ней и контексте?

## Подтема 5.4.3 — Эмоциональные междометия

### Словарный запас

| Тайский | Транскрипция | Эмоция |
|---|---|---|
| **โอ้โห** | оо̂-хо̌о | удивление, «вау» |
| **อ้อ** | о̂о | «а, понятно» |
| **เอ๊ะ** | э́э | удивление «хм?» |
| **อุ๊ย** | у́й | боль, неожиданность («ой!») |
| **โธ่** | тхо̂о | сочувствие, разочарование «ох» |
| **โอย** | оой | физическая боль |
| **อ๊ะ** | а́ | мягкое восклицание |
| **เฮ้อ** | хё̂о | вздох усталости |
| **แหม** | мээ | удивление-восторг |
| **โอ๊ย** | о́й | боль, шутливое возмущение |
| **แม่เจ้า** | мэ̂э джâу | удивление (через «матерь!») |
| **พระเจ้า** | пхра́ джâу | удивление, шок (через «Бог!») |
| **พุทโธ่** | пхут́-тхо̂о | мягкое удивление, ласковое осуждение |
| **คุณพระ** | кхун пхра́ | глубокое удивление |
| **ตายแล้ว** | таай лэ́эу | «о боже мой!», шок (буквально «умер») |

### Теория

**Главный принцип:** в тайском **много междометий**, и они **различаются по интенсивности и регистру**. В лакорнах это — основные эмоциональные маркеры героев.

### Базовые реакции

**โอ้โห** (оо̂-хо̌о) — «вау, ничего себе»:
```
โอ้โห สวยมาก!                   вау, очень красиво!
โอ้โห แพงจัง                       ого, дорого
```

**อ้อ** (о̂о) — «а, понял/-а»:
```
อ้อ เข้าใจแล้ว                     а, понятно
อ้อ ใช่ๆ                              а, да-да
```

**เอ๊ะ** (э́э) — «хм?», лёгкое сомнение:
```
เอ๊ะ ทำไม?                          хм, почему?
เอ๊ะ จริงเหรอ                       хм, правда?
```

### Восклицания удивления

В лакорнах самые драматичные:

**ตายแล้ว** (таай лэ́эу — «умер уже») — «о боже мой!»:
```
ตายแล้ว ลืมเอกสาร              о боже, забыла документы!
ตายแล้ว ทำไงดี                   о боже, что делать?
```

Это не про смерть — это **сильное восклицание** шока, как русское «о Господи!». Используется и женщинами, и мужчинами.

**แม่เจ้า** (мэ̂э джâу — «матерь!») — выражение удивления:
```
แม่เจ้า สวยจัง!                     матерь моя, какая красивая!
แม่เจ้า ใหญ่ขนาดนี้                 ой мама, такой большой!
```

**พระเจ้า** (пхра́ джâу — «Бог!») — буддистское восклицание (от санскритского «господин»):
```
พระเจ้า ช่วย!                       Господи, помоги!
พระเจ้า อะไรเนี่ย                    Боже, что это?!
```

**พุทโธ่** (пхут́-тхо̂о — от Будды) — мягкое:
```
พุทโธ่ น่าสงสาร                       ох, бедненький
พุทโธ่ ทำไงดี                          ох, что же делать
```

В лакорнах **พุทโธ่** часто звучит от старшей женщины (мама, бабушка) с **сочувствием и лёгким осуждением одновременно**.

**คุณพระ** (кхун пхра́ — «господин Будда») — глубокое удивление:
```
คุณพระช่วย!                           «Господи помоги!»
คุณพระคุณเจ้า                        восклицание шока
```

### Боль и дискомфорт

**โอย / โอ๊ย** — физическая или эмоциональная боль:
```
โอย เจ็บ                                ой, больно!
โอ๊ย หิวมาก                              ой, я голодная!
```

**อุ๊ย** — лёгкая неожиданность / боль:
```
อุ๊ย ลืม                                  ой, забыла
อุ๊ย ทำตกแล้ว                          ой, уронила!
```

### Усталость / вздохи

**เฮ้อ** — вздох:
```
เฮ้อ เหนื่อยจัง                          эх, как устала
เฮ้อ ปัญหาเยอะ                        эх, проблем много
```

**โธ่** — разочарованный вздох:
```
โธ่ น่าเสียดาย                         ох, какая жалость
โธ่ ทำไมไม่บอก                       эх, ну почему не сказал
```

### Восторг

**แหม** — лёгкий восторг:
```
แหม น่ารักจัง                          ой, какой милый!
แหม สวยจริงๆ                          ах, правда красивая!
```

### В лакорнах

Эмоциональные междометия — **главный звуковой ландшафт** лакорнов. По ним зритель ориентируется быстрее, чем по словам:

- **«ตายแล้ว!»** в начале сцены — что-то произошло.
- **«โธ่...»** — герой грустит.
- **«แหม!»** — комплимент или удивление с долей сарказма.
- **«พุทโธ่...»** — мать сокрушается над взрослым ребёнком.

Эти междометия **повторяются**: «ตายแล้ว ตายแล้ว» — «о боже, о боже!» — усиление шока.

### Якоря

- Тайские междометия **различаются по силе и регистру**.
- **ตายแล้ว** — главное «о боже».
- **พุทโธ่ / พระเจ้า / คุณพระ** — буддистские восклицания.
- **โธ่** — вздох разочарования.
- **แม่เจ้า** — «матерь моя!».
- **โอ๊ย / โอย** — боль или эмоциональная разрядка.

## Подтема 5.4.4 — Эмфатика «-จัง»

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **จัง** | джанг | очень, как-то (эмфатическая) |
| **เลย** | лӧ̄эй | совсем, вообще |
| **มากๆ** | маа̂к маа̂к | очень-очень |
| **ที่สุด** | тхии-су̀т | самый |
| **ขนาดนี้** | кха̀нàат нии́ | до такой степени |
| **เหลือเกิน** | лы̌а-кы̄ан | чрезвычайно |
| **ยังไงดี** | йанг-нгай дии | как же |
| **โคตร** | кхо̂оот | супер, очень (сленг, грубовато) |
| **สุดๆ** | су̀т су̀т | до предела |

### Теория

**Главный принцип:** для **эмфатической оценки** (эмоциональной реакции на что-то) тайский имеет специальную частицу **จัง** и несколько усилителей. Это **разговорная эмоциональность**.

### จัง — эмфатическая частица

**จัง** (джанг) ставится **после** прилагательного / глагола и означает **«как / так / очень»** с эмоциональным восхищением или удивлением:

```
สวยจัง                            какая красивая!
อร่อยจัง                            как вкусно!
น่ารักจัง                          какой милый!
หิวจัง                              как я голодная!
เหนื่อยจัง                         как устала!
```

Это **разговорная эмоциональность**. Аналог русского «как же...!», «такой...!», «какой/какая...!».

В лакорнах **จัง** — постоянное:
- **«คิดถึงจัง»** — «как я скучаю!»
- **«รักจัง»** — «как же люблю!»
- **«เขินจัง!»** — «как смущаюсь!»

**จัง vs มาก — различие.**

- **มาก** — «очень» (количественное усиление).
- **จัง** — «как же / такой» (эмоциональное восклицание).

```
สวยมาก                            очень красивая (констатация)
สวยจัง                              какая красивая! (восклицание)
สวยมากเลย                       очень-очень красивая
สวยจังเลย                          такая прям красивая!
```

**จัง** добавляет **эмоциональный возглас**, **มาก** — нейтральное усиление.

### เลย — «совсем, аж»

Усиливает чувство:
```
ดีเลย                                  отлично прямо
สวยเลย                               прям красиво
ชอบเลย                              сразу понравилось
ไม่รู้เลย                              вообще не знаю
```

В сочетании с **จัง**:
```
สวยจังเลย                           ой как красиво!
```

### ขนาดนี้ — «до такой степени»

```
รักขนาดนี้                          любить до такой степени
สวยขนาดนี้                         красивая до такой степени
ปวดขนาดนี้                         больно до такой степени
```

В лакорнах эмоциональное:
- **«รักขนาดนี้แล้ว ทำไมไม่บอก?»** — «любя до такой степени, почему не сказал?»

### เหลือเกิน — «чрезвычайно»

Литературное, чуть более книжное усиление:
```
ดีเหลือเกิน                          чрезвычайно хорошо
รักเหลือเกิน                        безмерно люблю
ลำบากเหลือเกิน                  страшно тяжело
```

В лакорнах звучит в **эмоциональных монологах**: «**ฉันคิดถึงเขาเหลือเกิน**» — «я ужасно по нему скучаю».

### สุดๆ — «до предела»

Молодёжный, разговорный:
```
สวยสุดๆ                              красотища
อร่อยสุดๆ                            вкуснотища
ฮาสุดๆ                                умора (буквально «смешно до предела»)
```

### โคตร — сленговое «супер»

**โคตร** (кхо̂оот) — **грубовато-разговорное** «супер», «очень». В лакорнах слышишь от молодых, неформальных персонажей. С аристократами и старшими — неуместно:

```
โคตรสวย                           очень красивая (грубовато)
โคตรอร่อย                          уж очень вкусно
```

К незнакомым / в формальных контекстах **โคตร** не использовать.

### ที่สุด — «самый»

Уже знакомое:
```
สวยที่สุด                              самая красивая
รักที่สุด                                больше всего люблю
ดีที่สุดในโลก                       лучший в мире
```

### Якоря

- **จัง** — эмоциональное «как же!» (после прилагательного).
- **จัง ≠ มาก** — джанг даёт восклицание, маа̂к — констатацию.
- **เลย** усиливает чувство, часто комбинируется с **จัง**.
- **ขนาดนี้** — «до такой степени» (эмоциональное).
- **เหลือเกิน** — книжное «чрезвычайно».
- **สุดๆ** — молодёжное «до предела».
- **โคตร** — сленговое, грубовато.

**Упражнение 1.** Добавь эмфазу через จัง:
