### Теория

**Главный принцип:** в тайской культуре **рис — центр трапезы**. Все блюда — это «**กับข้าว**» («то, что с рисом»). Это структурно влияет на язык.

**Структура порции.**

В тайской еде есть два основных формата:
1. **ข้าวราด** (кха̂ау ра̂ат, «рис залитый») — одна тарелка: рис + блюдо сверху. Это обед на бегу, на улице. Стоит 50-80 бат.
2. **กับข้าว** (ка̀п кха̂ау, «с рисом») — большая трапеза: рис отдельно, несколько блюд для дележки. Это домашний или семейный формат.

**ผัดกะเพรา** — национальный фастфуд.

**ผัดกะเพรา** (пха̀т ка̀ пхрау) — стир-фрай с базиликом и мясом — самое популярное «быстрое блюдо». Заказывается как **ข้าวกะเพรา** (рис с гапрао):
- **ข้าวกะเพราหมู** — рис с гапрао свининой
- **ข้าวกะเพราไก่ไข่ดาว** — рис с гапрао курицей и яичницей-глазуньей

В лакорнах герой одного из персонажей часто заказывает гапрао в офисном кафе — это маркер обычного, простого человека.

**ส้มตำ — северо-восток.**

**ส้มตำ** (со̂м там) — салат из недозрелой папайи. Острый, кислый, солёный — одновременно. Происходит из **อีสาน** (исаана, северо-востока). В лакорнах часто:
- Героиня из деревни заказывает сом-там → маркер региональной идентичности.
- Аристократка пробует впервые → шок от остроты.

**Степени остроты (важное!).**

Когда заказываешь сом-там или другое острое блюдо, **обязательно укажи уровень**:
```
ไม่เผ็ด                     не острое
เผ็ดน้อย                  чуть-чуть острое
เผ็ดปานกลาง          средне-острое
เผ็ดมาก                   очень острое
เผ็ดสุดๆ                   супер-острое
```

Без уточнения тебе принесут **по-тайски острое** — для непривычного европейца обычно невыносимо. Лакорная сцена: западный жених пробует тайское блюдо → слёзы, паника, восторг.

**Структура «блюдо + что-то».**

```
ข้าวผัด + ингредиент
ข้าวผัดไก่                    жареный рис с курицей
ข้าวผัดหมู                    жареный рис со свининой
ข้าวผัดกุ้ง                    жареный рис с креветками

ก๋วยเตี๋ยว + тип
ก๋วยเตี๋ยวน้ำ                  суп с лапшой («лапша с водой»)
ก๋วยเตี๋ยวแห้ง                 сухая лапша (без бульона)

แกง + цвет/тип
แกงเขียวหวาน               зелёное (сладкое)
แกงแดง                       красное
แกงเหลือง                    жёлтое
```

**ข้าวเหนียวมะม่วง — десерт-классик.**

**ข้าวเหนียวมะม่วง** (кха̂ау ни̌иау ма́-муа̂ң) — клейкий рис с манго и кокосовым молоком. Главный сладкий десерт страны, особенно популярен в сезон манго (март-май). В лакорнах часто романтическая сцена: пара ест ข้าวเหนียวมะม่วง.

**Тайский чай (ชาเย็น).**

Оранжевый/коричневый, с молоком, со льдом, очень сладкий — это **ชาเย็น**. Не путать с обычным горячим чаем (**ชาร้อน**). Уличный продукт, повсеместный.

### Якоря

- **ข้าว** — центр трапезы.
- **ข้าวราด** (тарелка) vs **กับข้าว** (семейный формат).
- **ผัดกะเพรา** — национальный фастфуд.
- **ส้มตำ** — салат из папайи, маркер региона.
- **Степени остроты** обязательны при заказе.

## Подтема 6.1.2 — Заказ в ресторане

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **เมนู** | мӭӭ-нуу | меню |
| **สั่ง** | са̀ң | заказать |
| **ขอ** | кхо̌о | попросить |
| **อะไรอร่อย** | а-рай а̀-ро̀й | что вкусное? |
| **มีอะไรบ้าง** | мии а-рай ба̂аң | что есть? |
| **แนะนำ** | нэ́э-нам | посоветовать |
| **อยากกิน** | йа̀ак гин | хотеть есть |
| **เอา** | ау | возьму |
| **จาน** | дьзаан | тарелка |
| **ที่** | тьхи̂и | порция |
| **อีก** | ѝик | ещё |
| **เพิ่ม** | пхӧ̂ӧм | добавить |
| **โต๊ะ** | тȯ́ | стол |
| **ที่นั่ง** | тьхи̂и на̂ң | место |
| **บริการ** | боо-ри́-гаан | обслуживание |
| **พนักงาน** | пха́-на́к-ңаан | сотрудник, официант |
| **คุณ / พี่** | кхун / пхи̂и | вы / старший (для официанта) |

### Теория

**Вход в ресторан.**

Стандартный диалог:
```
А (хост): สวัสดีค่ะ กี่ท่านคะ        здравствуйте, сколько человек?
Б: สองคนค่ะ                            двое
А: เชิญทางนี้ค่ะ                       пожалуйста, сюда
```

**ท่าน** (тьха̂ан) — уважительное «человек/гость», используется ресторанным персоналом. **คน** — нейтральное «человек», его тоже услышишь.

**Просьба о меню.**

```
ขอเมนูหน่อยค่ะ                      меню, пожалуйста
ขอเมนูภาษาอังกฤษได้ไหม          можно меню на аңлийском?
มีเมนูรูปภาพไหม                       есть ли меню с картинками?
```

**Спросить о блюде.**

```
อันนี้คืออะไรคะ                     что это?
อันนี้มีอะไรอยู่บ้าง                  что в этом блюде?
มีเนื้ออะไรบ้าง                       какое мясо есть?
อร่อยไหม                              вкусно?
แนะนำอะไรดี                         что посоветуете?
```

**Сделать заказ.**

Стандартный шаблон:
```
ขอ + [блюдо] + [количество] + [счётное] + ค่ะ/ครับ
```

```
ขอข้าวผัดไก่ที่หนึ่งค่ะ              рис с курицей одну порцию
ขอน้ำเปล่าสองขวด                  воды две бутылки
ขอเบียร์สามแก้ว                    пива три стакана
```

**Особые просьбы.**

```
ไม่ใส่ผัก                              без овощей
ไม่ใส่ผงชูรส                         без MSG (глутамата)
ไม่เผ็ด                                не острое
เผ็ดน้อย                              чуть острое
ไม่หวาน                              несладкое
ไม่ใส่น้ำตาล                         без сахара
```

В лакорнах сцены в ресторане часто содержат:
- **«ไม่เผ็ดนะคะ»** — героиня осторожничает.
- **«เผ็ดสุดๆ»** — герой соревнуется (показывает мужественность через переносимость остроты).

**Дополнения и добавки.**

```
ขออีกหน่อย                          ещё немножко
ขออีกจานนึง                         ещё одну порцию
เพิ่มข้าวอีกหน่อย                   рис добавьте
ขอน้ำเพิ่มได้ไหม                  можно ещё воды?
```

**Обращение к официанту.**

В тайской культуре официанта зовут по статусу:
- **น้อง** (но́оң) — к молодому (если он/она младше тебя).
- **พี่** (пхи̂и) — к старшему официанту.
- **คุณ** (кхун) — нейтрально вежливое.

```
น้องค่ะ ขอเช็คบิลหน่อย            но́оң, чек, пожалуйста
พี่ครับ ขอน้ำหน่อย                 пхи̂и, воды, пожалуйста
```

### Якоря

- **ขอ + блюдо + счётное** — стандартный заказ.
- **ที่** (тьхи̂и) — счётное слово для порций.
- **ไม่ใส่** — «не добавлять» (для запретов в блюде).
- К официанту: **น้อง / พี่ / คุณ** по возрасту.
- Уточнять **остроту и сладость** — норма.

### Практические упражнения

**Упражнение 1.** Переведи:
1. Меню, пожалуйста.
2. Что это?
3. Не острое, пожалуйста.
4. Можно ещё воды?
5. Что посоветуете?

**Упражнение 2.** Сделай заказ:
1. Одну порцию пад-тая.
2. Две бутылки воды.
3. Один кокосовый сок.
4. Пад-гапрао без острого.

**Упражнение 3.** Прочитай и переведи:
1. ขอข้าวผัดกุ้งที่หนึ่งค่ะ
2. แนะนำอะไรดีคะ
3. ไม่ใส่ผงชูรสนะคะ
4. ขออีกจานนึงค่ะ
5. มีเมนูภาษาอังกฤษไหม

**Упражнение 4.** Составь короткий диалог в ресторане (4-6 реплик).

**Упражнение 5.** В лакорне героиня впервые в дорогом ресторане. Какие 3 фразы она вероятно скажет с волнением?

## Подтема 6.1.3 — Вкусы и реакции

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **อร่อย** | а̀-ро̀й | вкусно |
| **ไม่อร่อย** | ма̂й а̀-ро̀й | невкусно |
| **อร่อยมาก** | а̀-ро̀й ма̂ак | очень вкусно |
| **ดีมาก** | дии ма̂ак | очень хорошо |
| **เผ็ด** | пхӭ̀т | острое |
| **หวาน** | ва̌ан | сладкое |
| **เปรี้ยว** | при̂иау | кислое |
| **เค็ม** | кхэм | солёное |
| **ขม** | кхȯ̌м | горькое |
| **มัน** | ман | жирное / маслянистое |
| **จืด** | дьзы̀ыт | пресное, безвкусное |
| **เผ็ดร้อน** | пхӭ̀т ро́он | острый-горячий |
| **เผ็ดจี๊ด** | пхӭ̀т дьзи́ит | пронзительно острый |
| **น่ากิน** | на̂а гин | аппетитный |
| **กลิ่นหอม** | глѝн хо̌ом | ароматный |
| **กลิ่นเหม็น** | глѝн мӭ̌н | вонючий |
| **สด** | сȯ̀т | свежий |
| **เน่า** | на̂у | гнилой |
| **เย็น** | йэн | холодный |
| **ร้อน** | ро́он | горячий |
| **อิ่ม** | ѝм | сытый |
| **หิว** | хи̌у | голодный |

### Теория

**Главный принцип:** тайская кухня культурно опирается на **5 основных вкусов**:
1. **เผ็ด** — острое
2. **หวาน** — сладкое
3. **เปรี้ยว** — кислое
4. **เค็ม** — солёное
5. **ขม** — горькое

Тайская кухня уникальна тем, что часто **сочетает все пять** в одном блюде. Например, **ส้มตำ** содержит:
- เปรี้ยว (лайм)
- เผ็ด (перец)
- เค็ม (рыбный соус)
- หวาน (пальмовый сахар)
- ขม (зелёная папайя)

В лакорнах **первая реакция персонажа на тайскую еду** часто маркирует его культурный фон:
- Тайка автоматически распознаёт балансы.
- Иностранец вынужден учиться.

**Реакция «вкусно».**

```
อร่อย                              вкусно
อร่อยมาก                         очень вкусно
อร่อยจัง                            как же вкусно!
อร่อยที่สุด                          вкуснее всего
อร่อยเหลือเกิน                  чрезвычайно вкусно
อร่อยสุดๆ                          вкуснотища
```

В разговоре стандартная реакция: **«อร่อยค่ะ/ครับ»**.

**Реакция «невкусно».**

В тайской культуре прямо сказать **«ไม่อร่อย»** (невкусно) — невежливо. Чаще используют:
- **«ไม่ค่อยอร่อย»** — не очень-то вкусно.
- **«เฉยๆ»** — так себе.
- **«กินได้»** — можно есть (= нормально, не более).

Лакорная сцена: героиня молча ест, не отказывается — это и есть ไม่อร่อย, замаскированное под вежливость.

**Описание остроты.**

```
ไม่เผ็ด                              не острое
เผ็ดน้อย                            чуть острое
เผ็ดนิดหน่อย                       чуточку острое
เผ็ดปานกลาง                    средне
เผ็ดมาก                            очень острое
เผ็ดสุดๆ                            экстра острое
เผ็ดร้อน                            острое-горящее
เผ็ดจี๊ด                              пронзительное (резкое жжение)
```

В лакорнах **«โอ๊ย เผ็ด!»** (ой, острое!) — обычная реакция западного гостя.

**Описание сладости.**

В тайской еде **หวาน** часто положительное — особенно в напитках. Но в основных блюдах сладкость может быть нежелательной:

```
หวาน                              сладкое
หวานเลย                          прям сладкое
ไม่หวาน                            несладкое
หวานน้อย                         мало сладкого
หวานพอดี                         в самый раз
```

В кафе для напитков:
```
ชาเย็นหวานน้อยค่ะ              чай со льдом, мало сладкого
```

**Аппетит — หิว vs อิ่ม.**

```
หิว                                  голодная
หิวมาก                             очень голодная
หิวจะตาย                          умираю с голоду (драматично)
อิ่ม                                  сытая
อิ่มแล้ว                              уже сытая
อิ่มแน่นท้อง                      переела (живот полный)
```

В лакорнах **«หิวจะตาย»** — частая шуточно-эмоциональная реплика.

**Запахи.**

```
หอม                              ароматный
หอมมาก                          очень ароматный
เหม็น                              вонючий
กลิ่นแรง                          сильный запах
กลิ่นไม่ดี                          плохой запах
```

⚠️ **ทุเรียน** (дуриан) знаменит запахом. Тайцы делятся на тех, кому **หอม** (аромат), и кому **เหม็น** (вонь). В отелях часто запрещён.

### Якоря

- **5 вкусов**: เผ็ด, หวาน, เปรี้ยว, เค็ม, ขม.
- Тайская кухня **сочетает все вкусы** в одном блюде.
- Прямо сказать **«невкусно»** — невежливо.
- Стандартные смягчения: **«ไม่ค่อยอร่อย» / «เฉยๆ»**.
- **เผ็ด** — главный маркер тайской еды для иностранца.

## Подтема 6.1.4 — Счёт и оплата

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **เช็คบิล** | щӭ́к бин | счёт (англицизм) |
| **เก็บเงิน** | гӧ̀п ңӧн | принять деньги |
| **บิล** | бин | счёт (англ. bill) |
| **บาท** | ба̀ат | бат (валюта) |
| **เงิน** | ңӧн | деньги |
| **เงินสด** | ңӧн со̀т | наличные |
| **บัตร** | ба̀т | карта |
| **บัตรเครดิต** | ба̀т кхрӭӭ-дит | кредитная карта |
| **เงินทอน** | ңӧн тьхоон | сдача |
| **คิดเงิน** | кхи́т ңӧн | посчитать счёт |
| **รวม** | руам | вместе, итого |
| **ทั้งหมด** | тьха́ң мо̀т | всего, итого |
| **แยกบิล** | йэ̂эк бин | разделить счёт |
| **เลี้ยง** | ли́иаң | угощать |
| **จ่าย** | дьза̀ай | платить |
| **ค่า** | кха̂а | стоимость, плата |
| **ค่าอาหาร** | кха̂а аа-ха̌ан | плата за еду |
| **ค่าบริการ** | кха̂а-боо-ри́-гаан | плата за обслуживание |
| **ทิป** | тьхип | чаевые |
| **ใบเสร็จ** | бай сӭ̀т | чек |

### Теория

**Попросить счёт.**

Самая частая фраза:
```
เช็คบิลค่ะ/ครับ                      счёт, пожалуйста
เก็บเงินด้วยค่ะ                     посчитайте, пожалуйста
คิดเงินหน่อยค่ะ                   посчитайте
```

**เช็คบิล** — заимствование из английского **check + bill**, прижилось как стандартное.

**Сумма.**

Официант приносит счёт и говорит:
```
ทั้งหมด ห้าร้อยห้าสิบบาทค่ะ      итого 550 бат
รวมทั้งหมด สี่ร้อยห้าสิบ           всего 450 (без บาท в быстрой речи)
```

**Оплата.**

```
จ่ายเป็นเงินสดได้ไหม                 можно наличными?
รับบัตรเครดิตไหม                       принимаете карты?
ขอเงินทอน                               сдачу, пожалуйста
ไม่ต้องทอน                              сдачи не надо (= оставляю чаевые)
```

В лакорнах **«ไม่ต้องทอน»** — герой щедро оставляет чаевые, маркер обеспеченности.

**Разделить счёт.**

В тайской культуре **обычно платит старший** или **тот, кто пригласил**. Разделение счёта (как в западной культуре «по-голландски») — менее принято, но возможно:

```
แยกบิลได้ไหม                         можно разделить счёт?
ฉันจ่ายของฉัน                         я плачу своё
จ่ายคนละครึ่ง                          платим пополам
```

В лакорнах есть классическая сцена:
- Героиня хочет заплатить за себя.
- Герой настаивает: «**ผมเลี้ยง**» (я угощаю).
- Героиня отказывается принять.
- Герой настаивает сильнее, в конце концов платит.

Это **тайская мелодрама щедрости**: настаивание на оплате — знак заботы и статуса.

**Чаевые.**

В Таиланде **чаевые не обязательны**, но приветствуются:
- В уличных кафе — обычно никакие.
- В обычных ресторанах — 20-50 бат сверху.
- В дорогих ресторанах — 10% (часто уже включено в **ค่าบริการ** — service charge).

```
ทิปนิดหน่อย                           чуть чаевых
เก็บไว้                                   оставьте (всю сдачу)
```

**Угощать — เลี้ยง.**

**เลี้ยง** (буквально «кормить, содержать») — «угощать»:
```
ฉันเลี้ยงเอง                            я сама угощаю
วันนี้ผมเลี้ยง                          сегодня я угощаю
เลี้ยงข้าวกัน                          угощаемся / ужинаем вместе
```

В лакорнах **«ผมเลี้ยง»** — типичная реплика героя:
- Знак мужественности и заботы.
- Маркер начала отношений.
- Или утешение после грустной сцены.

**Чек — ใบเสร็จ.**

```
ขอใบเสร็จ                            квитанцию, пожалуйста
รบกวนขอใบเสร็จด้วย                 будьте любезны, чек
```

Чек обычно нужен для отчётности или возмещения расходов.

### Якоря

- **เช็คบิล** или **เก็บเงิน** — попросить счёт.
- **ไม่ต้องทอน** — оставить чаевые («сдачу не надо»).
- **เลี้ยง** — угощать (часто настаивание в лакорнах).
- **แยกบิล** — разделить счёт (менее принято).
- **Service charge** часто уже включён в чек дорогих заведений.

### Практические упражнения

**Упражнение 1.** Переведи:
1. Счёт, пожалуйста.
2. Можно картой?
3. Сдачу не надо.
4. Я угощаю.
5. Можно разделить счёт?

**Упражнение 2.** Прочитай и переведи:
1. ทั้งหมดเจ็ดร้อยห้าสิบบาทค่ะ
2. รับบัตรเครดิตไหมคะ
3. วันนี้ฉันเลี้ยงเอง
4. ไม่ต้องทอนค่ะ
5. ขอใบเสร็จด้วยนะคะ

**Упражнение 3.** Составь диалог об оплате (5 реплик).

**Упражнение 4.** В лакорнах:
1. Герой настаивает на оплате — что он скажет?
2. Героиня настаивает оплатить свою часть — что она скажет?
3. Молодой парень оставляет щедрые чаевые — что говорит?

**Упражнение 5.** Опиши свой типичный обед в ресторане в Литве на тайском — от заказа до оплаты (минимум 5 фраз).
