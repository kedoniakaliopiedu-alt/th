### Теория

**Структура «ร้าน + что продаёт».**

В тайском большинство магазинов — это **ร้าน** (магазин/лавка) + **то, что продаётся**:

```
ร้าน + กาแฟ          ร้านกาแฟ        кафе
ร้าน + ขนม           ร้านขนม         кондитерская
ร้าน + ยา             ร้านยา           аптека
ร้าน + ดอกไม้        ร้านดอกไม้      цветочный
ร้าน + หนังสือ        ร้านหนังสือ     книжный
```

Это **продуктивная морфема** — можешь конструировать новые: ร้านชา (чайная), ร้านขายของเก่า (антикварный), ร้านตัดผม (парикмахерская).

**Главные форматы торговли.**

**1. ตลาดสด** — свежий рынок.

Главное место покупки еды для тайцев. Открытый или крытый, с прилавками рыбы, мяса, овощей, фруктов. Утренний (4-10 утра) и вечерний (16-19). Здесь:
- Свежие продукты, цены ниже супермаркетов.
- Торг возможен, но не такой агрессивный, как на туристических рынках.
- Атмосфера дружеская, продавцы часто постоянные клиенты узнают.

В лакорнах тёща героини покупает на свежем рынке → знак практичности, домашности.

**2. ตลาดนัด** — выходной/плавающий рынок.

Бывает только в определённые дни/вечера в определённых местах. Знаменитые:
- **Chatuchak** (Чатучак, выходные) — крупнейший в Бангкоке.
- **Asiatique** (Азиатик, вечер) — туристический.
- **Talad Rot Fai** (Талад Рот Фай) — винтажный.

Тут — одежда, безделушки, антиквариат, еда. Активный торг.

**3. ห้าง** — торговый центр.

Универсальное слово для **любого молла**. В Бангкоке десятки больших ห้าง:
- **Siam Paragon, ICONSIAM** — премиум.
- **MBK, Platinum** — мода для масс.
- **Central** — сеть универмагов.

Цены **фиксированные**, торг не уместен. В лакорнах ห้าง — место встреч молодёжи, романтических свиданий.

**4. เซเว่น (7-Eleven) — везде.**

Самая знаменитая сеть мини-маркетов. На каждом углу. Здесь покупают:
- Еду на ходу (онигири, лапшу, бутерброды).
- Кофе, воду, лёд.
- Симки, билеты, талоны на бензин.
- Платят за счета (электричество, телефон).

**เซเว่น** — это и магазин, и социальная инфраструктура. В лакорнах сцена в 7-Eleven — маркер обычной городской жизни.

**5. ซูเปอร์มาร์เก็ต — современный супермаркет.**

**Tops, Big C, Lotus, Makro, Villa** — главные сети. Фиксированные цены, аналог западного супермаркета. В отличие от ตลาด — стерильно, удобно, дороже.

**Различие ห้าง vs ร้าน vs ตลาด.**

| Тип | Размер | Цены | Атмосфера |
|---|---|---|---|
| **ตลาด** | большой, открытый | договорные | живая, шумная |
| **ร้าน** | маленький, конкретный | фиксированные | дружеская |
| **ห้าง** | огромный, крытый | фиксированные | премиум, кондиционер |

### Якоря

- **ร้าน + что продаёт** = магазин чего-то.
- **ตลาดสด** — свежий продуктовый рынок.
- **ตลาดนัด** — выходной/туристический рынок.
- **ห้าง** — торговый центр (любой молл).
- **เซเว่น** — социальная инфраструктура, не просто магазин.
- Торг **на ตลาด**, не на **ห้าง / เซเว่น**.

### Теория

**Структура «เสื้อ + тип».**

```
เสื้อยืด                      футболка
เสื้อเชิ้ต                       рубашка (классическая)
เสื้อโปโล                     поло

เสื้อกันหนาว                свитер
เสื้อโค้ท                      пальто
```

**กางเกง + тип** для брюк:
```
กางเกงยีนส์                  джинсы
กางเกงขาสั้น                шорты
กางเกงสแล็ก                слаксы
กางเกงเลกกิ้ง               легинсы
```

**ชุด — комплект.**

**ชุด** (щут) — «комплект, наряд, костюм». Используется для:
- Платья (одна вещь, но «комплект» в смысле «цельный наряд»).
- Костюма (брюки + пиджак).
- Униформы (школьной, медицинской).

```
ชุดเดรส                       платье
ชุดนักเรียน                  школьная форма
ชุดนอน                       пижама
ชุดว่ายน้ำ                   купальник
ชุดแต่งงาน                  свадебное платье
ชุดไทย                         традиционный тайский костюм
```

**ชุดไทย** — лакорный спецтермин. Это исторический традиционный наряд: для женщин — длинная запашная юбка **ผ้าซิ่น** (или намотка **โจงกระเบน**) и блузка/накидка **สไบ**. В исторических лакорнах все героини носят ชุดไทย.

**Тайский климат — особенности гардероба.**

В Таиланде **жарко круглый год** (за исключением декабря-января на севере). Поэтому:
- **เสื้อแขนสั้น и กางเกงขาสั้น** — основа гардероба.
- **เสื้อกันหนาว** — реально нужен только в **прохладный сезон** или для прохлады кондиционера в офисе.
- В кондиционированных торговых центрах часто холоднее, чем снаружи → лёгкая накидка для женщин.

В лакорнах героиня в офисе всегда в кофточке или накидке — это реализм.

**Размеры — два подхода.**

Тайцы используют:
1. **Европейские** (S, M, L, XL) — через слово **ไซส์** (от англ. size).
2. **Тайские** (เล็ก, กลาง, ใหญ่) — для одежды массового производства.

```
ไซส์ S                          размер S
ไซส์เล็ก                      маленький размер
ไซส์กลาง                    средний
ไซส์ใหญ่                      большой
```

**Тайские размеры обычно меньше европейских**. То, что в Европе M, в Таиланде часто L. Поэтому в магазинах для иностранцев есть отдельные секции.

**Цвета (детально в следующей подтеме).**

```
สี                              цвет
สีดำ                            чёрный
สีขาว                          белый
สีแดง                          красный
สีฟ้า                            голубой (→ твоё имя ฟ้า)
```

### Якоря

- **เสื้อ / กางเกง / ชุด** — основные категории одежды.
- **ชุดไทย** — традиционный наряд (лакорнный).
- **ไซส์** (S/M/L) или тайские **เล็ก/กลาง/ใหญ่**.
- Тайские размеры **меньше** европейских.
- **เสื้อกันหนาว** для **прохладного сезона** или офисного кондиционера.

### Теория

**Структура — สี + название.**

В тайском цвета строятся через **สี + цветовой корень**:

```
สี + ดำ (чёрный) = สีดำ
สี + แดง (красный) = สีแดง
```

Слово **สี** часто **обязательно** перед цветом. Сравни:
- «**สีฟ้า**» — голубой (цвет).
- «**ฟ้า**» — небо (без сѝи это слово значит «небо», не «голубой»).

Без сѝи могут понять, но **четче добавлять**.

**Этимология цветов.**

Многие цвета — **от природных объектов**:
- **น้ำตาล** (на́ам таан) — буквально «сахарная вода» → коричневый.
- **น้ำเงิน** (на́ам ңӧн) — «вода-серебро» → тёмно-синий (старое значение).
- **ฟ้า** (фа́а) — небо → голубой.
- **เขียว** (кхи̌иау) — зелёный (старое тайское слово).
- **ส้ม** (со̂м) — апельсин → оранжевый.
- **ชมพู** (щом-пхуу) — от санскритского, изначально «розовое дерево».
- **ม่วง** (муа̂ң) — манго (вид фиолетового манго) → фиолетовый.
- **ทอง** (тьхооң) — золото → золотой.
- **เงิน** (ңӧн) — серебро/деньги → серебряный.

**Цвета королевской семьи.**

В Таиланде каждый король и член королевской семьи имеет **«свой цвет»** по дню рождения (тебе известна эта система из главы 3):
- **Король Бхумибол** (понедельник) → **жёлтый**.
- **Король Вачиралонгкорн** (понедельник) → жёлтый, но также синий.
- **Королева Сирикит** (пятница) → **голубой**.
- **Принцесса Сириндорн** (суббота) → **фиолетовый**.

Эти цвета носят в день рождения монарха, в день памяти. **Жёлтые рубашки** по понедельникам — реальная практика.

**В лакорнах цвета — драматический инструмент:**
- **Чёрный** — траур, смерть, печаль.
- **Белый** — невинность, свадебное, иногда тоже траур (в буддизме).
- **Красный** — любовь, страсть, опасность.
- **Розовый** — наивность, девичество.
- **Фиолетовый** — печаль, благородство.
- **Голубой** — спокойствие, верность.

**Светлый / тёмный.**

```
สีน้ำเงินเข้ม                       тёмно-синий
สีฟ้าอ่อน                          светло-голубой
สีแดงสด                            ярко-красный
สีเขียวอ่อน                        светло-зелёный
สีเทาเข้ม                            тёмно-серый
```

Структура: **สี + цвет + เข้ม / อ่อน / สด**.

**Описать цвет одежды.**

```
เสื้อสีแดง                            красная рубашка
กระโปรงสีดำ                       чёрная юбка
รองเท้าสีขาว                       белая обувь
ชุดสีชมพู                            розовое платье
```

В тайском **цвет ставится после существительного** (как в русском: «рубашка красная»).

### Якоря

- **สี + цветовой корень** = цвет.
- Многие цвета — **от природных объектов** (น้ำตาล, ฟ้า, ส้ม, ทอง).
- **Королевские цвета** имеют культурное значение.
- **เข้ม / อ่อน / สด** — оттенки.
- В одежде: **существительное + сีี + цвет**.

### Теория

**Базовый шопинг-диалог.**

В магазине с фиксированными ценами:
```
Покупатель: อันนี้เท่าไหร่คะ            сколько это?
Продавец:   หนึ่งพันบาทค่ะ            1000 бат
Покупатель: มีไซส์เอ็มไหมคะ           есть размер M?
Продавец:   มีค่ะ                          есть
Покупатель: ขอลองได้ไหมคะ            можно примерить?
Продавец:   ห้องลองทางนี้ค่ะ           примерочная здесь
... (после примерки)
Покупатель: เอาค่ะ                         беру
Продавец:   ทั้งหมดหนึ่งพันบาทค่ะ    итого 1000
Покупатель: รับบัตรไหมคะ                принимаете карты?
Продавец:   รับค่ะ                          принимаем
```

**Торг на рынке.**

На свежем рынке, в туристических местах, на улице — торг **ожидается**. Цепочка торга:

```
Покупатель: เท่าไหร่คะ                      сколько?
Продавец:   ห้าร้อยค่ะ                       500
Покупатель: แพงไป ลดได้ไหม              дорого, можно скидку?
Продавец:   ลดได้ค่ะ สี่ร้อยห้าสิบ        можно, 450
Покупатель: สามร้อยห้าสิบได้ไหม         350 можно?
Продавец:   ไม่ได้ค่ะ ขาดทุน สี่ร้อย    не могу, в убыток, 400
Покупатель: เอาค่ะ                            беру
```

**Тонкости торга:**
1. **Не торгуйся слишком жёстко** — для тайцев это не борьба, а танец.
2. **Улыбайся** — резкий тон оттолкнёт продавца.
3. **Если сильно сбили цену — обязательно покупай**. Уйти после жёсткого торга — невежливо.
4. **Знай рыночную цену** — есть базовая цена для местных и завышенная для туристов. Опытный покупатель сразу делит на 2.

**В лакорнах сцены торга** часто играются для:
- Демонстрации хитрости / простоты героини.
- Контраста между героем (платит без торга) и героиней (умеет торговаться).
- Юмора через комичное переторгование.

**Подобрать размер и цвет.**

```

```

```

```
