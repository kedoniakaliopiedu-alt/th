# Thai Phonetics — кириллическая система транскрипции

Этот skill — **единственный источник записи** тайских звуков в проекте. Любая транскрипция,
которая попадает в задание, объяснение, отчёт или файл темы, собирается по нему. Он не
генерирует упражнения и не выносит вердиктов по ответам — он отвечает на один вопрос: как
это записывается.

Справочники под ним — данные, а не примеры: если знака нет в таблице, его нет и в записи.
**Подставлять «наиболее близкий кириллический эквивалент» запрещено.** Близкий по звуку, по
написанию и по привычке русского уха дают разный результат, и два листа расходятся между
собой.

## Порядок сборки транскрипции

Каждое слово проходит эти шаги по порядку. Пропуск шага 3 — самая частая причина
правдоподобной, но неверной записи.

1. **Разбить на слоги.** Без границы слога вопрос «инициаль это или финаль» не имеет смысла.
2. **Определить инициаль.** Одна согласная → `consonants.md`. Две подряд → сначала
   `clusters.md`: настоящий кластер, ложный или ведущая согласная — три разных ответа.
3. **Проверить немые буквы.** Есть `์`, или слог начинается с `ห` / `อ` перед согласной →
   `silent-letters.md`. Буква может не звучать и при этом менять тон.
4. **Записать гласный** → `vowels.md`. Долгота — удвоением. **Гласного знака в слоге может
   не быть вовсе** — две согласные подряд читаются с невидимой гласной: `ȯ`, а перед `ร` —
   `оо` (раздел 5 там же). Не спутать с кластером: `กล`, `ทร` гласной между собой не имеют.
5. **Записать финаль** → `consonants.md`, колонка «Финаль». Знак в конце слога читается не
   так, как в начале: `ร` → н, `ญ` → н, `ว` → у, звонкие оглушаются.
6. **Определить тон.** Класс инициали (с поправкой из шагов 2–3) плюс тип слога дают
   ожидаемый тон — и он **сверяется по** http://thai-language.com/dict/search перед тем, как
   попасть в текст. Никогда по памяти.

   → Как спросить словарь, как выбрать нужную запись и как перевести её тон в наш знак:
   см. skill **thai-verify**.

   **У слова бывает несколько записей — брать основную.** Словарь помечает варианты:
   `colloquial`, `alternate pronunciation`, `poetic`, `ancient`. На учебный лист идёт
   немаркированная запись, разговорная — только если она и есть предмет темы. Пример:
   `ไหม` — основная `mai R` (восходящий), рядом лежит `mai H` с пометкой *colloquial*;
   в курсе стоит восходящий. Взять первую попавшуюся строку выдачи — типовая ошибка.
7. **Собрать слоги через дефис** и проверить по `irregulars.md`, не входит ли слово в список
   тех, что читаются не по правилу.

Если на любом шаге данных нет — так и сказать. Пустая ячейка честнее правдоподобной.

## Справочники

| Файл | Когда читать |
|---|---|
| `references/alphabet.md` | Нужно ввести знак (скопировать, а не набрать похожий) или запись выглядит верной, но не находится поиском: 28 знаков системы с кодовыми точками |
| `references/consonants.md` | Всегда, когда записывается согласный: класс знака, чтение в инициали и в финали по всем 42 знакам, обратная таблица «звук в финали → знаки» |
| `references/vowels.md` | Всегда, когда записывается гласный: простые, дифтонги, `ำ ฤ ฦ`, колонка «закрывает слог» |
| `references/clusters.md` | Две согласные подряд в начале слога — настоящий кластер, ложный (`ทร` → `с`, молчащая `ร`) или ведущая согласная |
| `references/silent-letters.md` | В слове есть `์`, либо слог начинается с `ห` или `อ` перед согласной |
| `references/irregulars.md` | Перед записью незнакомого слова и перед вердиктом по слову из списка; там же — записи курса, которым нельзя верить |

**У всех шести одна рамка**, и новый справочник пишется по ней же: заголовок → строка
«Читать этот файл, когда…» → **Откуда взято** (источник и дата, без этого файл недоказуем) →
`---` → пронумерованные содержательные разделы → **Требует сверки** (если есть спорное) →
**Чего этот файл не решает** последним. Две закрывающие секции не нумеруются — это рамка,
а не содержание.

Целостность рамки и данных проверяется одной командой:

```bash
python3 .codex/skills/thai-phonetics/scripts/phonetics.py check
```

## Общие правила записи

- Транскрипция — **исключительно кириллицей**. Латиница не используется нигде, кроме
  Уровня 1 (изучение алфавита), где английское произношение букв даётся как справочное.
- **Долгота — удвоением**: аа, ии, уу, ыы, ӭӭ, ээ, ȯȯ, оо, ӧӧ. **Макрон не используется
  в проекте нигде** — ни для долготы, ни для тона.
- **Многосложные слова** записываются через дефис: กะทิ → га-тьхи, สวัสดี → са-ват-дии.
- **Тоны** обозначаются диакритическим знаком **строго над гласной** — над первой, если она
  долгая. Не над согласной и не в конце слога: `ща̌н`, а не `щан̌`. Правило жёсткое: съехавший
  знак привязывает тон не к тому звуку.

| Тон | Знак | Пример |
|---|---|---|
| Средний (สามัญ) | — | не обозначается |
| Низкий (เอก) | ` | а̀а |
| Нисходящий (โท) | ˆ | â |
| Высокий (ตรี) | ´ | á |
| Восходящий (จัตวา) | ˇ | ǎ |

- **Кириллица — приближение, а не звук.** Расхождение между таблицей и голосом носителя
  решается в пользу голоса, а не спором. Послушать знак можно на
  https://thai-alphabet.com/.
- **Знак в позиции — по алфавитному источнику; слово целиком (написание, значение, тон) —
  по словарю.** При конфликте источников запись помечается как спорная, и спорное на лист
  ученику не выносится.

## Примеры транскрипции

| Тайское слово | Транскрипция | Перевод |
|---|---|---|
| สวัสดี | са-ват-дии | здравствуй |
| ฉันรักเธอ | ща̌н-ра́к-тьхӧӧ | я люблю тебя |
| กำลังกิน | гам-лаң-гин | (сейчас) ест |
| ข้าว | кха̂ау | рис |
| ใจดี | дьзай-дии | добросердечный |

Тоны здесь не проставлены нигде, кроме `ข้าว`: они не были сверены по словарю, когда
таблица писалась. Перед показом любого примера ученику тон сверить.

## Проверь перед выдачей

1. Слово разбито на слоги, а не записано сплошняком.
2. Две согласные подряд разобраны по `clusters.md`, а не сложены из двух строк.
3. Немые буквы проверены — `์`, `ห`, `อ`.
4. Финаль взята из колонки «Финаль», а не из колонки «Инициаль».
5. Долгота — удвоением; макрона в записи нет.
6. Тон сверен по словарю, а не выведен по памяти.
7. Ни одного знака, которого нет в справочниках; там, где данных нет, так и написано.
