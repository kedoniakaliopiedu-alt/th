# Кластеры: настоящие, ложные и ведущая согласная

Читать этот файл всегда, когда в начале слога стоят **две согласные подряд**. Складывать их
чтения по `consonants.md` можно далеко не всегда: сочетание бывает настоящим кластером,
ложным (одна буква молчит или пара читается третьим звуком) или вообще не кластером,
а ведущей согласной. Решение принимается здесь, до того как собирается транскрипция.

**Откуда взято.** `Thai B1/Chapter 1/b1_glava1_tema1_klastery.md`, подтемы 1.1.1 и 1.1.2.
Ни одно слово не добавлено по памяти; новое попадает сюда после сверки по
http://thai-language.com/dict/search.

---

## 1. Настоящие кластеры (อักษรควบแท้)

Две согласные читаются слитно, без вставной гласной: `กล` — это `гл`, а не `га-л`.

Кластер возможен **только** при таком составе:

- первая — одна из **ก ข ค ต ป ผ พ**;
- вторая — одна из **ร ล ว**.

Любое другое сочетание настоящим кластером не является — иди в разделы 2 и 3.

| Первая ↓ Вторая → | + ร | + ล | + ว |
|---|---|---|---|
| **ก** | гр | гл | гв |
| **ข** | кхр | кхл | кхв |
| **ค** | кхр | кхл | кхв |
| **ต** | тр | (редко) | — |
| **ป** | пр | пл | — |
| **ผ** | пхр | пхл | — |
| **พ** | пхр | пхл | — |

Самые частые: ก ร, กล, ขร, คร, ตร, ปร, พร, พล.

### Класс считается по первой согласной

Вторая в расчёте тона не участвует вовсе:

| Кластер | Класс | По какой букве |
|---|---|---|
| กล | средний | ก |
| คร | низкий | ค |
| ขล | высокий | ข |
| ตร | средний | ต |

Разбор целиком, на примере `กลับ`: `ก` средний + `ล` (не считается) → средний класс,
слог мёртвый (финаль `บ`), гласная краткая → низкий тон → **гла̀п**.

### Редукция в быстрой речи — не для листа

В разговорной норме Бангкока второй согласный часто выпадает: `ครับ` → кха́п, `ตรง` → тооң.
**На учебный лист выносится полная форма.** Редукции описаны отдельно, в
`Thai B1/Chapter 1/b1_glava1_tema2_redukcii.md`, и в транскрипцию заданий не идут.

## 2. Ложные кластеры (อักษรควบไม่แท้)

Написание выглядит как кластер, читается иначе. Два типа, оба — закрытые списки, которые
учат наизусть.

### 2.1 Молчащая `ร`

Вторая буква `ร` не читается вовсе. Слова заимствованы из санскрита, пали и кхмерского,
где `ร` была частью этимологии, а в тайском произношении упростилась.

| Слово | Чтение | Перевод |
|---|---|---|
| จริง | дьзиң | правда |
| เศร้า | са̂у | грустный |
| สร้าง | са̂аң | строить |
| ศรี | си̌и | святой, благородный (в именах) |
| ศรัทธา | са̀т-тьхаа | вера |
| สรร | са̌н | избирать |
| สระ | са̀ | бассейн |

**`สระ` — только в значении «бассейн».** В значении «гласная» то же написание читается
`са̀-ра̀` (словарь: `saL raL`), то есть `ร` там **звучит** и молчащей не является. Одно
написание, два чтения по смыслу — при сверке смотреть на значение, а не только на буквы.

### 2.2 `ทร` → `с`

Сочетание `ท` + `ร` читается как `с`. **Тон считается как от `ส`** (высокий класс), а не
от `ท` — это отдельная фонетическая категория, а не выпадение буквы.

| Слово | Чтение | Перевод |
|---|---|---|
| ทราย | саай | песок |
| ทรง | соң | форма; королевское «делать» |
| ทรุด | су́т | опуститься, упасть |
| แทรก | сэ̂эк | вставить |
| ทราบ | са̂ап | знать (вежливое) |

## 3. Ведущая согласная (อักษรนำ) — не кластер

Высокая или средняя согласная перед одиночной низкой передаёт ей свой класс. Выглядит
похоже на кластер, но устроено иначе: `สบาย` → са̀-баай, два слога, а не один.

В курсе тема помечена как разобранная не до конца, поэтому здесь только рабочий признак:

> Две согласные подряд — это ещё **не** кластер. Прежде чем читать, реши, что перед тобой:
> настоящий кластер (раздел 1), ложный (раздел 2) или ведущая согласная.

Полное правило ведущей согласной в проекте пока не записано. До этого её случаи сверяются
по словарю пословно.

## Требует сверки

Записи из файла курса, где транскрипция повреждена или противоречит правилу этого же файла.
**В заданиях не использовать, пока не сверены по словарю.**

| Записано | Что не так |
|---|---|
| ทราย → сааай | три «а» подряд; по системе должно быть саай |
| ทรัพย์ → сап́ | тоновый знак стоит после согласной, а не над гласной |
| ทรุดโทรม → су̀т-троом | второй слог противоречит правилу `ทร` → `с` из этого же раздела |
| ทรพี → са́ пхии | пробел вместо дефиса, знак не над гласной |
| มัทรี → мат́ сии | то же |
| มหันต์ทรัพย์ → ма ха̌н сап́ | то же |

Отдельно: **карта кластеров в самом файле курса всё ещё пишет `ก` как «к»** (кр, кл, кв).
Здесь она приведена по действующей записи (гр, гл, гв) — файл курса на этом месте устарел.

## Чего этот файл не решает

- **Тон.** Кластер задаёт класс инициали, то есть вход в тональное правило, но сам тон перед
  вердиктом сверяется по http://thai-language.com/dict/search.
- **Немые буквы вне кластеров** — танхатхат, `ห`-наводящая, `อ`-наводящая: см.
  `silent-letters.md`.
- **Слова, не покрытые ни одним правилом**, — `irregulars.md`.
