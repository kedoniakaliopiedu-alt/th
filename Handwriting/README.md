# Handwriting — фото рукописного тайского

Сюда складываются фотографии тетради, доски, вывесок — всё, что нужно прочитать с
картинки. Эта папка и есть переключатель: скилл `thai-handwriting` запускается, только
когда здесь лежат файлы **за сегодняшний день**, и разбирает именно их. Картинка,
вставленная в чат, сама по себе распознавание не запускает — иначе любой скриншот
превращался бы в разбор рукописи.

Почему не просто вставить в чат: инструменту `thaiocr` нужен файл на диске — он режет
страницу на строки и увеличивает каждую, а это заметно точнее, чем чтение страницы
целиком.

## Как класть

Три способа, все ведут в один и тот же конвейер:

1. **Перетащить файл на эту папку** в проводнике VS Code или в Finder — самый надёжный.
2. **AirDrop с телефона** в эту папку.
3. **Из чата через буфер обмена.** Вставь фото в чат по **Cmd+V** (не мышью — важно, чтобы
   оно попало в буфер), затем попроси «прими фото». Скрипт `scripts/intake` поднимет
   картинку из буфера сюда и сразу нарежет на строки.

`intake` разбирает буфер по-разному и сохраняет лучший доступный формат:

- скопирован **файл** (в Finder выделил и Cmd+C) → берётся **оригинал без потерь**,
  HEIC остаётся HEIC, JPG остаётся JPG;
- скопировано **содержимое картинки** (Cmd+V фото в чат) → сохраняется как **JPEG** с
  полным разрешением и EXIF;
- если доступен только растр без JPEG → PNG.

Картинку, затащенную в чат **мышью**, переложить нельзя — она не становится файлом на
диске. Для такой используй способ 1, либо перед этим скопируй фото в буфер (Cmd+C).

Имя файла роли не играет. Файлы из буфера называются `chat-<дата>-<время>.<формат>`.

## Что снимать

- Лист целиком, сверху, без сильного угла — перспективу `thaiocr` не правит,
  наклон в плоскости листа правит (`prep --deskew`).
- Резкость важнее света: тень и серый фон вычищаются автоматически
  (`CIDocumentEnhancer`), а смазанный штрих не восстановить.
- Не обрезать верх строки — там тоновые знаки, без них не прочитать тон.
