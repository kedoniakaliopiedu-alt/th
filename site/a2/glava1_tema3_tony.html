Цель темы: уметь определить тон любого слога — по его классу согласной, типу финали, длине гласной и наличию тонового знака.
Это самая важная тема главы. Все правила тонов сходятся здесь. У тебя уже есть рабочая таблица — мы её достроим и систематизируем.

Подтема 1.3.1 — Живой и мёртвый слог#

Словарный запас (терминология)#

ТайскийТранскрипцияПеревод

มาตราма̂ат-траакатегория (финаль/«мать»)

Теория#

Принцип: тип слога зависит от финали (что в конце) и длительности гласной (если слог открытый).

Живой слог (คำเป็น) — слог, который можно «петь». Его финаль не обрывает звук резко. К живым относятся:

  1. Открытые слоги с долгой гласной: กา (каа), ตี (тии), ดู (дуу)
  2. Слоги с сонорной финалью (можно тянуть): กง (коң), กน (кон), กม (кам), กย (кай), กว (кау)
  3. Слоги с финалью-полугласной (-ย, -ว): ลอย (лоой), เก้า (ка̂у)

Мёртвый слог (คำตาย) — слог, который обрывается резко. К мёртвым относятся:

  1. Открытые слоги с короткой гласной: กะ (ка), ติ (ти), จุ (дьзу), เกะ (кӭ)
  2. Слоги со взрывной финалью [k̚], [t̚], [p̚]: รัก (ра́к), รส (рот), รับ (рап)
ТипФинальЖивой/МёртвыйПример

Открытый, краткая гласнаянетмёртвыйติ (ти)

Зачем это знать?

От типа слога прямо зависит, какие тоны он может иметь:

  • Живой слог по умолчанию даёт средний или восходящий тон.
  • Мёртвый слог по умолчанию даёт низкий или высокий тон.

То есть мёртвый слог не может быть восходящим без тонового знака. А живой не может быть высоким без знака. Это будет в 1.3.2 — здесь главное запомнить классификацию.

Тонкость с долгой и краткой гласной в мёртвом слоге.

Когда мёртвый слог имеет низкоклассовую инициальную согласную, длина гласной начинает влиять на тон:

  • Краткий + мёртвый + низкокласс = высокий тон: รัก (ра́к ́, любить)
  • Долгий + мёртвый + низкокласс = нисходящий тон: มาก (ма̂ак — много), ลาบ (ла̂ап — блюдо лаап)

Это правило уже встречалось раньше — здесь оно зафиксировано формально.

Подтема 1.3.2 — Правила тонов без знаков#

Теория#

Главный принцип: тон слога определяется тремя факторами:

  1. Класс инициальной согласной (средний / высокий / низкий)
  2. Тип слога (живой / мёртвый)
  3. Долгота гласной (важна для мёртвых слогов с низкокл.)

Плюс — наличие тонового знака (если есть). О знаках — в 1.3.3. Здесь рассматриваем слоги без знаков.

Пояснения и якоря#

1. Живой слог + средняя инициаль = средний тон.

กา (каа — ворона), ดี (дии — хорошо), ตา (таа — глаз)

2. Живой слог + высокая инициаль = восходящий тон.

ขา (кха̌а — нога), สาม (са̌ам — три), หา (ха̌а — искать)

3. Живой слог + низкая инициаль = средний тон.

มา (маа — приходить), นา (наа — рисовое поле), ลา (лаа — осёл)

4. Мёртвый слог + средняя инициаль = низкий тон.

กะ (ка̀ — и), จับ (дьза̀п — хватать), ตก (то̀к — падать)

5. Мёртвый слог + высокая инициаль = низкий тон.

ขะ (кха̀ — частица), สด (со̀т — свежий), ผัก (пха̀к — овощи)

6. Мёртвый слог + низкая инициаль + краткая гласная = высокий тон.

รัก (ра́к — любить), นัก (на́к — большой /приставка), มัด (ма́т — связывать)

7. Мёртвый слог + низкая инициаль + долгая гласная = нисходящий тон.

มาก (ма̂ак — много), ลาบ (ла̂ап — лаап, блюдо), ราด (ра̂ат — поливать)

Как использовать эту таблицу на практике#

При чтении нового слога:

  1. Смотришь на первую согласную → определяешь её класс.
  2. Смотришь на финаль и длину гласной → определяешь живой/мёртвый и длину.
  3. Пересекаешь в таблице → получаешь тон.

Пример с คน (кхон — человек):

  1. ค = низкая
  2. คน — закрытый, финаль [n] — сонорная → живой
  3. Низкая + живой = средний тон → кхон.

Пример с รัก (любить):

  1. ร = низкая
  2. รัก — закрытый, финаль [k̚] — взрывная → мёртвый; гласная ั — краткая
  3. Низкая + мёртвый + краткая = высокий тон → ра́к. ✓

Теория#

Какой знак какой тон даёт — зависит от класса инициали.

Это ключевой принцип: один и тот же знак даёт разные тоны в зависимости от того, какая согласная стоит перед ним. Запомни:

Пояснения#

1. Знаки –๊ и –๋ работают только со средним классом. Зачем? Потому что:

  • Среднеклассовая согласная — единственная, способная принять все 5 тонов. Высокому и низкому классам недоступны какие-то тоны без хитростей.
  • Когда тайцу нужно записать слог в высоком тоне с низкой инициалью — он использует ма́й тхоо: รู้ (ру́у — знать).
  • Когда нужно записать слог в восходящем тоне с низкой инициалью — он использует ห-наводящую (тема 1.4): หนา (на̌а — толстый).

2. Знак ма́й тхоо ведёт себя по-разному. Со средним и высоким классом → нисходящий: ก้า (ка̂а), ข้า (кха̂а). С низким классом → высокий: ค้า (кха́а), น้า (на́а).

Это исключение, которое ты уже один раз ловила: รู้ (ру́у) — высокий, не нисходящий, потому что ร — низкая.

3. Тоновый знак стоит ВСЕГДА над инициалью. Даже если в слоге есть знак гласной над инициалью (например, ี), тоновый знак ставится выше гласной: ตี้ (ти̂и).

4. Кластеры и тоновый знак. Если в начале слога кластер (две согласные подряд), знак ставится над второй, но тон определяется по классу первой: ปลู้ (плу̂у — по правилу ปลู: ป — средняя → ма́й тхоо даёт нисходящий).

Якоря для запоминания#

Знаки ма́й ӭ́к и ма́й тхоо — главные, встречаются постоянно. Знаки ма́й трии и ма́й джат-ваа — редкие, в основном для звукоподражаний и заимствований: จ๊ะ (тя́ — частица согласия), ตี๋ (тиˇи — китаец).

Главная пара исключений (низкий класс):

  • ма́й ӭ́к → нисходящий (а не низкий!)
  • ма́й тхоо → высокий (а не нисходящий!)

Это потому, что низкий класс «не может» в эти тоны без знака — поэтому знаки «сдвигают» его на один шаг вверх.

Подтема 1.3.4 — Кластеры (อักษรควบ)#

Словарный запас#

Кластер — это две согласные подряд в начале слога, без гласной между ними. В тайском кластеры бывают истинные (читаются обе согласные) и ложные (читается только первая, либо звук модифицируется).

ТипТайское названиеТранскрипция
Истинныйอักษรควบแท้ак-со̌он кхуап тьхэ́э
Ложныйอักษรควบไม่แท้ак-со̌он кхуап ма̂й тьхэ́э

Теория#

Истинный кластер — строгое правило.

Истинный кластер возможен только если:

  1. Первая согласная — одна из: ก, ข, ค, ต, ป, ผ, พ
  2. Вторая согласная — одна из: ร, ล, ว
Первая ↓ \ Вторая →รลว
กกร (кр)กล (кл)กว (кв)
ขขร (кхр)ขล (кхл)ขว (кхв)
คคร (кхр)คล (кхл)คว (кхв)
ตตร (тр)——
ปปร (пр)ปล (пл)—
ผผร (пхр)ผล (пхл)—
พพร (пхр)พล (пхл)—

Если первая согласная не из этого списка — кластер невозможен. Например:

  • เวลา (вее-лаа) — два слога: เว + ลา. Это не кластер, потому что ว не входит в список «первых букв кластера».
  • สลาก (сала̀к) — два слога: ส + ลาก. ส не в списке.

Это правило ты уже зафиксировала в своих заметках.

Тон в истинном кластере.

Тон определяется по первой согласной кластера, не по второй.

  • ปลา (плаа — рыба): ป — средняя → живой слог без знака → средний тон.
  • ครับ (кхра́п — частица): ค — низкая → мёртвый закрытый, краткий → высокий тон (но из-за финали –ับ слышится как «крап»).
  • ขรึม (кхрым — серьёзный): ข — высокая → живой → восходящий тон.

Ложные кластеры.

Бывают 3 типа:

1. Молчащий ร: Когда сочетания ทร, ศร, สร в начале слова — буква ร не читается, остаётся только первая.

  • ทราย (саай — песок) — не «тхрай»!
  • ศรี (си̌и — благоприятный) — не «срии»
  • สร้าง (са̂аң — строить) — не «сраанг»

2. ทร = с: Особое чтение: ทร = с, как в ทราย, ทรง (соң — форма).

3. Кластеры по виду, но не по правилу. Когда сочетание выглядит как кластер, но первая согласная не из списка — это не кластер, а два отдельных слога с «беглой» гласной:

  • เสมา → читается как «сами̌а» с подразумеваемой «а» между ส и ม. Это «слитная орфография», не кластер.

Особый случай — ห-наводящая.

Сочетание ห + одиночная низкоклассовая (ง, ญ, น, ม, ย, ร, ล, ว) — это не кластер. Это специальная конструкция, где ห меняет класс второй согласной с низкого на высокий. Об этом — в Теме 1.4.

Пример: หนู (ну̌у — мышь) — ห не читается, читается только น, но тон вычисляется так, будто инициаль высокого класса.

Якоря#

Запомни строгий список первых букв кластера (мнемоника):

ก ข ค + ต ป + ผ พ
«гадский тип, плохой» (грубая мнемоника, но рабочая)

И второй части:

ร ล ว — «всегда плавные, всегда сонорные»

Сравни два примера, чтобы зафиксировать разницу:

  • เปล่า (бпла̀у — нет) — кластер ปล: ป входит в список → один слог, [пл-]
  • เวลา (вее-лаа — время) — не кластер: ว не входит → два слога, เว + ลา

Резюме по теме#

К концу темы ты должна уметь:

  • ✅ Определить живой или мёртвый слог по финали и длине гласной
  • ✅ Назвать 5 тонов и их обозначения
  • ✅ Применить главную таблицу для определения тона без знака
