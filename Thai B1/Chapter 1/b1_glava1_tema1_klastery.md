## Подтема 1.1.1 — Настоящие кластеры (อักษรควบแท้)

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **กลับ** | кла̀п | возвращаться |
| **กลัว** | клуа | бояться |
| **กลาง** | клааанг | середина |
| **กล้วย** | клуа̂й | банан |
| **ครู** | кхруу | учитель |
| **ครอบครัว** | кхро̂оп кхруа | семья |
| **ความ** | кхуаам | (приставка абстракции) |
| **ขวด** | кхуа̀т | бутылка |
| **ขวัญ** | кхуа̌н | дух, душа |
| **ตรง** | тронг | прямо |
| **ตรวจ** | трруа̀т | проверять |
| **ปรับ** | пра̀п | подстроить |
| **ผลไม้** | пхо̌н ла ма́й | фрукт |
| **พลัง** | пхланг | сила |
| **พระ** | пхра́ | святой |

### Теория

**Настоящий кластер (อักษรควบแท้)** — это **слитное произношение двух согласных** в начале слога. Обе согласные читаются вместе, без вставной гласной.

**Правило (повторение из A2):** настоящий кластер возможен только если:
- **Первая согласная**: ก, ข, ค, ต, ป, ผ, พ
- **Вторая согласная**: ร, ล, ว

Любые другие комбинации — **не настоящий кластер**.

**Полная карта возможных кластеров.**

| Первая ↓ Вторая → | + ร | + ล | + ว |
|---|---|---|---|
| **ก** | กร [кр] | กล [кл] | กว [кв] |
| **ข** | ขร [кхр] | ขล [кхл] | ขว [кхв] |
| **ค** | คร [кхр] | คล [кхл] | คว [кхв] |
| **ต** | ตร [тр] | (редко) | (нет) |
| **ป** | ปร [пр] | ปล [пл] | (нет) |
| **ผ** | ผร [пхр] | ผล [пхл] | (нет) |
| **พ** | พร [пхр] | พล [пхл] | (нет) |

Не все комбинации одинаково употребимы. Самые частые: **กร, กล, ขร, คร, ตร, ปร, พร, พล**.

**Особенности произношения.**

1. **Без вставной гласной.** Кластер **กล** — это **/кл/**, а не **/каl/** или **/каle/**. Произноси слитно.

2. **В быстрой речи второй согласный часто редуцируется** — особенно **ล** и **ร**:
   ```
   гл-произношение: ครับ → /кhrа́p/ → в речи /кhа́p/ (выпадает ร)
   гл-произношение: ตรง → /троонг/ → в речи /тоонг/ (выпадает ร)
   ```
   Это **разговорная норма Бангкока**.

3. **В формальной речи** (новости, литература) — все кластеры произносятся отчётливо.

**Класс кластера = класс первой согласной.**

При определении тона кластер ведёт себя как **первая согласная**:
- **กล** — класс средний (как ก).
- **คร** — класс низкий (как ค).
- **ขล** — класс высокий (как ข).
- **ตร** — класс средний (как ต).

Это значит: тон рассчитывается по **первой согласной**, не по второй.

**Примеры.**

```
กลับ
ก [средний] + ล [низкий → не считается]
= средний класс, мёртвый слог (финаль บ), краткая гласная → низкий тон
произношение: кла̀п
```

```
ครู
ค [низкий] + ร [низкий → не считается]
= низкий класс, открытый слог без тонового знака = тон средний
произношение: кхруу
```

```
ขวด
ข [высокий] + ว [низкий → не считается]
= высокий класс, мёртвый слог с долгой гласной = низкий тон
произношение: кхуа̀т
```

### Якоря

- **Первая согласная** кластера: только **ก ข ค ต ป ผ พ**.
- **Вторая согласная** кластера: только **ร ล ว**.
- **Тон считается по первой согласной**.
- В разговоре часто **редуцируют второй** (ครับ → คับ).

## Подтема 1.1.2 — Ложные кластеры (อักษรควบไม่แท้)

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **จริง** | джинг | правда (ร не читается!) |
| **เศร้า** | сâу | грустный (ร не читается) |
| **สร้าง** | са̂анг | строить (ร не читается) |
| **สระ** | са̀ | бассейн (особое чтение) |
| **ทราย** | сааай | песок (ทร → с) |
| **ทรง** | соонг | (король) форма (ทร → с) |
| **ทรัพย์** | сап́ | имущество (ทร → с) |
| **แทรก** | сэ̂эк | вставлять (ทร → с) |
| **ทรุด** | су̀т | опуститься (ทร → с) |
| **ไซร้** | са́й | (литературное) (ซ + ร = с) |

### Теория

**Ложный кластер (อักษรควบไม่แท้)** — это написание, **похожее на кластер**, но **читающееся иначе**. Есть два главных типа:

### Тип 1: Молчащая ร

В некоторых словах вторая буква **ร** в кластере **не читается**:

```
จริง = จ + ริง → читается /джинг/ (без ร)
เศร้า = ศ + ร้า → читается /сâу/ (ร не звучит)
สร้าง = ส + ร้าง → читается /са̂анг/ (без ร)
```

Это **исключения**, которые надо **запомнить**. Их немного, но они **очень частые**:

| Слово | Произношение | Перевод |
|---|---|---|
| จริง | джинг | правда |
| เศร้า | сâу | грустный |
| สร้าง | са̂анг | строить |
| ศรี | сѝи | святой / благородный (имена) |
| ศรัทธา | сàт-тхаа | вера |
| สรร | сǎн | избирать |
| สระ | са̀ | бассейн / гласная |

Почему так? Эти слова — **заимствования** (из санскрита, палия, кхмерского), где **ร** была частью оригинальной этимологии, но в тайском произношении упрощённа.

### Тип 2: ทร → с

Когда **ท** стоит перед **ร**, комбинация читается как **/с/**:

```
ทราย = ทร + าย → читается /сааай/ (песок)
ทรง = ทร + ง → читается /соонг/ (форма, для короля)
ทรัพย์ = ทร + ัพย์ → читается /сап́/ (имущество)
ทรุด = ทร + ุด → читается /су̀т/ (опуститься)
```

Это **отдельная фонетическая категория**: **ทร = с**. Тон рассчитывается **как от ส** (высокий класс), а не от ท.

Полный список основных слов с **ทร → с**:

| Слово | Произношение | Перевод |
|---|---|---|
| ทราย | сааай | песок |
| ทรง | соонг | форма; королевское «делать» |
| ทรัพย์ | сап́ | имущество |
| ทรุด | су̀т | опуститься, упасть |
| ทรุดโทรม | су̀т-троом | разрушенный, упавший |
| แทรก | сэ̂эк | вставить |
| ทราบ | са̂ап | знать (вежливо) |
| ทรพี | са́ пхии | (литер.) недостойный сын |
| มัทรี | мат́ сии | имя из Рамаяны |
| มหันต์ทรัพย์ | ма ха̌н сап́ | огромное состояние |

### Тип 3: Знак อักษรนำ (ведущая согласная)

Это другая категория — не кластер, но похоже выглядит. Когда **высокая или средняя** согласная стоит перед **низкой одиночной**, она «передаёт свой класс» низкой:

```
สบาย = ส + บาย → /са̀-баай/
  ส (высокий) ведёт บ (средний → ведёт к низкому тону для следующего слога?)
  → результат: первый слог короткий с низким тоном, второй с тоном по правилам ส
```

Это **более сложная тема**, которую разберём отдельно. Пока главное:
- **Не все «двусогласные начала» — кластеры**.
- Если видишь две согласные подряд — **проверь**: это кластер, ведущая, или ложный?

### Якоря

- **Молчащая ร**: จริง, เศร้า, สร้าง, ศรี (запомнить).
- **ทร = /с/**: ทราย, ทรง, ทรัพย์, แทรก.
- Тон считается **как от первой согласной** в кластере.
- При **ทร = с** тон считается **как от ส** (высокий класс).

### Практические упражнения

**Упражнение 1.** Это настоящий или ложный кластер?

2. จริง → ?
3. ทราย → ?
4. กลัว → ?
5. สร้าง → ?

**Упражнение 2.** Как читается ทร в каждом слове?
1. ทรัพย์ → ?
2. ทรง → ?
3. แทรก → ?
4. ทราบ → ?

**Упражнение 3.** Произнеси правильно:

2. ทรายร้อน

**Упражнение 4.** Найди ошибку (произношение):

2. ทราย → /тхрааай/ (неверно)

## Подтема 1.1.3 — Двусложные начала и вставная гласная

### Словарный запас

| Тайский | Транскрипция | Перевод |
|---|---|---|
| **กระเป๋า** | кра-пǎу | сумка |
| **กระดาษ** | кра-да̀ат | бумага |
| **ตลาด** | та-ла̀ат | рынок |
| **ตลก** | та-ло̀к | смешной |
| **ขนม** | кха̀-но̌м | сладкое |
| **ขนุน** | кха̀-нǔн | джекфрут |
| **ฉลาด** | чха̀-лàат | умный |
| **ฉลอง** | чха̀-ло̌онг | праздновать |
| **ผลิต** | пха̀-лит̀ | производить |
| **ปลอม** | плоом | поддельный |
| **สบาย** | са̀-баай | хорошо |
| **สนุก** | са-ну̀к | весело |
| **สวัสดี** | са̀-ват-дии | здравствуй |
| **อร่อย** | а̀-ро̀й | вкусно |
| **อนุญาต** | а-ну́-йа̂ат | разрешать |

### Теория

**Главный принцип:** некоторые «начальные сочетания согласных» в тайском читаются **с короткой вставной гласной /а/** между ними. Это называется **อักษรนำ** или **двусложное начало**.

Это **не кластер** (кластер читается слитно), и **не ложный кластер** (там не звучит вторая). Это **отдельный тип**.

**Структура:**
```
[согласная_1] + [согласная_2] + [гласная]
↓
/[согл1]-а-[согл2][гласная]/
```

То есть слово начинается с **двух слогов**: короткий **/[согл1]-а/** + основной слог.

### Примеры

**กระ-:**
```
กระเป๋า → กระ + เป๋า → /кра-пǎу/
กระดาษ → กระ + ดาษ → /кра-да̀ат/
```

**ตล-:**
```
ตลาด → ตะ + ลาด → /та-ла̀ат/
ตลก → ตะ + ลก → /та-ло̀к/
```

**ขน-:**
```
ขนม → ขะ + นม → /кха̀-но̌м/
ขนุน → ขะ + นุน → /кха̀-нǔн/
```

**ฉล-:**
```
ฉลาด → ฉะ + ลาด → /чха̀-лàат/
ฉลอง → ฉะ + ลอง → /чха̀-ло̌онг/
```

**สบ-, สน-, สว-:**
```
สบาย → สะ + บาย → /са̀-баай/
สนุก → สะ + นุก → /са-ну̀к/
สวัสดี → สะ + วัสดี → /са̀-ват-дии/
```

### Распределение тонов в двусложных началах

Это **самая сложная** часть. Правило:

**Первая согласная (которая «несёт» вставную /а/)** — определяет **тон первого мини-слога**.

**Вторая согласная** «получает» класс **первой**, и **её слог** тонизуется по этому переданному классу.

**Пример: ตลาด**

- ต — средний класс.
- ล — низкий класс (одиночная).
- ตล: ต ведёт ล → ล получает «средний класс» для тона.
- Слог 1 (та): средний класс, открытый, краткий → **низкий тон** (правило для «ведущей»).
- Слог 2 (лàат): по правилам среднего класса для мёртвого слога с долгой гласной + майэк → низкий тон.

Результат: **та-ла̀ат**.

**Пример: สบาย**

- ส — высокий класс, несёт вставную /а/ → слог 1 (са̀): краткий открытый, высокий класс → **низкий тон**.
- บ — средний класс, живой слог без знака → слог 2 (баай): **средний тон**.
- Результат: **са̀-баай**.

⚠️ **Важный нюанс.** «Ведущая» согласная передаёт свой класс второму слогу **только если вторая — низкоклассовая одиночная сонорная** (น, ม, ง, ย, ร, ล, ว): например, ขนม → ข ведёт น → **кха̀-но̌м** (восходящий во втором слоге). Если же вторая согласная средне- или высококлассовая (как บ в สบาย), она сохраняет **свой** тон.

**Главное практическое правило:**
- **Первый мини-слог** обычно с **низким тоном** (краткий, безударный).
- **Второй слог** тонизуется **по контексту** — иногда по передаваемому классу, иногда по реальному классу.

**Не пытайся запомнить всю систему сразу.** Учи **по отдельным словам**, постепенно паттерн станет очевиден.

### Как отличить от настоящего кластера?

| Признак | Кластер (กลับ) | Двусложное начало (ตลาด) |
|---|---|---|
| Первая согласная | ก/ข/ค/ต/ป/ผ/พ | любая |
| Вторая согласная | ร/ล/ว | любая (часто น/ม/บ) |
| Слогов | один | два |
| Вставная /а/ | нет | есть |

**Тест: попробуй произнести две согласные подряд без гласной.**
- Получается легко (как в /кл/, /пр/, /кх/) → **кластер**.
- Нужно вставить /а/ для произнесения → **двусложное начало**.

### Якоря

- **Двусложные начала** читаются с **краткой /а/** между согласными.
- Это **не кластер** и **не ложный кластер** — это **отдельный тип**.
- **Тон второго слога** часто определяется **классом первой** (ведущей) согласной.
- Учи **по отдельным словам**, не по правилам.

| **ตู้เย็น** | туу̂ йэн | холодильник |
| **เปอร์เซ็นต์** | пёэ-сен | процент |
| **เซ็นต์** | сен | подписать |

### Теория

**Главный принцип:** в тайском есть **много нерегулярных написаний**, особенно в **заимствованиях** из санскрита/палия и из европейских языков. Им надо учиться **по отдельности**.

### Категория 1: Слова с **ทันทฆาต (์)**

**Тантхакхат** (์) — это знак «убей букву», который ты уже знаешь из A2. Он часто стоит над **последней согласной** заимствований, чтобы показать, что её **не нужно читать**:

Например, **เกียรติ** (честь) читается /кииа̂т/: конечные **ร** и **ติ** не произносятся — остаётся закрытый слог на [т]. (Здесь буквы молчат по орфографической традиции, без явного тантхакхата.)

Лучшие примеры с явным тантхакхатом:

| Слово | Из чего убирается | Читается |
|---|---|---|
| **โทรศัพท์** | ์ над พ̂ → молчит | тхоо-ра́-са̀п |
| **อิเล็กทรอนิกส์** | ์ над ส → молчит | и-ле́к-тхро-нѝк |
| **อาทิตย์** | ์ над ย → молчит | аа-тхи́т |
| **ศุกร์** | ์ над ร → молчит | су̀к |
| **อังกฤษ** | ์ над ษ → нет тантхакхата, но не читается | анг-крит |

⚠️ Иногда **последняя буква не читается** и **без** тантхакхата — это просто **орфографическая традиция** заимствования. Запоминается по словам.

### Категория 2: Особые санскритские чтения

В словах из санскрита/палия часто бывают **странные на вид** правила чтения:

**กษัตริย์** (король)
- Видишь: /ка-са-три-я/?
- Читается: **/ка̀-сàт/**
- Объяснение: ษ часто не читается отдельно, а **сливается** с предыдущим звуком; ริย์ — с тантхакхатом ิ ย์, читается просто как краткий /т/.

**ปฏิบัติ** (практиковать)
- Видишь: /па-ти-ба-ти/?
- Читается: **/па̀-ти-бат́/**
- Объяснение: последнее ิ + неявная редукция.

**ราชา** (король)
- Читается: /раа-чхаа/
- ช здесь — /чх/, как обычно.

**Это не «исключения» — это особенности санскритской орфографии**, перенесённые в тайский. Когда ты видишь длинное слово с **ษ, ฤ, ฦ, ์** — это **почти всегда санскрит**.

### Категория 3: Заимствования из английского

В Таиланде много англицизмов, особенно в технологиях и моде:

```
คอมพิวเตอร์ = кхом-пхиу-тӧ̄ӭ        компьютер
อินเตอร์เน็ต = ин-тӧ̄ӭ-нет́              интернет
เซเว่น = сее-вэ̂н                            7
มอเตอร์ไซค์ = мо̄о-тӧ̄ӭ-сай          мотоцикл
แท็กซี่ = тхэ́к-сии̂                          такси
แอร์ = ээ                                    кондиционер (air)
ทีวี = тии-вии                              ТВ
```

**Особенности:**
1. **Тоны** заимствований — обычно **средний или высокий** на основных слогах, без сильных перепадов.
2. **Длина гласных** часто сохраняется из английского.
3. **Согласные** адаптируются к тайской фонетике (например, /v/ → /w/, /f/ часто сохраняется).

**Английские заимствования через ฟ:**
- ฟ = /ф/, есть и в тайских словах, но часто в заимствованиях: ฟุตบอล (футбол), แฟน (фан = парень/девушка).

### Категория 4: Аббревиатуры и сокращения

Тайские аббревиатуры читаются по буквам, **как латинские**:
- **กทม.** = กรุงเทพมหานคร = Бангкок (но читается по буквам: «กอ-ทอ-มอ»)
- **ม.** = มหาวิทยาลัย = университет
- **น.ส.** = นางสาว = мисс
- **ดร.** = ดอกเตอร์ = доктор (PhD)

### Категория 5: Дни недели и месяцы (повторение)

Помнишь из A2 правило окончаний?
- **-คม** = 31 день (январь, март, май, июль, август, октябрь, декабрь)
- **-ยน** = 30 дней (апрель, июнь, сентябрь, ноябрь)
- **-พันธ์** = февраль (с тантхакхатом!)

Все эти окончания — **санскритские**, с непростой орфографией.

### Якоря

- **Тантхакхат (์)** часто молчит последнюю букву заимствования.
- **Санскритские слова** имеют свои правила чтения — учи по словам.
- **Английские заимствования** адаптированы фонетически, тоны нейтральные.
- **Аббревиатуры** читаются по буквам (กอ-ทอ-มอ для กทม.).
