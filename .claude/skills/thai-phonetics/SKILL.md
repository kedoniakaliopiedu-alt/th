# Thai Phonetics — Кириллическая система транскрипции

Этот skill используется совместно с **thai-learning**. Все транскрипции в заданиях,
аннотациях и контрольных работах записываются строго по правилам этого документа.

---

## Общие правила записи

- Транскрипция — **исключительно кириллицей**. Латиница не используется нигде, кроме Уровня 1 (изучение алфавита), где английское произношение букв даётся как справочное.
- **Тоны** обозначаются диакритическим знаком над первой гласной слога:

| Тон | Знак | Пример |
|---|---|---|
| Средний (สามัญ) | ¯ | а̄а̄ |
| Низкий (เอก) | ` | а̀а |
| Нисходящий (โท) | ˆ | â |
| Высокий (ตรี) | ´ | á |
| Восходящий (จัตวา) | ˇ | ǎ |

- **Многосложные слова** записываются через дефис: กะทิ → га-тӣ, สวัสดี → са-ват-дӣ.
- Долгие гласные обозначаются удвоением: аа, ии, уу, ыы, ӭӭ, ээ, оо, åå, ӧӧ.

## Гласные

### Монофтонги

| Класс (кирилл.) | Тайский знак | Транскрипция короткая | Транскрипция длинная | Закрывает слог |
|---|---|---|---|---|
| а | -า / -ะ / -ั | а | аа | -า: нет; -ะ: да; -ั: нет |
| и | -ี / -ิ | и | ии | нет |
| ы | -ื / -ึ | ы | ыы | нет |
| у | -ู / -ุ | у | уу | нет |
| ӭ | เ- / เ-็ / เ-ะ | ӭ | ӭӭ | нет (-็/-ะ: да) |
| э | แ- / แ-็ / แ-ะ | э | ээ | нет (-็/-ะ: да) |
| о | โ- / โ-ะ | о | оо | โ-ะ: да |
| å | -อ / เ-าะ | å | åå | เ-าะ: да |
| ӧ | เ-อ / เ-อะ | ӧ | ӧӧ | เ-อะ: да |

**Пояснение звуков:**
- **ӭ** — между «э» и «е», как в английском *men*
- **å** — между «а» и «о», округлённый
- **ӧ** — между «э», «е» и «о»; нейтральный центральный гласный

### Дифтонги

| Класс (кирилл.) | Тайский знак | Транскрипция | Длина | Закрывает слог |
|---|---|---|---|---|
| ай | ไ- / ใ- | аай | длинный | да |
| ай | -ัย | ай | короткий | нет |
| иа | เ-ีย / เ-ียะ | ииа / иа | длинный / короткий | нет / да |
| ыа | เ-ือ / เ-ือะ | ыыа / ыа | длинный / короткий | нет / да |
| уа | -ัว / -ัวะ | ууа / уа | длинный / короткий | нет / да |
| ау | เ-า | ау | длинный | нет |
| ауу | -าว | ауу | длинный | да |

### Составные дифтонги (правило сложения)

| Формула | Результат |
|---|---|
| เ- + -ี + ย | иа |
| เ- + -ื + อ | ыа |
| -ั + ว | уа |
| เ- + -า | ау |

## Согласные

### Особые правила произношения

Следующие согласные имеют **разное чтение в начале слога и в финали**:

| Буква | В начале слога | В финали |
|---|---|---|
| จ | дьж | т |
| ท, ธ | тьх | т |

> **Важно:** дьж и тьх — аффрикаты/придыхательные, характерные именно для позиции в начале слога. В финали они оглушаются до чистого **т**.

### Прочие согласные (будет дополняться)

Остальные согласные записываются по мере того, как пользователь уточняет предпочтительную запись. До получения уточнения использовать наиболее близкий кириллический эквивалент и помечать как предварительный.
