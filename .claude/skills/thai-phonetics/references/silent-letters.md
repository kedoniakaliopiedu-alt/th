# Немые буквы: танхатхат, наводящие ห и อ

Читать этот файл всегда, когда в слове есть значок `์`, либо слог начинается с `ห` или `อ`
перед другой согласной. Все три случая объединяет одно: **буква написана, но не звучит**.
Две из них при этом меняют тон, так что пропустить их нельзя — получится верный набор
звуков с неверным тоном.

**Откуда взято.** `Thai A2/Chapter 1/glava1_tema4_spec_znaki.md`, подтемы 1.4.1 и 1.4.2.
Ни одно слово не добавлено по памяти.

---

## 1. Танхатхат `์` — буква просто не читается

Значок над согласной означает «эта буква не произносится». Встречается почти только
в заимствованиях: слово записывают по правилам языка-источника, а лишние для тайской
фонетики согласные глушат.

| Слово | Чтение | Что подавлено |
|---|---|---|
| สงฆ์ | со̌ң | ฆ |
| จันทร์ | дьзан | кластер ทร |
| เบียร์ | бииа | ร |
| ภาพยนตร์ | пха̂ап-пха́-йон | кластер ตร |
| ไมล์ | май | ล |
| อาทิตย์ | аа-тьхи́т | ย |

**Танхатхат может глушить не одну букву, а группу** — всё, что стоит после неё в той же
морфологической группе. Это частое у санскритских корней и по написанию не всегда очевидно:
незнакомое заимствование проверяется по словарю, а не выводится.

Современные английские заимствования используют танхатхат для передачи согласного на конце
оригинала: `คอมพิวเตอร์`, `เบียร์`, `แซนด์วิช`. Тон и точную запись таких слов сверять
отдельно — они не подчиняются общим правилам.

---

## 2. `ห`-наводящая — не звучит, но задаёт тон

Одиночные низкоклассовые (**ง ญ น ม ย ร ล ว**) не имеют пары в высоком классе, поэтому сами
по себе не дают восходящий и низкий тон. Перед такой согласной ставят немую `ห`, и весь слог
считает тон **по правилам высокого класса**. Звука `х` в транскрипции при этом нет.

| Слово | Чтение | Тон | Без `ห` было бы |
|---|---|---|---|
| หนู | ну̌у | восходящий | нуу (средний) |
| หมา | ма̌а | восходящий | маа (средний) |
| หงาย | ңа̌ай | восходящий | |
| หญิง | йи̌ң | восходящий | |
| หวาน | ва̌ан | восходящий | |
| หลาย | ла̌ай | восходящий | |
| หน่อย | но̀й | низкий | |
| หน้า | на̂а | нисходящий | |
| หม่อม | мо̀м | низкий | |

**Когда не применяется.** С парными низкоклассовыми (**ค ช ท พ ฟ ซ ฮ**) — у них уже есть
высокая пара, и вместо `ห` берут сразу высокую букву (`ข` вместо `ค`).

`ห` со своим собственным звуком `х` (`ห้าม` → ха̂ам) наводящей не является: там она
инициаль, а не показатель.

---

## 3. `อ`-наводящая — закрытый список из четырёх слов

`อ` перед `ย` делает слог среднеклассовым, отчего ма́й ӭ́к даёт низкий тон. Список закрыт
и не растёт:

| Слово | Чтение | Перевод |
|---|---|---|
| อย่า | йа̀а | не надо, не делай |
| อยู่ | йу̀у | находиться |
| อย่าง | йа̀аң | вид, способ; как |
| อยาก | йа̀ак | хотеть |

---

## 4. `อ` как носитель гласного

Собственного согласного звука у `อ` нет: в начале слога он лишь держит гласный и
в транскрипции не даёт ничего. Это не исключение, а свойство знака — см. `consonants.md`,
средний класс.

---

## Чего этот файл не решает

- **Молчащая `ร` в ложных кластерах** (`จริง`, `สร้าง`) — это кластерное явление,
  см. `clusters.md`, раздел 2.1.
- **Тон.** Наводящие меняют класс инициали, то есть вход в тональное правило, но сам тон
  перед вердиктом сверяется по http://thai-language.com/dict/search.
- **Слова, не покрытые ни одним правилом**, — `irregulars.md`.
