# Режимы отработки

Шесть режимов. Режим определяется категорией ошибки (`drill-plan` отдаёт поле `mode`),
объём — формулой 3+1 с потолком 10. Внутри режима задания идут от простого к сложному и
обязательно включают продукцию рус→тай.

**Общее для всех режимов:**

- Свободное написание диалога/текста/рассказа **не даётся** ни в одном режиме.
- Каждое задание проходит чеклист однозначности из thai-tasks: один глагол действия,
  явно сказано что прислать и в каком виде, показан образец формата.
- Примеры свежие — не переписанные из «Практических упражнений» учебного файла, но на
  лексике и правилах той же темы.
- Подпункты внутри задания — буквами (а, б, в), чтобы можно было сослаться на «3б».
- Транскрипция кириллицей, тоновый знак над гласной.
- После круга — `record` по элементам и `attempt` по паттерну.

---

## `vocab` — запоминание слов

**Когда:** ошибка в выборе слова, забытое слово, подстановка похожего, пропуск («не
знаю»). Правила тут нет — есть дыра в словаре темы.

**Особенность:** отрабатывается **весь словарь темы**, а не одно провалившееся слово.
Берётся `vocab_pool` из `drill-plan` (отсортирован по mastery, слабые первыми). Порция —
**5–7 слов** за подход; словарь темы больше — идём порциями, между порциями короткая
сводка «взято / осталось».

**Три прохода по каждой порции:**

1. **Узнавание тай→рус** — список тайских слов, ответ переводом.
2. **Продукция рус→тай** — те же значения обратно, ответ тайским письмом (по уровню
   сложности — с транскрипцией или без).
3. **Слово в живой фразе** — короткая фраза-контекст с пропуском, вставить нужное слово;
   ситуации из реальной жизни (рынок, кафе, распорядок дня), не абстрактные.

**Критерий взятия:** слово считается взятым после **2 верных ответов подряд в разных
направлениях** (узнавание + продукция). Невзятые возвращаются в конце подхода ещё раз и,
если снова мимо, уходят в трекер с низким качеством (`record <слово> 1`).

**Дополнительные типы, если порций несколько:** сортировка слов по смысловым группам,
поиск лишнего в ряду, подбор антонима/пары из той же темы, сопоставление слово ↔
ситуация.

## `tones` — тоновый дрилл

**Когда:** неверный тон, неверная транскрипция тона, путаница нисходящий/средний и т.п.

**Обязательное:** каждый тон в ответе и в ключе сверяется по
http://thai-language.com/dict/search. Не по памяти.

**Типы заданий:**

- **Цепочка «класс → знак → тип слога → тон»** на 6–10 словах темы: по каждому слову
  ответ в виде «класс согласной — тоновый знак — открытый/закрытый — тон».
- **Транскрипция с тоном** списка слов темы.
- **Минимальные пары**: два слова, различающиеся только тоном (например ขาว / ข่าว) —
  определить тон и значение каждого.
- **Найди в списке**: «выпиши слова с нисходящим тоном».
- **Обратное задание**: дан тон и значение — выбрать верное написание из двух вариантов.
- **Позиционное чтение** (если ошибка на финалях): «как читается จ / ท / ธ в начале слога
  и в финали» — с примерами из темы.

## `grammar` — трансформации

**Когда:** порядок слов, частица, конструкция, счётное слово, маркер времени, вопросная
форма.

**Принцип:** одна конструкция под **4–5 разных углов**, не пять однотипных подстановок.

**Типы заданий:**

- **Перестрой фразу**: дана правильная фраза — сделай из неё вопрос / отрицание /
  прошедшее / вежливую форму.
- **Найди и исправь**: дана фраза с ошибкой того же типа, что сделал пользователь —
  найти, исправить, объяснить одной строкой.
- **Дострой по модели**: дан образец, к нему 3 незаконченные фразы.
- **Выбор из двух** с обоснованием (для второго круга — основная опора).
- **Сборка рус→тай**: короткая фраза целиком по-тайски, конструкция обязательна.
- **Собери из блоков**: даны слова вразбивку — выстроить в правильном порядке.

Минимум одно задание — продуктивное рус→тай, но **фраза, а не текст**.

## `spelling` — восстановление написания

**Когда:** неверная согласная/гласная, потерянный знак, неверный класс согласной,
ложный кластер (จริง, สร้าง), слитность/раздельность.

**Типы заданий:**

- **Запиши по транскрипции**: дана кириллическая транскрипция + перевод — написать
  тайским письмом.
- **Пара-ловушка**: два похожих написания (กู / คู, ลิ / ลี) — выбрать верное и сказать,
  чем отличаются по звучанию/тону.
- **Найди ошибку**: слово написано неверно — найти, исправить, назвать, что подменено.
- **Вставь пропущенное**: слово с дырой (`?ับ`) — восстановить знак/гласную/согласную.
  Кандидатов по маске можно проверить скриптом `thai-handwriting/scripts/lookup.py`.
- **Разбор слога**: разложить слово на инициаль — гласную — финаль, назвать класс
  инициали и получившийся тон.
- **Ложные кластеры**: список слов, где ร немая или кластер читается не буквально —
  прочитать и записать транскрипцию.

## `register` — регистр и уместность

**Когда:** неверное обращение (คุณ вместо ป้า), мужская/женская частица, слишком
книжно/слишком фамильярно, не тот уровень вежливости.

Это не «ошибка правила», а промах по адресату. Поэтому все задания строятся от **ситуации
и собеседника**.

**Типы заданий:**

- **Кому говоришь**: 4–5 ситуаций (пожилая продавщица, ровесник-коллега, ребёнок,
  чиновник, друг) — подобрать обращение и частицу.
- **Перепиши вежливее / проще / разговорнее**: дана нейтральная фраза, изменить регистр.
- **Исправь неуместное**: фраза грамматически верная, но не в том регистре — что не так
  и как сказать.
- **Ситуация → реплика**: одна конкретная реплика (не диалог!) под заданную ситуацию.
- **Отличи пары**: две фразы с одинаковым смыслом, разным регистром — сказать, где какая
  уместна.

Здесь же уместна линза «естественность» из `thai-tasks/references/checking.md`:
показывай, как сказал бы носитель, отдельной строкой — это не снижает оценку.

## `reference` — справка без дрилла

**Когда:** ошибка не языковая, а понимания формулировки: незнакомый учебный термин
(แม่ как «группа по конечному звуку»), непонятое условие задания.

Блок заданий **не собирается**. Вместо него:

1. Короткое объяснение термина — 2–3 строки, с примером из уже пройденного.
2. **Один** контрольный вопрос на понимание.
3. Термин заносится в трекер как элемент (`record ... --type rule`), чтобы всплыл в
   спирали.

Если после контрольного вопроса термин всё ещё не понят — тогда уже собирается дрилл того
режима, к которому относится сам материал (обычно `spelling` или `tones`).

---

## `general` — смешанный

Категория не легла ни в один режим. Собери блок из типов
`thai-tasks/references/exercise-catalog.md` по теме ошибки, соблюдая общие правила
(объём по формуле, продукция обязательна, свободного сочинения нет). Заодно уточни
категорию ошибки в трекере — `mistake --category` с более точным названием, чтобы в
следующий раз режим определился сам.
