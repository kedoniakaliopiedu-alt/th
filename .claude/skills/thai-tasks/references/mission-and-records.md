# Миссия, учебные записи и ресурсы

Практики из skill `teach` (Matt Pocock), адаптированные под проект Thailand. Три коротких
файла в проекте держат обучение осмысленным: **зачем** учим (mission), **что качественно
сдвинулось** (learning records) и **откуда берём факты** (resources). Трекер `progress.json`
отвечает за числа; эти файлы — за смысл и достоверность.

---

## MISSION.md — зачем всё это

Компактный файл в проекте Thailand с реальной целью Ked. Каждый комплекс привязывай к
нему: примеры, темы и ситуации должны служить цели, а не быть абстрактными. Если запрос
уводит в сторону от миссии — мягко верни к ней или уточни.

Шаблон (держи в пределах экрана):

```md
# Миссия: тайский

## Зачем
{1–3 предложения. Конкретная цель. Например: понимать лакорны без субтитров, читать
тайские посты/тексты, свободно говорить на знакомые темы и переводить рус→тай.}

## Как выглядит успех
- {наблюдаемое умение — напр. «смотрю сцену лакорна и понимаю диалог без субтитров»}
- {напр. «перевожу связный абзац рус→тай с частицами и счётными словами»}
- {…}

## Ограничения
- Учусь на практике: теория сама по себе не укладывается — задания через действие.
- Произношение ставлю отдельно (диктовка, повтор за актёрами); в заданиях достаточно
  проверять транскрипцию.
- Тон серьёзный, без геймификации.

## Вне фокуса
- Подготовка к языковым сертификатам (не цель — цель лакорны/иммерсия и живая речь).
```

Правила: одна миссия на проект; конкретика вместо абстракции; при смене цели — обнови файл
и заведи learning record. Если миссия не заполнена — сначала распроси, потом учи.

## learning-records/ — качественные инсайты (не журнал)

Записи уровня решений — как ADR в разработке. Фиксируют то, что **меняет, чему учить
дальше**: не «прошли тему», а «есть свидетельство, что она усвоена / исправлено
заблуждение / раскрыто прежнее знание / сдвинулась цель». Ведут зону ближайшего развития.

Файлы `learning-records/0001-slug.md`, номер инкрементируется. Формат — одно-три
предложения:

```md
# {Что установлено или усвоено}

{Что именно усвоено (или какое прежнее знание раскрыто) и почему это меняет следующие
занятия.}
```

Когда писать запись:
1. Пользователь **показал реальное понимание** нетривиального (не просто прошли, а есть
   доказательство корректного применения) — это поднимает планку следующего шага.
2. **Раскрыл прежнее знание** («это я уже знаю») — записать, чтобы не переучивать.
3. **Исправлено заблуждение** — высокоценно: предсказывает будущие спотыкания в смежном.
4. **Сдвинулась миссия** — перелинкуй с MISSION.md и обнови её.

Не писать: про «просто прошли» (охват ≠ обучение), дубли того, что уже в трекере/списках.

Отличие от базы ошибок (`mistakes` в progress.json): та — про повторяющиеся *ошибки*
числом; learning records — про *прорывы и смыслы* словами. Они дополняют друг друга.

## RESOURCES.md — доверенные источники + принцип сверки

Курируемый список источников, из которых берём факты. **Не выдумывай тайский по памяти** —
значения, написание, тоны, употребление бери из файлов проекта и источников ниже; при
малейшей неуверенности сверься. Это расширение правила «тоны — только по авторитету» на
весь контент.

Шаблон:

```md
# Ресурсы — тайский

## Знание
- [thai-language.com — словарь](http://thai-language.com/dict/search)
  Тоны, значения, класс согласных. Использовать: любая сверка тона/значения перед оценкой.
- {словарь/грамматический справочник — для чего}
- Файлы проекта THAILAND (glava*/b1_glava*) — основная лексика и правила по уровням.

## Мудрость (сообщества)
- [r/learnthai](https://reddit.com/r/learnthai) — живой опыт, разбор, советы практиков.
- {источники лакорнов/песен — материал для контекстных заданий}
```

Правила: только высокодоверенные источники; каждую запись аннотируй одной строкой (что и
когда брать); отдельно секция `## Пробелы`, если по нужной области нет хорошего источника
(это двигает поиск); если пользователь не хочет сообществ — отметь и не предлагай снова.

Принцип сверки в действии: перед вынесением оценки тона — thai-language.com; перед подачей
нового слова — транскрипция из файла проекта, а не из головы; факт о культуре/лакорне без
источника — пометь как неуверенный или найди подтверждение.
