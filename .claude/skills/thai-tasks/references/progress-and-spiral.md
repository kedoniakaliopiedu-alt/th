# Трекер прогресса, SM-2 и спираль

Механика собрана из практик двух плагинов и адаптирована под осознанную практику Ked:
- из **polyglot** — идея mastery-уровней и авто-импорта сид-словаря;
- из **fluent** — алгоритм **SM-2** (интервал по easiness-factor) и **база ошибок-
  паттернов** с примерами.

Скилл читает и переписывает один файл `progress.json` в проекте Thailand. Геймификации
(стрики, ачивки) нет — тон серьёзный, фокус на обучении.

## Автоматизация: scripts/tracker.py (основной путь)

Чтобы не считать SM-2 и get_due вручную, **используй бандл-скрипт** `scripts/tracker.py`
(только стандартная библиотека Python 3.8+). Он сам создаёт/обновляет `progress.json`.
Путь к progress.json — в проекте Thailand (например `<проект>/progress.json`).

```
# начать тему: импортировать её словарь из файла главы
python3 scripts/tracker.py import <progress.json> <glavaN_temaM_*.md> --topic 6.1

# что повторить (для 40% спирали) — вернёт JSON: mistakes_due + items_due
python3 scripts/tracker.py due <progress.json> --limit 4

# после ответа: применить SM-2 (quality 0–5)
python3 scripts/tracker.py record <progress.json> "ข้าว" 5
python3 scripts/tracker.py record <progress.json> "счётные слова จาน/ที่" 2 --type rule --topic 6.1.2

# записать паттерн ошибки (--topic обязателен: по нему собирается работа над ошибками)
python3 scripts/tracker.py mistake <progress.json> "тон_высокий_класс_закрытый" \
    --category Тоны --topic 6.1 --your средний --correct нисходящий --context "ข้าว"
# закрыть паттерн, когда он стабильно без ошибок
python3 scripts/tracker.py resolve <progress.json> "тон_высокий_класс_закрытый"

# работа над ошибками (skill thai-mistakes): список паттернов, план дрилла, итог круга
python3 scripts/tracker.py mistakes <progress.json> --topic 6.1
python3 scripts/tracker.py drill-plan <progress.json>
python3 scripts/tracker.py attempt <progress.json> "тон_высокий_класс_закрытый" --result ok

# обзор прогресса (для «покажи прогресс»)
python3 scripts/tracker.py progress <progress.json>

# сложность/точность
python3 scripts/tracker.py set-meta <progress.json> --difficulty 5 --recent-accuracy 0.68
```

Рабочий цикл занятия: `import` (если новая тема) → `due` (взять повтор в спираль) →
генерация и проверка заданий → по каждому элементу `record`, по ошибкам `mistake` →
в конце `progress` и, при желании, `set-meta`.

Если Python почему-то недоступен — веди `progress.json` вручную по формулам ниже (скрипт
реализует ровно их). Формулы остаются источником истины.

## progress.json — структура

```json
{
  "meta": {
    "difficulty": 4,
    "target_success": [0.6, 0.7],
    "recent_accuracy": 0.0,
    "updated": "2026-07-21"
  },
  "items": {
    "ข้าว": {
      "translation": "рис", "type": "word", "topic": "6.1",
      "repetitions": 2, "interval_days": 6, "easiness_factor": 2.5,
      "due_date": "2026-07-27", "last_seen": "2026-07-21",
      "mastery": 2, "consecutive_correct": 2, "consecutive_incorrect": 0
    },
    "счётные слова จาน/ที่": {
      "translation": "классификаторы порций", "type": "rule", "topic": "6.1.2",
      "repetitions": 0, "interval_days": 1, "easiness_factor": 2.3,
      "due_date": "2026-07-22", "last_seen": "2026-07-21",
      "mastery": 1, "consecutive_correct": 0, "consecutive_incorrect": 1
    }
  },
  "mistakes": {
    "тон_закрытый_слог_высокий_класс": {
      "category": "Тоны", "topic": "6.1", "frequency": 3, "status": "active",
      "rounds": 1, "drill_ok": 0, "last_drill": "2026-07-21",
      "last_occurred": "2026-07-21", "next_review": "2026-07-22",
      "examples": [
        { "your_answer": "средний", "correct": "нисходящий",
          "context": "ข้าว", "date": "2026-07-21" }
      ],
      "notes": "путает нисходящий и средний на ข-словах с ไม้โท"
    }
  }
}
```

- `items` — и лексика (`word`), и правила/конструкции (`rule`/`construction`).
  Для Ked грамматика в приоритете (её план B1), поэтому правила отслеживаем наравне.
- `mistakes` — повторяющиеся ошибки как **паттерны**, категория ровно из 4 категорий
  проверки (Словарный запас / Грамматика / Орфография / Тоны) — плюс отдельно
  «Регистр/обращения» и «Терминология», у них свои режимы отработки.
- Поля работы над ошибками (ведёт skill **thai-mistakes**): `topic` — тема, по которой
  собирается дрилл; `rounds` — сколько кругов отработки прошло; `drill_ok` — успешных
  кругов подряд (два подряд → `resolved`); `last_drill`; `status` = `active` /
  `critical` (пережила два круга за занятие, идёт первой в спирали) / `resolved`.
  Старые записи без этих полей дополняются скриптом автоматически.

## SM-2: как обновлять элемент после ответа

**1. Определи качество ответа `q` (0–5)** по тому, как пользователь справился:

| q | Что значит |
|---|---|
| 5 | мгновенно верно, без колебаний |
| 4 | верно после заминки / с мелкой помаркой |
| 3 | верно, но с трудом или после подсказки |
| 2 | неверно, но вспомнила, когда показал |
| 1 | неверно, лишь смутно знакомо |
| 0 | полный провал |

**2. Обнови повторения и интервал:**

```
если q >= 3 (верно):
    repetitions += 1
    если repetitions == 1: interval_days = 1
    иначе если repetitions == 2: interval_days = 6
    иначе: interval_days = round(interval_days * easiness_factor)
    consecutive_correct += 1;  consecutive_incorrect = 0
иначе (q < 3, ошибка):
    repetitions = 0
    interval_days = 1
    consecutive_incorrect += 1;  consecutive_correct = 0
```

**3. Обнови easiness_factor (EF):**

```
EF = EF + (0.1 - (5 - q) * (0.08 + (5 - q) * 0.02))
EF = max(1.3, EF)
```

**4. Даты и mastery:**

```
last_seen = сегодня
due_date  = сегодня + interval_days
если consecutive_correct >= 5: mastery = min(5, mastery + 1)
если consecutive_incorrect >= 3: mastery = max(0, mastery - 1)
```

EF делает интервал индивидуальным: лёгкие для тебя элементы быстро уходят на длинные
паузы, трудные возвращаются часто.

## get_due — что пора повторить (для 40% спирали)

1. Элемент **due**, если `due_date <= сегодня`.
2. Приоритет выборки:
   1) активные паттерны ошибок с `next_review <= сегодня` (слабые места — вперёд);
   2) items с низким `mastery`;
   3) items с самой ранней `due_date`.
3. Возьми 2–4 элемента на ~40% комплекса и **вплети в задания по новой теме** (спираль),
   не отдельным блоком.
4. Если due-элементов нет — 1–2 с самым низким mastery, либо комплекс целиком на новом.

## База ошибок-паттернов (mistakes)

Отдельно от отдельных элементов фиксируем **повторяющиеся ошибки**, чтобы бить точечно.

При ошибке в разборе (см. checking.md):
1. Определи паттерн: категория (Словарный запас/Грамматика/Орфография/Тоны) + конкретика
   (например «тон в закрытом слоге, высокий класс»).
2. Если такой паттерн уже есть — `frequency += 1`, добавь новый пример
   `{your_answer, correct, context, date}`, обнови `last_occurred`.
3. Если новый — заведи запись со `status: active`, `frequency: 1`, первым примером.
4. Назначь `next_review` близко (например +1 день) — слабое место должно вернуться скоро.
5. Когда паттерн несколько занятий не всплывает и mastery связанных элементов растёт —
   переведи `status` в `resolved` (перестаёт тянуться в спираль, но история остаётся).

Паттерны — главный источник ответа на вопрос «что из старого я не помню».

## Авто-импорт лексики и правил из файлов

Чтобы get_due видел словарь темы, занеси его в трекер до генерации заданий.

1. Прочитай нужный файл (`glavaN_temaM_*.md` / `b1_glavaN_*.md`), секции «Словарный
   запас» и «Теория/конструкции».
2. Для каждого нового слова/правила добавь запись с `repetitions: 0, interval_days: 0,
   easiness_factor: 2.5, mastery: 0, consecutive_correct: 0, consecutive_incorrect: 0,
   due_date: сегодня` (сразу due) и `topic`. Транскрипцию бери из файла.
3. Не дублируй существующее. Примеры из «Практических упражнений» не импортируй.

Импорт делай тихо, до заданий.

## Целевой процент успеха (desirable difficulty / i+1)

Держи сложность так, чтобы **свежие** (не повторные) задания давали ~**60–70%** успеха —
это зона максимального обучения: трудно, но достижимо.

- Считай `meta.recent_accuracy` по последним занятиям (доля верных на новом материале).
- Если стабильно **> 80%** — подними `meta.difficulty` на 1 (см. регулятор в SKILL.md).
- Если **< 50%** — опусти на 1 и добавь больше опоры/разминки.
- 60–70% — не трогай, идёшь оптимально.

Это калибрует регулятор сложности сам, а не на глаз.

## Обновление после занятия и обзор прогресса

После разбора обнови по каждому задействованному элементу SM-2 (выше), запиши ошибки в
`mistakes`, пересчитай `meta.recent_accuracy`, поставь `meta.updated = сегодня`.

Команда «покажи прогресс» → собери из `progress.json` короткий обзор (без геймификации):

```
Прогресс — тайский · сложность 4 · точность (новое): 68%

Навыки/темы (средний mastery):
  Еда 6.1        ⭐⭐⭐☆☆  (3/5)
  Заказ 6.1.2    ⭐⭐☆☆☆  (2/5)
  Тоны           ⭐⭐⭐⭐☆  (4/5)

Пора повторить (due): 5 элементов
Активные слабые места:
  • Тоны: закрытый слог, высокий класс — 3×
  • Грамматика: порядок слов в вопросе — 2×
```

Файл машинный — не засоряй прозой; источник правды для спирали — `progress.json`.
