# Скиллы проекта Thai

Набор скиллов, превращающих Claude в персонального репетитора по тайскому для этого
репозитория. Практико-ориентированное обучение: осознанные комплексные задания, спираль
с интервальным повтором, продукция рус→тай, серьёзный тон без геймификации.

## Состав и роли

| Скилл | Роль |
|---|---|
| **thai-tasks** | Главный движок. Собирает комплексные практические задания по любой теме, ведёт трекер прогресса (SM-2), спираль 60/40, два режима (сессия / воркшит). |
| **thai-learning** | Правила подачи заданий и проверки ответов, структура уровней, контрольные. |
| **thai-phonetics** | Кириллическая транскрипция тайских звуков, тоновые знаки (` ˆ ´ ˇ). |
| **thai-display** | Оформление слов по классам согласных. Опционально — только когда нужен разбор по классам. |
| **learn** | Базовая педагогика: диагностика, один шаг за ход, подсказка вместо готового ответа. |
| **teach** | Учебное пространство: миссия, learning-records, ресурсы, глоссарий (форматы). |

## Как связаны

```
thai-tasks  (движок заданий)
├── learn            — педагогика диалога
├── thai-learning    — правила подачи и проверки
├── thai-phonetics   — транскрипция и тоны
├── thai-display     — оформление по классам (опционально)
└── teach (форматы)  — миссия / learning-records / ресурсы
```

thai-tasks — точка входа; остальные он подключает по мере надобности.

## Источник теории

Материал уроков лежит в этом же репозитории:

- `Thai A2/Chapter N/glavaN_temaM_*.md`
- `Thai B1/Chapter N/b1_glavaN_temaM_*.md`
- `Helpers/*.md`, `ШАБЛОН-подтемы.md`

thai-tasks ищет файлы **рекурсивно** и берёт из них лексику и правила (примеры из секции
«Практические упражнения» не переписывает — генерирует свежие).

## Трекер прогресса

thai-tasks ведёт `progress.json` (в корне проекта) через скрипт
`thai-tasks/scripts/tracker.py` — только стандартная библиотека Python 3.8+, офлайн.

```bash
# импортировать словарь темы
python3 .claude/skills/thai-tasks/scripts/tracker.py import progress.json "Thai A2/Chapter 3/glava3_tema4_rasporyadok.md" --topic 3.4
# что пора повторить
python3 .claude/skills/thai-tasks/scripts/tracker.py due progress.json
# применить SM-2 после ответа (качество 0–5)
python3 .claude/skills/thai-tasks/scripts/tracker.py record progress.json "ตื่น" 5
# записать паттерн ошибки
python3 .claude/skills/thai-tasks/scripts/tracker.py mistake progress.json "тон_финаль" --category Тоны --your ... --correct ...
# обзор прогресса
python3 .claude/skills/thai-tasks/scripts/tracker.py progress progress.json
```

Полная механика (SM-2, get_due, база ошибок, авто-импорт, регулятор сложности) —
в `thai-tasks/references/progress-and-spiral.md`.

## Как пользоваться

Запусти движок и назови тему любого масштаба:

```
/thai-tasks составь задания на тему Глава 3 · Тема 3.4 — Распорядок дня
/thai-tasks потренируем счётные слова
/thai-tasks дай разговорную практику на рынке
/thai-tasks покажи прогресс
```

Масштаб запроса управляет объёмом: правило (≤5, разминка+сборка) → подтема (все блоки) →
тема (сборник подтем) → глава (план по темам).

## Справочные файлы thai-tasks

- `references/exercise-catalog.md` — меню типов заданий (атомарные → интеграционные →
  комплексные), включая индуктивный вывод правила, этимологию/морфемы, нарративы.
- `references/checking.md` — порядок разбора: подсказки → ответ, оценка по 4 категориям
  (Словарь / Грамматика / Орфография / Тоны), линза «естественность», сверка тонов.
- `references/progress-and-spiral.md` — трекер, SM-2, спираль, авто-импорт, сложность.
- `references/mission-and-records.md` — миссия, learning-records, доверенные источники.

## Примечания

- Транскрипция — строго кириллицей; тоновый знак ставится над гласной.
- Тоны перед оценкой сверяются по авторитетному источнику (thai-language.com), не по памяти.
- Литовские скиллы (`lithuanian-*`) относятся к отдельному проекту LT и здесь не нужны.
