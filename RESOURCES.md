# Ресурсы — тайский

Откуда берутся факты. Значения, написание, тоны и звучание не пишутся по памяти: при
малейшей неуверенности — сверка по источнику отсюда. Это расширение правила «тоны только по
авторитетному источнику» из `CLAUDE.md` на весь материал.

**Знание живёт в репозитории, ссылка добавляет звук.** Внешний ресурс не стоит в критическом
пути занятия: всё, без чего урок не идёт, должно быть скопировано в файл проекта с датой
сверки. Отключённый интернет не должен ломать занятие.

---

## Знание

**[thai-language.com — словарь](http://thai-language.com/dict/search)**
Зона: слово целиком — написание, значение, **тон**, класс согласного в конкретном случае.
Когда брать: перед любым вердиктом по тону, перед подачей нового слова, при сомнении
в значении. Единственный источник тона в проекте.
Чем заменяем: замены нет. Пока не найдена, при недоступности словаря тон не оценивается —
задание переносится, а не выносится вердикт по памяти.

**[thai-alphabet.com](https://thai-alphabet.com/)**
Зона: отдельный знак — класс, чтение в инициали, чтение в финали, **звучание** (озвучено
носителем), примеры слов с аудио. Есть русский интерфейс и кириллический режим записи.
Когда брать: любой вопрос «как читается этот знак в конце слога», постановка произношения,
задание на слух. Слов не знает — тон конкретного слова там не проверяется.
Снято в проект: `.claude/skills/thai-phonetics/references/consonants.md`, сверка 2026-07-28.
Чем заменяем: таблица уже скопирована, поэтому смерть ссылки отнимает только звук.

**Файлы курса — `Thai A2/`, `Thai B1/`, `Helpers/`**
Зона: лексика, правила и конструкции по уровням; критерий закрытия темы.
Когда брать: основной материал заданий. `thai-tasks` ищет по ним рекурсивно и берёт слова
и правила, но не переиспользует примеры из «Практических упражнений».

## Как разводятся зоны

Источники не дублируют друг друга, и путать их зоны — ошибка:

| Вопрос | Источник |
|---|---|
| Какой тон у этого слова | thai-language.com |
| Как пишется, что значит | thai-language.com, файлы курса |
| Как читается знак в конце слога | thai-alphabet.com → `consonants.md` |
| Как это звучит | thai-alphabet.com |
| Какая лексика у темы | файлы курса |

При конфликте источников запись помечается как спорная и **на лист ученику не выносится**.

## Пробелы

Области, где хорошего источника нет — список двигает поиск, а не оправдывает выдумывание.

- **Названия групп финалей** (แม่กก, แม่กน и прочие «матери»): термин уже нужен — ошибка
  `термин_мать_финали` в трекере, — но ни один подключённый источник его не даёт.
- **Правило тона** как связная тема: класс инициали плюс тип слога есть по кускам, единого
  описания нет ни в источниках, ни в файлах курса.
- **Аудио целых фраз**: озвучены знаки и отдельные слова, связной речи для аудирования нет.
- **Сообщества и живой материал** (лакорны, песни): не выбраны. Пока не выбраны — контекст
  из них подаётся как неуверенный либо не подаётся.
