# th — Проект «Тайский»

Личный репозиторий для изучения тайского языка: учебные материалы по уровням,
разбор рукописных ответов, трекер прогресса и набор навыков («skills») для
занятий с Claude Code в роли преподавателя.

## Структура репозитория

- **`Thai A2/`, `Thai B1/`** — учебные материалы по главам (лексика, правила,
  контрольные) для соответствующих уровней.
- **`Helpers/`** — вспомогательные справочные материалы к курсу.
- **`Handwriting/`** — рабочая папка для распознавания рукописных ответов
  (используется пайплайном `thai-handwriting`).
- **`.claude/`** — навыки («skills») для тьютора: постановка заданий
  (`thai-tasks`), проверка ошибок (`thai-mistakes`), транскрипция
  (`thai-phonetics`), проверка тонов (`thai-verify`) и мета-навыки для
  работы над самими навыками (`skill-brainstorm`, `skill-writer`,
  `skill-review`). Подробнее — в `.claude/skills/README.md` и `MAP.md`.
- **`site/`, `scripts/`** — HTML-версия курса с навигацией по уровням/темам
  и обслуживающие скрипты.
- **`progress.json`** — трекер прогресса и ошибок ученика.
- **`CLAUDE.md`** — рабочие правила проекта для Claude Code.
- **`RESOURCES.md`** — какие источники (словари, справочники) авторитетны
  для каких вопросов (тон, написание, звучание) и как избегать конфликтов
  между ними.

## Принципы

- Тоны сверяются только по авторитетному источнику (thai-language.com),
  никогда по памяти.
- Транскрипция — только кириллицей, по единой системе (`thai-phonetics`).
- Все материалы, показываемые ученику, — на русском языке; правила и код
  могут постепенно переходить на английский.
- Исправления отчётов выдаются целиком, а не как дельта к предыдущей версии.

## Технологии

HTML/CSS для сайта курса, Python для вспомогательных скриптов и трекера
прогресса.
